# 🐛 React Native — 4.

## 🎯 Concept

React Native provides multiple debugging tools that help you:

- Understand your app behavior
    
- Detect and fix errors
    
- Inspect components, state, and props
    
- Analyze performance and network activity
    

The tools learned in this section are sufficient for debugging most real-world React Native apps.

---

# 🧰 Core Debugging Tools Recap

## 1. Error Messages (First and Most Important Tool)

React Native shows error messages that include:

- Error description
    
- Component name
    
- File location
    
- Stack trace
    

Example:

```
Invalid prop 'source' supplied to Image
```

Helps identify:

- What is wrong
    
- Where it is wrong
    

Always read error messages carefully.

---

## 2. console.log (Basic but essential debugging tool)

Used to:

- Track execution flow
    
- Inspect variable values
    
- Inspect state changes
    

Example:

```
console.log("GoalInput rendered");
console.log(enteredGoalText);
```

Output appears in:

- Terminal
    
- Chrome DevTools (when remote debugging enabled)
    

---

## 3. Developer Menu (Expo built-in debugging control)

Open Developer Menu using:

```
m  (terminal)
```

OR

```
Cmd + D (iOS)
Ctrl + M (Android)
```

Provides debugging options:

- Reload app
    
- Enable Remote Debugging
    
- Debug settings
    

---

## 4. Remote Debugging (Chrome DevTools integration)

Enable via Developer Menu:

```
Debug Remote JS
```

Allows access to:

- Console logs
    
- Network requests
    
- JavaScript debugging
    

Useful for API debugging and advanced debugging.

---

## 5. React DevTools (Most powerful debugging tool)

Installed using:

```
npm install -g react-devtools
```

Run using:

```
react-devtools
```

Allows inspection of:

- Component tree
    
- Component props
    
- Component state
    
- Live state editing
    

Extremely useful for complex apps.

---

# 📊 Debugging Tool Comparison

|Tool|Purpose|
|---|---|
|Error messages|Identify crashes and problems|
|console.log|Inspect values and execution flow|
|Developer Menu|Access debugging features|
|Remote Debugging|Advanced debugging and network inspection|
|React DevTools|Inspect components, props, and state|

# 🧠 Recommended Debugging Workflow

When encountering a problem:

```
1. Read error message
2. Check stack trace
3. Use console.log if needed
4. Use React DevTools to inspect state and props
5. Use Remote Debugging for deeper analysis
6. Fix problem and test again
```
