# 🐛 React Native — Developer Menu & Remote Debugging (Expo Tools)

## 🎯 Concept

React Native + Expo provide built-in debugging tools beyond `console.log`.

These tools help you:

- Reload the app quickly
    
- Open debugging tools
    
- Inspect logs
    
- Inspect network requests
    
- Analyze app behavior deeply
    

These tools are accessed through:

- Terminal shortcuts
    
- Developer Menu
    
- Remote Debugging (Chrome DevTools)
    

---

# ⌨️ Terminal Shortcuts (Expo Development Server)

When running:

```
npm start
```

You can press keys in the terminal to trigger actions.

Click the terminal first, then press:

|Key|Action|
|---|---|
|a|Open Android emulator|
|i|Open iOS simulator|
|r|Reload app|
|m|Open Developer Menu|
|?|Show all shortcuts|

Press:

```
?
```

to see all available commands.

---

# 📱 Developer Menu (Very Important Tool)

Open Developer Menu using:

Terminal shortcut:

```
m
```

OR emulator shortcuts:

|Platform|Shortcut|
|---|---|
|iOS|Cmd + D|
|Android|Ctrl + M|

This opens the React Native Developer Menu.

---

# 🧰 What you can do in Developer Menu

Developer Menu provides options like:

- Reload app
    
- Go back to home screen
    
- Enable remote debugging
    
- Open debugging tools
    

Most important option:

```
Debug Remote JS
```

---

# 🌐 Remote Debugging (Chrome DevTools)

When you select:

```
Debug Remote JS
```

React Native opens:

```
Chrome browser tab
```

You can then open:

```
Chrome DevTools
```

This provides advanced debugging tools.

---

# 🧠 What you can do in Chrome DevTools

## 1. View console logs

Same logs as terminal:

Example:

```
console.log("GoalInput rendered")
```

Appears in Chrome console.

---

## 2. Inspect network requests

This is very important for apps using APIs.

In Chrome DevTools → Network tab

You can see:

- API calls
    
- Request headers
    
- Response data
    
- Errors
    

Example:

```
GET https://api.example.com/goals
```

---

## 3. Inspect JavaScript execution

You can:

- Pause execution
    
- Inspect variables
    
- Debug logic
    

---

# 📊 Debugging Flow Diagram

```
React Native App
      │
      ▼
Developer Menu
      │
      ▼
Remote Debugging
      │
      ▼
Chrome DevTools
      │
      ├ Console logs
      ├ Network requests
      ├ Debugging tools
```

---

# 🧠 Where logs appear when remote debugging is enabled

Logs appear in:

```
Chrome DevTools Console
```

instead of only terminal.

---

# 🔄 Reloading when debugging

Sometimes logs don’t appear immediately.

Fix by:

```
Press r in terminal
```

OR reload emulator manually.

---

# 🧠 When to use Remote Debugging

Use it when you want:

- Network inspection
    
- Advanced debugging
    
- Console inspection
    
- Logic debugging
    

Especially useful for:

- API calls
    
- Backend integration
    
- Complex logic
    

---

# ⚠️ Remote debugging is optional

You do NOT need it all the time.

Use it when needed.

Normal debugging via terminal is sufficient in many cases.

---

# 🧠 Difference: Terminal vs Chrome DevTools

|Tool|Best for|
|---|---|
|Terminal|Simple logs|
|Chrome DevTools|Advanced debugging|
|Developer Menu|Debugging controls|

---

# 🧠 Important Developer Workflow

Typical debugging workflow:

```
Run app
↓
Error occurs
↓
Check terminal logs
↓
Open Developer Menu
↓
Enable Remote Debugging
↓
Inspect in Chrome DevTools
↓
Fix problem
```

Expo provides powerful debugging tools.

- Terminal shortcuts

- Console logs
