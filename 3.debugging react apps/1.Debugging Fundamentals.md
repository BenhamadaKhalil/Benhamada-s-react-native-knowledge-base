# 🐛 React Native — Debugging Fundamentals

## 🎯 Concept

Debugging is the process of:

- Finding errors
    
- Understanding why they happen
    
- Fixing them
    

Errors are normal in development.

Every React Native developer must know how to:

- Read error messages
    
- Understand error causes
    
- Use debugging tools
    
- Inspect UI and state
    

---

# ⚠️ Why Debugging is Important

When building apps, things will go wrong:

- Syntax errors
    
- Logic errors
    
- UI errors
    
- State errors
    
- Runtime crashes
    

Debugging helps you:

- Fix crashes
    
- Improve code quality
    
- Understand app behavior
    
- Develop faster
    

---

# 🧠 Types of Errors in React Native

You will encounter different error types:

---

## 1. Syntax Errors

Caused by invalid code.

Example:

```
const name =
```

Missing value.

Result:

App won’t compile.

---

## 2. Runtime Errors

Code runs but crashes.

Example:

```
props.name.toUpperCase()
```

If props.name is undefined → crash.

---

## 3. Logic Errors

App runs but behaves incorrectly.

Example:

- Wrong state update
    
- Wrong condition
    

No crash, but wrong behavior.

---

## 4. UI Errors

Layout or styling issues.

Example:

- Component not visible
    
- Incorrect positioning
    

---

# 📱 React Native Error Messages

React Native shows detailed error messages.

These messages usually include:

- Error description
    
- File name
    
- Line number
    
- Component stack
    

Example:

```
Error: Cannot read property 'text' of undefined

at GoalItem.js line 14
```

This tells you:

- What failed
    
- Where it failed
    

---

# 🧠 How to read error messages properly

Always check in this order:

1. Error message description
    
2. File name
    
3. Line number
    
4. Component involved
    

Example analysis:

```
Cannot read property 'text'
```

Means:

```
Something.text
```

But something is undefined.

# 🧰 Debugging Tools Available

React Native + Expo provides powerful debugging tools:

---

## 1. Error overlay (Red Screen)

Shows errors directly on the app screen.

Includes:

- Stack trace
    
- File location
    
- Error explanation
    

---

## 2. Console logs

Use:

```
console.log()
```

Example:

```
console.log(goals)
```

Shows values in terminal.

---

## 3. Expo DevTools

Provides:

- Logs
    
- Reload controls
    
- Debugging options
    

---

## 4. React Developer Tools (later in course)

Allows:

- Inspect components
    
- Inspect state
    
- Inspect props
    

---

# 🧠 Key Debugging Mindset

When an error occurs:

Do NOT panic.

Follow this process:

```
Read error
↓
Find file
↓
Find line
↓
Understand cause
↓
Fix code
↓
Test again
```

---

# 🧪 Example debugging scenario

Error:

```
Cannot read property 'text' of undefined
```

Cause:

```
props.goal.text
```

But props.goal is undefined.

Fix:

```
Ensure props.goal exists
```

# 🧠 Debugging in React Native vs React Web

Mostly the same concepts.

Differences:

React Native debugging focuses on:

- Native components
    
- Mobile layout
    
- Touch interactions
    

Instead of HTML DOM.
