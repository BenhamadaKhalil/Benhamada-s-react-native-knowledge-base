# 📱 React Native — Managing a Dynamic List of Goals (State + map + keys)

## 🎯 What problem are we solving?

We already can:

- Read what the user types (`enteredGoalText` in state)
    
- React to button press (`onPress`)
    

Now we want the app to actually **store goals** and **show them on screen**.

That means we need:

1. A **list state** (array)
    
2. Add new items to it when the button is pressed
    
3. Render that list dynamically in JSX
    

---

# 1) Why we need a second state (array of goals)

A list of goals changes over time:

- Starts empty
    
- Grows when user adds goals
    
- UI must update when it changes
    

That’s exactly what state is for.

So we create:

```jsx
const [courseGoals, setCourseGoals] = useState([]);
```

- `courseGoals` is an array
    
- Starts as `[]` because there are no goals initially
    

---

# 2) Adding a new goal to the list (important React best practice)

In `addGoalHandler`, we want to append `enteredGoalText` to the existing array.

### The “simple” way (works, but not ideal in React)

```jsx
setCourseGoals([...courseGoals, enteredGoalText]);
```

Why it’s not ideal here:

- The new state depends on the **previous state**
    
- State updates may be batched, so `courseGoals` might not be the latest value in some cases
    

### ✅ Best practice: use the functional state update

React gives you the latest previous state automatically:

```jsx
setCourseGoals((currentCourseGoals) => {
  return [...currentCourseGoals, enteredGoalText];
});
```

**Mental model:**  
Instead of “trusting” your `courseGoals` variable, you tell React:

> “Give me the most recent version of the goals, then I’ll build the next version from it.”

This is the recommended pattern whenever:  
✅ new state depends on old state

---

# 3) Rendering the list on the screen (map)

We want to display each goal under “List of goals”.

In React (web or native), the typical pattern is:

- Take array data
    
- Convert each item into a JSX element using `map()`
    

```jsx
{courseGoals.map((goal) => (
  <Text>{goal}</Text>
))}
```

### What `map()` is doing here

- It runs once for each item in the array
    
- For each `goal` string, it returns a `<Text>` element
    
- React renders the resulting array of `<Text>` elements
    

So if `courseGoals = ["Learn RN", "Practice Flexbox"]`, it becomes:

```
<Text>Learn RN</Text>
<Text>Practice Flexbox</Text>
```

---

# 4) The “key” warning and how to fix it

React shows a warning:

> “Each child in a list should have a unique ‘key’ prop”

This is not React Native specific — it’s core React behavior.

### Why keys matter

When the list changes, React needs to figure out efficiently:

- which items are new
    
- which items were removed
    
- which items moved
    

A unique `key` helps React track each list item correctly.

### ✅ Fix: add `key` prop

Since goals are strings for now, the instructor uses the string itself:

```jsx
{courseGoals.map((goal) => (
  <Text key={goal}>{goal}</Text>
))}
```

⚠️ Note (same as instructor said): this is **not guaranteed unique** if the user adds the same text twice, but it’s OK for now. Later we’ll improve it (usually by giving each goal an id).

# ✅ Final “lecture-style” code (core idea)

```jsx
import { useState } from 'react';
import { View, Text, TextInput, Button } from 'react-native';

export default function App() {
  const [enteredGoalText, setEnteredGoalText] = useState('');
  const [courseGoals, setCourseGoals] = useState([]);

  function goalInputHandler(enteredText) {
    setEnteredGoalText(enteredText);
  }

  function addGoalHandler() {
    setCourseGoals((currentCourseGoals) => [
      ...currentCourseGoals,
      enteredGoalText,
    ]);
  }

  return (
    <View>
      <View>
        <TextInput
          placeholder="Your course goal"
          onChangeText={goalInputHandler}
        />
        <Button title="Add Goal" onPress={addGoalHandler} />
      </View>

      <View>
        {courseGoals.map((goal) => (
          <Text key={goal}>{goal}</Text>
        ))}
      </View>
    </View>
  );
}
```

## 🧠 Key takeaways from this lecture

- Lists are state → initialize with `[]`
    
- When new state depends on old state → use functional update:
    
    ```jsx
    setState(prev => ...)
    ```
    
- Render arrays using `map()`
    
- Always add a `key` when rendering lists
