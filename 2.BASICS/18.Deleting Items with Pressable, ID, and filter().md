# 📱 React Native — Deleting Items with Pressable, ID, and filter()

## 🎯 Concept

To delete an item from a list, you must:

1. Identify the item uniquely → using an **ID**
    
2. Update the state → removing that item
    
3. Trigger deletion → using **Pressable**
    
4. Pass the ID → from child to parent
    

This follows the standard React pattern:

```
Child triggers event → Parent updates state → UI updates
```

---

# 🧠 Step 1 — Each item must have a unique ID

Example data:

```
[
  { text: "Learn React Native", id: "g1" },
  { text: "Build Apps", id: "g2" }
]
```

Why ID is needed:

- Text may not be unique
    
- ID uniquely identifies item
    

---

# 🧠 Step 2 — Create deleteGoalHandler in App.js

```
function deleteGoalHandler(id) {

   setCourseGoals((currentGoals) => {

      return currentGoals.filter((goal) => {
         return goal.id !== id;
      });

   });

}
```

---

# 🧠 Understanding filter()

filter() creates a new array removing unwanted items.

Example:

```
[1, 2, 3, 4].filter(num => num !== 2)

Result:
[1, 3, 4]
```

---

# 📊 filter() logic diagram

```
Original array:
[g1, g2, g3]

Delete g2

filter runs:

g1.id !== g2 → keep
g2.id !== g2 → remove
g3.id !== g2 → keep

Result:
[g1, g3]
```

---

# ⚠️ Why use function version of setState

Correct:

```
setCourseGoals((currentGoals) => {...})
```

Wrong:

```
setCourseGoals(newArray)
```

Reason:

When state depends on previous state → use function.

This prevents bugs.

---

# 🧠 Step 3 — Pass ID to GoalItem component

App.js:

```
<GoalItem
   text={itemData.item.text}
   id={itemData.item.id}
   onDeleteItem={deleteGoalHandler}
/>
```

Now GoalItem has access to ID.

---

# 🧠 Step 4 — Pass ID when item is pressed using bind()

GoalItem.js:

```
<Pressable onPress={props.onDeleteItem.bind(this, props.id)}>
```

bind() creates a new function and passes parameter.

---

# 🧠 How bind() works

Syntax:

```
function.bind(thisArg, param1)
```

Example:

```
function deleteGoalHandler(id)

bind(this, "g1")

Result:
deleteGoalHandler("g1")
```

---

# 📊 Full deletion flow

```
User taps item
      │
      ▼
Pressable executes function
      │
      ▼
deleteGoalHandler(id)
      │
      ▼
filter removes item
      │
      ▼
State updates
      │
      ▼
FlatList updates UI
```

# 🧪 Full Example Code

## App.js

```
function deleteGoalHandler(id) {

   setCourseGoals((currentGoals) => {

      return currentGoals.filter((goal) => goal.id !== id);

   });

}
```

---

```
<FlatList
   data={courseGoals}
   renderItem={(itemData) => (
      <GoalItem
         text={itemData.item.text}
         id={itemData.item.id}
         onDeleteItem={deleteGoalHandler}
      />
   )}
/>
```

---

## GoalItem.js

```
import { Pressable, View, Text } from "react-native";

function GoalItem(props) {

   return (

      <Pressable onPress={props.onDeleteItem.bind(this, props.id)}>

         <View>
            <Text>{props.text}</Text>
         </View>

      </Pressable>

   );

}

export default GoalItem;
```

---

# 🧠 Alternative method (also correct)

Instead of bind():

```
<Pressable onPress={() => props.onDeleteItem(props.id)}>
```

This is often easier to read.

Both methods are valid.

---

# 💡 Why React uses immutable updates

React requires creating a new array.

Wrong:

```
currentGoals.splice(...)
```

Correct:

```
currentGoals.filter(...)
```

Reason:

React detects changes using references.

---

# 🚨 Common mistakes

### ❌ Not passing ID

```
<GoalItem text="Goal" />
```

Delete won't work.

---

### ❌ Using filter incorrectly

Wrong:

```
goal.id === id
```

This keeps only deleted item.

Correct:

```
goal.id !== id
```

---

### ❌ Modifying original array

Wrong:

```
currentGoals.pop()
```

Never mutate state directly.

# 🧠 Key React Pattern Used Here

This is called:

```
Event → State Update → Re-render
```

This is the core of React.

---

# 🧠 Summary

To delete items:

1. Each item must have unique ID
    
2. Pass ID via props
    
3. Use Press Pressable to detect tap
    
4. Pass ID using bind() or arrow function
    
5. Use filter() to remove item
    
6. Update state immutably
    
7. React re-renders automatically
    

This is the standard pattern used in all real React Native apps.
