# 🎨 1) Styling built-in Buttons (color prop)

React Native built-in `Button` can’t be styled using `style`.

✅ You change button color using:

```
color="..."
```

Chosen colors:

- Add button: initially `#5E0ACC`, later changed to a lighter purple for iOS readability: `#B180F0`
    
- Cancel button: `#F31282`
    

Result:

- Android looked fine with darker purple
    
- iOS text readability was harder → switch to lighter purple for cross-platform consistency
    

📌 Note: Platform-specific styling is possible later, but for now they keep one shared solution.

# ✅ 5) Better approach with Expo: global background color via app.json

If you have multiple screens, manually setting background color for every screen becomes annoying.

With **Expo**, you can set a global background color in:

```
app.json
```

Add a background color configuration entry (hex code).

Effect:

- Expo automatically applies this background color to all “main screens”
    
- Modals are overlays → they keep their own background styling (inside modal content View)
    

This is more scalable for multi-screen apps (especially later with navigation).

# 📶 7) Fix Status Bar visibility (Expo StatusBar)

After using dark backgrounds, the default status bar becomes hard to see (still dark text/icons).

Expo provides a dedicated component:

```
StatusBar
```

Import it from:

```
expo-status-bar
```

Add `<StatusBar />` in the root JSX.

Since JSX root cannot return siblings without a wrapper, wrap the View + StatusBar with a Fragment:

```
<>
  <StatusBar style="light" />
  <View>...</View>
</>
```

Set:

- `style="light"`
    

So the status bar icons become white and readable.

📌 `auto` didn’t work well here, so `light` was chosen.

- Built-in `Button` is limited: use `color` only (custom buttons need `Pressable`)
    
- TextInput styling is done via styles object (like web, but with RN properties)
    
- With Expo, `app.json` can configure global default background
    
- Use Expo `StatusBar` to ensure readable status icons on dark UI
