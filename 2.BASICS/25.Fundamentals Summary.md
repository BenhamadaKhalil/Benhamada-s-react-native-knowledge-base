# 📱 React Native — Fundamentals Summary (First App & Core Concepts)

This section introduced the **core foundations of React Native** by building a complete Goal App.

You learned how to create mobile UIs, manage state, handle user input, style components, and optimize lists.

React Native is essentially:

> React + Native platform components instead of HTML.

---

# 🧱 1. Core Components (No HTML in React Native)

In React Native, you **cannot use HTML elements** like:

```
div ❌
span ❌
button ❌
```

Instead, you use built-in React Native components:

|React Native|Equivalent Web Concept|
|---|---|
|View|div|
|Text|p / span|
|TextInput|input|
|Button|button|
|Image|img|
|Pressable|clickable div|
|FlatList|optimized list|

Example:

```
<View>
   <Text>Hello World</Text>
</View>
```

All UI is built from these core components.

---

# 🎨 2. Styling in React Native

Styling is done using **JavaScript objects**, not CSS files.

Example:

```
const styles = StyleSheet.create({
   container: {
      padding: 16,
      backgroundColor: "#311b6b"
   }
});
```

Applied like:

```
<View style={styles.container}>
```

---

## ⚠️ Important differences from CSS

React Native styling:

- Looks similar to CSS
    
- But is NOT CSS
    

Differences:

|CSS|React Native|
|---|---|
|Uses classes|Uses JS objects|
|Uses strings|Uses JS values|
|Has inheritance|No inheritance|
|Uses kebab-case|Uses camelCase|

Example:

```
background-color ❌
backgroundColor ✅
```

---

## How styling works internally

React Native converts:

```
JS styles → Native styles (Android / iOS)
```

This allows apps to run as native apps.

---

# 🧠 3. State Management (Same as React Web)

React Native uses the same React concepts:

- useState
    
- props
    
- events
    
- conditional rendering
    

Example:

```
const [goals, setGoals] = useState([]);
```

State controls UI.

Updating state → re-renders UI automatically.

---

# 🖱️ 4. Handling User Events

React Native does NOT use:

```
onClick ❌
```

Instead uses:

```
onPress ✅
```

Example:

```
<Pressable onPress={handler}>
```

This works for touch input.

---

# 📦 5. Components & Component Architecture

Apps are split into reusable components.

Example structure:

```
App.js
components/
   GoalItem.js
   GoalInput.js
```

Benefits:

- Reusable
    
- Maintainable
    
- Scalable
    

Data flows using props:

```
Parent → Child
```

Functions can also be passed via props.

---

# 📜 6. Lists: ScrollView vs FlatList

Two important components:

---

## ScrollView

- Renders ALL items at once
    
- Bad for large lists
    
- Poor performance with many items
    

Use for:

- Static content
    
- Small content
    

---

## FlatList (Recommended for lists)

- Renders only visible items
    
- Loads items lazily
    
- Optimized performance
    

Example:

```
<FlatList
   data={goals}
   renderItem={...}
/>
```

This is the standard way to display lists in React Native.

---

# 👆 7. Pressable (Handling Touch Interaction)

Pressable makes elements clickable.

Example:

```
<Pressable onPress={handler}>
   <Text>Tap me</Text>
</Pressable>
```

Provides touch feedback.

Supports styling based on pressed state.

---

# 🪟 8. Modal (Overlay UI)

Modal creates overlay screens.

Used for:

- Forms
    
- Popups
    
- User input
    

Example:

```
<Modal visible={true}>
   <View>...</View>
</Modal>
```

Controlled using state.

---

# 🖼️ 9. Image Component

React Native uses Image component.

Example:

```
<Image source={require("../assets/images/goal.png")} />
```

Important difference from web:

Uses:

```
require()
```

Not:

```
src="..."
```

---

# 🎛️ 10. Platform Differences (Android vs iOS)

React Native supports both platforms.

But behavior may differ:

Example differences:

- Ripple effect works only on Android
    
- Some styling behaves differently
    
- UI rendering can vary slightly
    

React Native translates your code to native instructions.

---

# 📊 11. Expo & Global Configuration

Expo simplifies development.

You can configure global settings in:

```
app.json
```

Example:

- backgroundColor
    
- app name
    
- icons
    

---

# 📶 12. StatusBar Component

Expo provides:

```
StatusBar
```

Used to control:

- color
    
- visibility
    
- appearance
    

Example:

```
<StatusBar style="light" />
```

Important when using dark backgrounds.
