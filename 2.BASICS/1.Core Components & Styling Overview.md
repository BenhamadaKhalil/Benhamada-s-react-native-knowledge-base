## 🧱 Core React Native Components

In `App.js`, some components are imported from **React Native**, such as:

- `View`
    
- `Text`
    
- `StyleSheet`
    

These are **built-in core components**.

### Why Not `div`, `h1`, etc.?

- HTML elements only work in browsers
    
- Native devices:
    
    - Are not browsers
        
    - Do not have a DOM
        
- Therefore:
    
    - HTML elements are not supported
        

React Native exposes its **own components** that are translated to:

- Android native UI widgets
    
- iOS native UI widgets

## 🧩 How UI Is Built in React Native

React Native works by:

- Combining core components
    
- Creating custom components from them
    
- Composing the UI step by step
    

This is similar to React Web:

- Web → combine HTML elements
    
- Native → combine React Native components
    

The idea is the same:  
**composition**

---

## 🎨 Styling in React Native

Important difference from web development:

- ❌ No CSS
    
- ❌ No `.css` files
    
- ❌ No CSS language
    

Why?

- React Native apps are not browser-based
    

---

### ✅ How Styling Works Instead

Styling is done in **JavaScript** using:

- Inline styles via props
    
- `StyleSheet` objects
    

Key points:

- Styles are written in JavaScript
    
- Style properties look similar to CSS
    
- Only a **subset of CSS** is supported
    
- All essential styling features are available
    

---

## 🧠 StyleSheet Object

- `StyleSheet` is provided by React Native
    
- Used to define reusable style objects
    
- Styles are passed to components via the `style` prop
    

You will explore styling in depth later.

## 🌳 The `App` Component

- `App.js` contains the **root component**
    
- This component has a **special role**:
    
    - It is automatically rendered by Expo
        
    - It is the entry point of the UI
        

Important rule:

- All UI elements must be:
    
    - Inside `App`
        
    - Or inside children / descendants of `App`
        

This structure will be expanded later.
