# 📱 React Native — Making Lists Scrollable with ScrollView

## Core problem: View is NOT scrollable by default

In React Native, a normal `View` does not scroll — even if its content exceeds the screen height.

Example:

```jsx
<View>
  {/* many items */}
</View>
```

If the content becomes taller than the screen, it will simply overflow and be cut off.  
Unlike web browsers, React Native does **not automatically enable scrolling**.

On the web:

```
Content overflow → browser automatically allows scrolling
```

In React Native:

```
Content overflow → nothing happens unless you use ScrollView
```

---

# Solution: Use ScrollView

React Native provides a built-in component called `ScrollView`.

Import it:

```js
import { ScrollView } from 'react-native';
```

Use it as a container around the content you want to scroll:

```jsx
<ScrollView>
  {courseGoals.map(goal => (
    <View key={goal}>
      <Text>{goal}</Text>
    </View>
  ))}
</ScrollView>
```

Now the list becomes scrollable when it exceeds available space.

---

# Important layout detail: ScrollView must be inside a container with defined height

If you replace your layout incorrectly like this:

```jsx
<ScrollView style={styles.goalsContainer}>
  {/* goals */}
</ScrollView>
```

It breaks the layout proportions.

Why?

Because ScrollView itself doesn’t control how much screen space it gets.  
The parent container must define that space.

Correct structure:

```jsx
<View style={styles.goalsContainer}>
  <ScrollView>
    {/* goals */}
  </ScrollView>
</View>
```

Explanation:

- Outer `View` → controls layout and space (using flex)
    
- Inner `ScrollView` → makes content scrollable inside that space
    

Mental model:

```
View = defines area size
ScrollView = makes that area scrollable
```

---

# How flex interacts with ScrollView

Previously:

```jsx
goalsContainer: {
  flex: 4
}
```

This gives the goals area most of the screen height.

Now structure becomes:

```jsx
<View style={styles.goalsContainer}>
  <ScrollView>
    {/* goals */}
  </ScrollView>
</View>
```

So:

- View controls height using flex
    
- ScrollView enables scrolling within that height
    

---

# ScrollView only scrolls when content exceeds available height

If you have few items:

```
Not enough content → no scrolling
```

If you add many items:

```
Content exceeds height → scrolling becomes active
```

This is expected behavior.

---

# ScrollView configuration example: disabling bounce effect (iOS)

By default, iOS ScrollView has a bounce effect.

You can disable it:

```jsx
<ScrollView alwaysBounceVertical={false}>
```

Effect:

- No bounce if content does not exceed container height
    
- Scroll still works normally when content exceeds height
    

This is platform-specific behavior (mostly iOS).

---

# Final structure used in this app

```jsx
<View style={styles.goalsContainer}>
  <ScrollView>
    {courseGoals.map(goal => (
      <View key={goal} style={styles.goalItem}>
        <Text style={styles.goalText}>{goal}</Text>
      </View>
    ))}
  </ScrollView>
</View>
```

---

# Key takeaways

- `View` is not scrollable by default
    
- Use `ScrollView` to enable scrolling
    
- Wrap ScrollView inside a container View that defines layout space
    
- ScrollView only scrolls when content exceeds available height
    
- ScrollView has many configuration props (bounce, scroll direction, etc.)
