# 📱 React Native — Using Modal for Input (Overlay UI + Visibility State)

## 🎯 Goal of this improvement

To improve the UX, the input area (TextInput + Buttons) is moved into a **Modal**.

A **Modal** is an overlay that appears on top of the screen (often sliding up or fading in) to let the user perform an action, then disappear.

---

## 🧠 Modal basics in React Native

React Native provides a built-in component:

```
Modal
```

You use it by:

1. Importing it from `react-native`
    
2. Wrapping the content that should appear inside the modal
    

Example idea:

```
<Modal>
  <View>...input stuff...</View>
</Modal>
```

⚠️ If you do this with no control, the modal covers the whole app **all the time**.

---

# ✅ The correct approach: control Modal visibility with state

We need a boolean state:

- `true` → modal is shown
    
- `false` → modal is hidden
    

This state belongs in **App.js** because it controls overall UI flow.

---

## 1) Add a button to open the modal (App.js)

In `App.js`, above `<GoalInput />`, add a built-in Button:

- Title: “Add New Goal”
    
- Color: same purple as your goal items
    
- Uses `onPress`
    

Important note about `Button`:

- It does **not** support `style`
    
- Only supports simple props like `color`
    
- For full customization, build a custom button with `Pressable`
    

---

## 2) Add state to control modal visibility (App.js)

Create a state variable:

- starts `false`
    
- toggled to `true` when pressing “Add New Goal”
    

Example behavior:

```
modalIsVisible = false  // initial
press button → modalIsVisible = true
```

---

## 3) Add a handler that opens the modal

Create a function like:

- `startAddGoalHandler()`
    
- sets modal state to `true`
    

Then connect it:

```
<Button onPress={startAddGoalHandler} />
```

---

# ⚠️ Avoid conditionally rendering GoalInput just to show/hide the modal

You _could_ do this:

```
{modalIsVisible && <GoalInput />}
```

But it’s not the best approach here because:

- Modal has built-in features that are better
    
- Modal provides its own visibility control + animation options
    

---

# ✅ Better approach: Use Modal props (visible + animation)

`Modal` provides:

### `visible`

- `true` → shown
    
- `false` → hidden
    

### `animationType`

- `"none"`
    
- `"fade"`
    
- `"slide"` ✅ (used here)
    

So inside `GoalInput.js`, the modal becomes:

- controlled by a prop passed from App
    

---

## 4) Pass visibility to GoalInput via props

In `App.js`:

- pass something like:
    

```
<GoalInput visible={modalIsVisible} />
```

(Prop name is your choice, but `visible` is clean and matches Modal’s prop.)

---

## 5) Use props.visible inside GoalInput’s Modal

In `GoalInput.js`:

- set the modal’s `visible` based on `props.visible`
    
- add `animationType="slide"`
    

Result:

- When user taps “Add New Goal”
    
- `modalIsVisible` becomes `true`
    
- Modal slides up automatically ✅
