# 📱 React Native — Pressable Styling & Visual Feedback (android_ripple & pressed state)

## 🎯 Concept

When users press an item, they should get **visual feedback**.

Without feedback, the UI feels broken or unresponsive.

React Native provides two main ways to add press feedback:

|Platform|Method|
|---|---|
|Android|android_ripple|
|iOS|style function with pressed state|

---

# 🤖 Android — Using android_ripple

Android provides a built-in ripple effect.

This creates a wave-like animation when pressing.

---

## Basic usage

```
<Pressable
   android_ripple={{ color: "#dddddd" }}
   onPress={handler}
>
   <Text>Goal Item</Text>
</Pressable>
```

Result:

```
User presses → ripple animation appears
```

---

## Example with darker ripple

```
android_ripple={{ color: "#6d6d6d" }}
```

You can customize color using HEX.

---

# ⚠️ Important: Ripple applies only to Pressable area

Example:

Wrong structure:

```
<Pressable>
   <View style={styles.container}>
      <Text>Goal</Text>
   </View>
</Pressable>
```

Ripple may not cover full container.

Better structure:

```
<View style={styles.container}>
   <Pressable>
      <Text style={styles.text}>Goal</Text>
   </Pressable>
</View>
```

Padding should be inside Pressable.

---

# 🍎 iOS — android_ripple does NOT work

iOS does not support ripple effect.

Instead, use style function with pressed state.

---

# 🧠 Using Pressable style function

Pressable supports dynamic styling based on press state.

```
<Pressable
   style={({ pressed }) => pressed && styles.pressedItem}
>
   <Text>Goal Item</Text>
</Pressable>
```

---

# 🧠 What is pressed?

Pressable automatically provides:

```
pressed = true   → when user presses
pressed = false  → when released
```

---

# 📦 Example styles

```
const styles = StyleSheet.create({

   pressedItem: {
      opacity: 0.5
   }

});
```

Result:

```
Pressed → item becomes transparent
Released → returns to normal
```

---

# 📊 Press lifecycle

```
User touches item
      │
      ▼
pressed = true
      │
      ▼
style applied
      │
      ▼
User releases
      │
      ▼
pressed = false
      │
      ▼
style removed
```

---

# 🧪 Full Cross-Platform Example

```
<Pressable
   android_ripple={{ color: "#210644" }}
   style={({ pressed }) =>
      pressed ? styles.pressedItem : null
   }
   onPress={props.onDeleteItem.bind(this, props.id)}
>

   <View style={styles.goalItem}>
      <Text style={styles.goalText}>
         {props.text}
      </Text>
   </View>

</Pressable>
```

---

# 📦 Styles

```
const styles = StyleSheet.create({

   goalItem: {
      margin: 8,
      backgroundColor: "#5e0acc",
      borderRadius: 6
   },

   goalText: {
      color: "white",
      padding: 8
   },

   pressedItem: {
      opacity: 0.5
   }

});
```

# 📊 Visual Feedback Comparison

|Platform|Feedback|
|---|---|
|Android|Ripple animation|
|iOS|Opacity change|
|Both|Better UX|

---

# 💡 Best Practice — Support both platforms

Always use BOTH:

```
android_ripple
```

AND

```
style={({pressed}) => ...}
```

This ensures:

- Android → ripple
    
- iOS → opacity feedback
    

---

# 🧠 Alternative styling options

Instead of opacity, you can change:

Background color:

```
pressedItem: {
   backgroundColor: "#210644"
}
```

Scale:

```
pressedItem: {
   transform: [{ scale: 0.98 }]
}
```

Opacity + color:

```
pressedItem: {
   opacity: 0.5,
   backgroundColor: "#210644"
}
```

---

# 🚨 Common mistakes

### ❌ Using only android_ripple

No feedback on iOS.

---

### ❌ Not using style function

Static style won't change on press.

---

### ❌ Putting padding outside Pressable

Ripple won't cover full area.

---

# 🧠 Professional Pressable structure

```
<View style={styles.goalItem}>

   <Pressable
      android_ripple={{ color: "#210644" }}
      style={({pressed}) =>
         pressed && styles.pressedItem
      }
   >

      <Text style={styles.goalText}>
         Goal
      </Text>

   </Pressable>

</View>
```

---

# 🧠 Summary

Pressable provides visual feedback.

Android:

```
android_ripple={{ color }}
```

iOS:

```
style={({pressed}) => styles.pressedItem}
```

pressed property allows dynamic styling.

Best practice:

Use both methods for cross-platform feedback.

This ensures professional and responsive UI.
