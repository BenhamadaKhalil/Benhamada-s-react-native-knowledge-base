# 📱 React Native — Styling Basics (Inline Styles & StyleSheet)

## 🎯 Objective

Learn how styling works in React Native, including:

- How to apply styles
    
- Difference between CSS and React Native styling
    
- Inline styling vs StyleSheet styling
    
- Why StyleSheet is the recommended approach
    

---

# 🧠 Core Concept: No CSS in React Native

Unlike React (web), React Native **does NOT use CSS files**.

❌ Not supported:

```css
.container {
  margin: 10px;
}
```

❌ Not supported:

```js
import "./styles.css";
```

✅ Instead, React Native uses **JavaScript objects for styling**.

---

# 🎨 How Styling Works in React Native

React Native uses the `style` prop.

Example:

```jsx
<Text style={{ margin: 16 }}>
  Hello World
</Text>
```

Here:

- `style` receives a JavaScript object
    
- Each property defines a style
    

---

# 🧩 React Native Styles vs CSS

React Native styles are:

- Inspired by CSS
    
- But NOT identical
    
- Only a subset of CSS exists
    
- Property names may differ
    

Example comparison:

|CSS|React Native|
|---|---|
|margin: 16px|margin: 16|
|border: 1px solid red|borderWidth: 1, borderColor: 'red'|
|padding: 10px|padding: 10|

⚠️ Notice:

- No `px`
    
- Values are numbers, not strings (usually)
    

---

# 📏 Units in React Native

Example:

```jsx
margin: 16
```

Means:

```
16 device-independent pixels
```

React Native automatically adjusts to screen density.

---

# 🎨 Example: Adding Margin, Border, Padding

```jsx
<Text style={{
  margin: 16,
  borderWidth: 2,
  borderColor: 'red',
  padding: 16
}}>
  Hello World
</Text>
```

Result:

- Margin → space outside element
    
- Border → red border
    
- Padding → space inside element
    

---

# ⚠️ Important Difference: border property DOES NOT exist

❌ Invalid:

```jsx
border: '1px solid red'
```

✅ Correct:

```jsx
borderWidth: 1,
borderColor: 'red'
```

React Native separates border properties.

---

# 🧠 Two Ways to Apply Styles

## Method 1: Inline Styles (Allowed but not recommended)

Example:

```jsx
<Text style={{
  margin: 16,
  padding: 16,
  borderWidth: 2,
  borderColor: 'red'
}}>
  Hello
</Text>
```

Problem:

- Not reusable
    
- Hard to maintain
    
- Code duplication
    

---

## Method 2: StyleSheet Object (Recommended ✅)

This is the best practice.

---

# 📦 What is StyleSheet?

StyleSheet is a React Native API used to define styles.

Import:

```jsx
import { StyleSheet } from 'react-native';
```

Create styles:

```jsx
const styles = StyleSheet.create({
  dummyText: {
    margin: 16,
    padding: 16,
    borderWidth: 2,
    borderColor: 'red'
  }
});
```

Use styles:

```jsx
<Text style={styles.dummyText}>
  Hello World
</Text>
```

---

# 🧠 Why use StyleSheet instead of inline styles?

## Advantage 1: Reusability

Use same style everywhere:

```jsx
<Text style={styles.dummyText}>Text 1</Text>
<Text style={styles.dummyText}>Text 2</Text>
```

---

## Advantage 2: Cleaner Code

Bad:

```jsx
<Text style={{ margin:16, padding:16, borderWidth:2 }}>Text</Text>
```

Good:

```jsx
<Text style={styles.dummyText}>Text</Text>
```

---

## Advantage 3: Easier Maintenance

Change once:

```jsx
borderColor: 'blue'
```

All components update automatically.

---

## Advantage 4: Better Developer Experience

StyleSheet provides:

- Auto-completion
    
- Error checking
    
- Cleaner structure
    

---

# ⚙️ How StyleSheet Works Internally

```jsx
const styles = StyleSheet.create({...})
```

Creates an optimized style object.

Then used like:

```jsx
style={styles.dummyText}
```

React Native applies styles efficiently.

---

# 🧠 Mental Model (VERY IMPORTANT)

Think of React Native styling like this:

```
React Web:
HTML + CSS

React Native:
Components + JavaScript Style Objects
```

NOT:

```
React Native ≠ CSS
React Native = JavaScript styling system
```

---

# 💡 Best Practices

✅ Always use StyleSheet for real apps

✅ Keep styles separate from JSX

✅ Reuse styles

✅ Use numbers, not px

---

# ⚠️ Common Mistakes

❌ Using CSS syntax:

```jsx
border: "1px solid red"
```

❌ Using px:

```jsx
margin: "16px"
```

❌ Using inline styles everywhere

---

# 📝 Summary

React Native styling:

- Uses JavaScript objects
    
- No CSS files
    
- Applied using `style` prop
    
- Two methods:
    
    - Inline styles ❌ (not recommended)
        
    - StyleSheet ✅ (recommended)
        

StyleSheet allows:

- Reusable styles
    
- Cleaner code
    
- Easier maintenance
