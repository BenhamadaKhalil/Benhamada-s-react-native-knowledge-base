# 📱 React Native — Deep Dive into Flexbox (Main Axis, Cross Axis, flex, alignItems, justifyContent)

## 🎯 What is Flexbox really?

Flexbox is the **system React Native uses to position and size elements inside containers**.

Very important fact:

> Every `View` in React Native uses Flexbox automatically — even if you don’t add any Flexbox styles.

This means this code already uses Flexbox:

```jsx
<View>
  <View><Text>1</Text></View>
  <View><Text>2</Text></View>
  <View><Text>3</Text></View>
</View>
```

You don’t need to enable it.

This is different from web CSS, where you must write:

```css
display: flex;
```

In React Native, Flexbox is always ON.

---

# 🧠 Default behavior of Flexbox in React Native

By default, Flexbox uses:

```jsx
flexDirection: 'column'
```

This means children are placed vertically.

Example:

```jsx
<View>
  <Box1 />
  <Box2 />
  <Box3 />
</View>
```

Layout:

```
Box1
Box2
Box3
```

Top → Bottom

---

# 🧭 Core Concept: Main Axis and Cross Axis

Flexbox always works with two axes:

```
Main Axis
Cross Axis
```

The main axis depends on flexDirection.

---

## Case 1: flexDirection: 'column'

```jsx
flexDirection: 'column'
```

Main Axis:

```
↓ Vertical
```

Cross Axis:

```
→ Horizontal
```

Visualization:

```
Main Axis
↓
Box1
Box2
Box3

Cross Axis →
```

---

## Case 2: flexDirection: 'row'

```jsx
flexDirection: 'row'
```

Main Axis:

```
→ Horizontal
```

Cross Axis:

```
↓ Vertical
```

Visualization:

```
Box1   Box2   Box3
→ Main Axis

↓ Cross Axis
```

---

# 🧠 Mental Model (EXTREMELY IMPORTANT)

Main Axis = direction elements flow  
Cross Axis = perpendicular direction

Think:

```
flexDirection decides element flow direction
```

---

# 📦 Example: Changing layout direction

Code:

```jsx
container: {
  flexDirection: 'row'
}
```

Result:

Before:

```
1
2
3
```

After:

```
1   2   3
```

---

# 🔄 Reverse directions

Flexbox also supports reverse directions.

```jsx
flexDirection: 'row-reverse'
```

Result:

```
3   2   1
```

And:

```jsx
flexDirection: 'column-reverse'
```

Result:

```
3
2
1
```

---

# 📏 Default size behavior of Flexbox children

By default, children only take as much space as needed.

Example:

```jsx
<View>
  <View><Text>1</Text></View>
</View>
```

Result:

```
Small box around "1"
```

Because size = content size.

Flexbox does NOT automatically stretch children along main axis.

---

# 📏 Important: Parent controls cross-axis stretching

Example parent:

```jsx
container: {
  height: 300,
  flexDirection: 'row'
}
```

Result:

Children stretch vertically (cross axis):

```
| Box | Box | Box |
|     |     |     |
|     |     |     |
```

Because default:

```jsx
alignItems: 'stretch'
```

---

# 📐 justifyContent — controls position on MAIN AXIS

Since main axis depends on flexDirection, justifyContent works in that direction.

Example:

```jsx
flexDirection: 'row',
justifyContent: 'center'
```

Result:

```
    Box1 Box2 Box3
```

Centered horizontally.

---

Example:

```jsx
justifyContent: 'space-between'
```

Result:

```
Box1       Box2       Box3
```

Spread across container.

---

# 📐 alignItems — controls position on CROSS AXIS

Example:

```jsx
alignItems: 'center'
```

Result:

```
     Box
     Box
     Box
```

Centered vertically (if row layout).

---

Example:

```jsx
alignItems: 'stretch'
```

Result:

Boxes stretch to full cross-axis size.

This is default behavior.

---

# 📏 The flex property (MOST IMPORTANT PROPERTY)

flex is applied to children.

It controls how much space a child takes along the main axis.

Example:

```jsx
box1: {
  flex: 1
}
```

Means:

```
Take all available space
```

---

Example:

```jsx
box1: { flex: 1 }
box2: { flex: 1 }
```

Result:

Both share space equally.

```
| box1 | box2 |
```

50% each.

---

Example:

```jsx
box1: { flex: 1 }
box2: { flex: 2 }
```

Result:

box2 takes twice more space than box1.

```
| box1 |     box2     |
```

Ratio:

```
1 : 2
```

---

# 📊 How flex distribution works internally

Example:

```jsx
box1: flex 1
box2: flex 2
box3: flex 3
```

Total flex units:

```
1 + 2 + 3 = 6
```

Space distribution:

```
box1 = 1/6
box2 = 2/6
box3 = 3/6
```

---

# 🧠 Real example from instructor (Red, Blue, Green boxes)

```jsx
container: {
  flexDirection: 'row'
}

redBox: {
  flex: 1
}

blueBox: {
  flex: 2
}

greenBox: {
  flex: 1
}
```

Result:

```
| Red |     Blue     | Green |
```

Blue is twice larger than red and green.

---

# 📦 Flexbox works on nested Views too

Example:

```jsx
<View style={outerContainer}>

  <View style={box}>
    <Text>1</Text>
  </View>

</View>
```

Inner View also uses Flexbox automatically.

This is how content is centered:

```jsx
box: {
  justifyContent: 'center',
  alignItems: 'center'
}
```

Result:

```
   1
```

Centered vertically and horizontally.

---

# 🧠 Extremely Important Mental Model (REMEMBER THIS FOREVER)

Flexbox has 2 control levels:

Level 1 — Parent controls:

- Direction → flexDirection
    
- Main axis positioning → justifyContent
    
- Cross axis positioning → alignItems
    

Level 2 — Child controls:

- Space taken → flex
    

---

# 🧱 Real-world analogy

Parent = shelf  
Children = books

Parent decides:

- Stack vertically or horizontally
    
- Spacing between books
    

Books decide:

- How much space they occupy
    

---

# 🧠 Most important Flexbox properties summary

Parent properties:

```
flexDirection
justifyContent
alignItems
```

Child property:

```
flex
```

# 🚨 Key takeaway

Flexbox is the foundation of ALL layouts in React Native.

Everything is built using:

```
View (container)
+
Flexbox properties
```

Without Flexbox, layout control is impossible.
