# 📱 React Native — Flexbox in Practice (Input + Button Layout)

## 🎯 What problem are we solving?

We want this layout:

```
[ TextInput          ][ Button ]
```

But by default, React Native gives us:

```
[ TextInput          ]
[ Button             ]
```

Why? Because React Native uses Flexbox with default:

```
flexDirection: 'column'
```

Which means:

```
Stack vertically
```

We must change it to horizontal layout.

---

## 🧠 Core Principle: Flexbox is applied to the container

This is the most important rule:

> Flexbox properties are applied to the parent container to control its children.

Example:

```jsx
<View style={styles.inputContainer}>
  <TextInput />
  <Button />
</View>
```

Here:

- View = container
    
- TextInput and Button = children
    

We control layout by styling the View.

---

## ✅ Step 1: Make elements horizontal using flexDirection

Create style:

```jsx
inputContainer: {
  flexDirection: 'row'
}
```

Apply:

```jsx
<View style={styles.inputContainer}>
```

---

## 🔍 What happens internally?

Default behavior:

```
flexDirection: 'column'
```

Layout:

```
TextInput
Button
```

After changing:

```jsx
flexDirection: 'row'
```

Layout becomes:

```
TextInput    Button
```

Because now the main axis is horizontal.

---

## 🧠 Mental Model

Think of flexDirection like telling the container:

```
"Place children vertically"
or
"Place children horizontally"
```

column → vertical  
row → horizontal

---

## ✅ Step 2: Control spacing using justifyContent

Now maybe elements are too close or badly positioned.

Add:

```jsx
inputContainer: {
  flexDirection: 'row',
  justifyContent: 'space-between'
}
```

---

## 🔍 What justifyContent does

It controls spacing along the main axis.

Since main axis is horizontal, it controls horizontal spacing.

Result:

```
TextInput               Button
```

Instead of:

```
TextInput Button
```

---

## ✅ Step 3: Control TextInput width

Without width, TextInput and Button fight for space.

We want TextInput to take most of the space.

Create style:

```jsx
textInput: {
  width: '80%'
}
```

Apply:

```jsx
<TextInput style={styles.textInput} />
```

---

## 🔍 What happens internally?

Container width = 100%

TextInput takes:

```
80%
```

Button takes remaining:

```
20%
```

Layout:

```
| TextInput (80%) | Button (20%) |
```

---

## ⚠️ Important rule: percentage must be string

Correct:

```jsx
width: '80%'
```

Wrong:

```jsx
width: 80%
```

Wrong:

```jsx
width: 80
```

---

## ✅ Step 4: Add border for visual clarity

```jsx
textInput: {
  borderWidth: 1,
  borderColor: '#cccccc'
}
```

This helps user see input area.

---

## ✅ Step 5: Add margin for spacing between input and button

```jsx
marginRight: 8
```

Without margin:

```
TextInput|Button
```

With margin:

```
TextInput   Button
```

---

## ✅ Step 6: Add padding inside TextInput

```jsx
padding: 8
```

Without padding:

```
|Text|
```

With padding:

```
| Text |
```

Much better user experience.

---

## 🧠 Final Code (Goal App Input Layout)

```jsx
const styles = StyleSheet.create({

  inputContainer: {
    flexDirection: 'row',
    justifyContent: 'space-between'
  },

  textInput: {
    borderWidth: 1,
    borderColor: '#cccccc',
    width: '80%',
    marginRight: 8,
    padding: 8
  }

});
```

Usage:

```jsx
<View style={styles.inputContainer}>
  <TextInput
    style={styles.textInput}
    placeholder="Your course goal"
  />
  <Button title="Add Goal" />
</View>
```

---

## 🧠 Real-world analogy

Container = table  
TextInput + Button = objects on table

flexDirection: 'column' →

Objects stacked vertically.

flexDirection: 'row' →

Objects placed side by side.
