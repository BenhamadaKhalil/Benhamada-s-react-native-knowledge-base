# 📱 React Native — Creating GoalInput Component & Passing Functions via Props

## 🎯 Concept

As apps grow, you split functionality into multiple components.

In this case, we move the **input logic and UI** from `App.js` into a new component:

```
GoalInput.js
```

This component handles:

- Text input
    
- Button press
    
- Input state
    

But the main goals list state stays in:

```
App.js
```

This introduces an important concept:

> Child components can communicate with parent components using function props.

---

# 📁 Final Component Architecture

```
App.js
│
├ GoalInput.js     → handles input
│
├ FlatList
     │
     ├ GoalItem.js → displays item
```

Responsibilities:

|Component|Responsibility|
|---|---|
|App.js|Manages goals list state|
|GoalInput.js|Handles user input|
|GoalItem.js|Displays individual goal|

# 🧠 Step 1 — Create GoalInput component

GoalInput.js:

```
import { View, TextInput, Button, StyleSheet } from "react-native";

function GoalInput() {
   return (
      <View style={styles.inputContainer}>
         <TextInput style={styles.textInput} />
         <Button title="Add Goal" />
      </View>
   );
}

export default GoalInput;
```

---

# 🧠 Step 2 — Move input state into GoalInput

Before (wrong place):

```
App.js
```

After (correct place):

```
GoalInput.js
```

```
import { useState } from "react";

function GoalInput() {
   const [enteredGoalText, setEnteredGoalText] = useState("");

   function goalInputHandler(text) {
      setEnteredGoalText(text);
   }
}
```

Reason:

The TextInput exists in GoalInput, so its state should also exist there.

---

# 🧠 Step 3 — Bind state to TextInput (Controlled Component)

```
<TextInput
   style={styles.textInput}
   value={enteredGoalText}
   onChangeText={goalInputHandler}
/>
```

This creates two-way binding.

Flow:

```
User types → state updates → UI updates
State changes → UI updates
```

---

# 🧠 Step 4 — Pass function from parent to child via props

App.js:

```
<GoalInput onAddGoal={addGoalHandler} />
```

This passes the function.

---

# 🧠 Step 5 — Receive function in child

GoalInput.js:

```
function GoalInput(props) {

}
```

Access function:

```
props.onAddGoal()
```

---

# 🧠 Step 6 — Call parent function from child and pass data

GoalInput.js:

```
function addGoalHandler() {
   props.onAddGoal(enteredGoalText);
   setEnteredGoalText("");
}
```

Connect to button:

```
<Button title="Add Goal" onPress={addGoalHandler} />
```

# 🧪 Final Code Example

## GoalInput.js

```
import { useState } from "react";
import { View, TextInput, Button, StyleSheet } from "react-native";

function GoalInput(props) {

   const [enteredGoalText, setEnteredGoalText] = useState("");

   function goalInputHandler(text) {
      setEnteredGoalText(text);
   }

   function addGoalHandler() {
      props.onAddGoal(enteredGoalText);
      setEnteredGoalText("");
   }

   return (
      <View style={styles.inputContainer}>
         <TextInput
            style={styles.textInput}
            value={enteredGoalText}
            onChangeText={goalInputHandler}
         />
         <Button title="Add Goal" onPress={addGoalHandler} />
      </View>
   );
}

export default GoalInput;
```

---

## App.js

```
<GoalInput onAddGoal={addGoalHandler} />
```

# 🧠 Important Concept: Lifting State Up

Definition:

Moving state to parent so multiple components can use it.

In this case:

```
goals state → App.js
input state → GoalInput.js
```

GoalInput sends data → App.js updates goals

---

# 🔁 Function Prop Communication Flow

```
App.js
 passes function
      ▼
GoalInput.js
 calls function with data
      ▼
App.js updates state
```

This is standard React pattern.

# 🚨 Common mistakes

### ❌ Keeping input state in App.js

Wrong architecture.

State should be close to component using it.

---

### ❌ Forgetting value prop on TextInput

Without value:

```
<TextInput onChangeText={handler} />
```

State reset won't update UI.

Correct:

```
<TextInput value={enteredGoalText} />
```

---

### ❌ Calling parent function without passing data

Wrong:

```
props.onAddGoal()
```

Correct:

```
props.onAddGoal(enteredGoalText)
```

---

# 🧠 Controlled Component Concept

TextInput is controlled by state:

```
State → controls UI
UI → updates state
```

This ensures synchronization.
