# 📱 React Native — Props & Passing Data to Custom Components

## 🎯 Concept

When using custom components, they often need **data from parent components**.

This is done using **props**.

Props allow you to:

- Pass data
    
- Pass values
    
- Pass functions
    
- Communicate between components
    

Flow direction:

```
Parent → Child
(App.js → GoalItem.js)
```

---

# 🧠 What are Props?

Props = properties passed to components.

Example:

```
<GoalItem text="Learn React Native" />
```

Here:

```
text = prop
"Learn React Native" = prop value
```

---

# 📦 Step 1 — Passing props from parent (App.js)

Inside FlatList:

```
renderItem={(itemData) => (
   <GoalItem text={itemData.item.text} />
)}
```

Explanation:

```
itemData.item.text
```

contains goal text.

We pass it as prop named `text`.

---

# 📥 Step 2 — Receiving props in child component

GoalItem.js:

```
function GoalItem(props) {
   return (
      <View>
         <Text>{props.text}</Text>
      </View>
   );
}

export default GoalItem;
```

props.text now contains the value passed from App.js.

---

# 📊 Props Flow Diagram

```
App.js
 │
 │ passes prop
 ▼
<GoalItem text="Learn React Native" />
 │
 ▼
GoalItem.js
 │
 ▼
props.text = "Learn React Native"
```

---

# ⚡ Cleaner syntax using destructuring (Recommended)

Instead of:

```
function GoalItem(props) {
   return <Text>{props.text}</Text>;
}
```

Use:

```
function GoalItem({ text }) {
   return <Text>{text}</Text>;
}
```

This is modern and cleaner.

---

# 🚨 VERY IMPORTANT — Import React Native components

Unlike React web, React Native components MUST be imported.

Wrong ❌

```
function GoalItem(props) {
   return (
      <View>
         <Text>{props.text}</Text>
      </View>
   );
}
```

This crashes because View and Text are not imported.

Correct ✅

```
import { View, Text, StyleSheet } from "react-native";

function GoalItem({ text }) {
   return (
      <View>
         <Text>{text}</Text>
      </View>
   );
}
```

---

# ⚠️ Difference between React Web and React Native

React Web:

```
<div>
<h1>
```

No import needed.

React Native:

```
<View>
<Text>
```

Must import:

```
import { View, Text } from "react-native";
```

Because they are components, not HTML elements.

## GoalItem.js

```
import { View, Text, StyleSheet } from "react-native";

function GoalItem({ text }) {
   return (
      <View style={styles.goalItem}>
         <Text style={styles.goalText}>{text}</Text>
      </View>
   );
}

export default GoalItem;

const styles = StyleSheet.create({
   goalItem: {
      padding: 10,
      backgroundColor: "#5e0acc",
      margin: 8
   },
   goalText: {
      color: "white"
   }
});
```

# 💡 Why props are important

Props allow:

- Dynamic UI
    
- Reusable components
    
- Data flow between components
    

Example:

```
<GoalItem text="Learn React Native" />
<GoalItem text="Build apps" />
<GoalItem text="Get job" />
```

Same component, different data.

---

# 🧠 Parent vs Child relationship

```
Parent Component
(App.js)
   │
   │ passes props
   ▼
Child Component
(GoalItem.js)
```

Parent controls data.

Child displays data.

---

# 🚨 Common mistakes

### ❌ Forgetting to pass prop

```
<GoalItem />
```

Result: undefined value

---

### ❌ Forgetting to import View and Text

Causes crash:

```
Can't find variable View
```

---

### ❌ Using wrong property name

Example:

```
props.value
```

But passed:

```
text
```

Must match names.

---

# 🧠 Summary

Props allow passing data between components.

Flow:

```
Parent → Child
```

Steps:

1. Pass prop
    

```
<GoalItem text="Goal" />
```

2. Receive prop
    

```
function GoalItem(props)
```

3. Use prop
    

```
props.text
```

Props are essential for building dynamic and reusable React Native apps.
