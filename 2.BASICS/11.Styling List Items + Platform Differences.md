# 📱 React Native — Styling List Items + Platform Differences (iOS vs Android) + No CSS Inheritance

## 🎯 What we’re improving

We can render goals as a list, but it looks plain.  
Now we want each goal item to look like a “real list item”:

- spacing around each item
    
- padding inside
    
- rounded corners
    
- colored background
    
- readable text color
    

---

# 1) Styling each goal item

We create a new style entry in the `StyleSheet` for list items, e.g. `goalItem`.

Instructor’s styles (with the same ideas):

```js
goalItem: {
  margin: 8,
  padding: 8,
  borderRadius: 6,
  backgroundColor: '#5e0acc',
  color: 'white'
}
```

### What each property means (in this context)

- `margin: 8` → space **outside** each item (so items don’t stick together)
    
- `padding: 8` → space **inside** the item (so text isn’t stuck to the edge)
    
- `borderRadius: 6` → rounded corners (only visible if there’s a background)
    
- `backgroundColor: '#5e0acc'` → colored pill/card effect
    
- `color: 'white'` → intended to make text readable (but this will change later due to wrapper)
    

---

# 2) First attempt: applying style to `<Text>`

We might do:

```jsx
{courseGoals.map(goal => (
  <Text key={goal} style={styles.goalItem}>
    {goal}
  </Text>
))}
```

### What happens?

- On Android: looks correct (rounded corners appear)
    
- On iOS: **rounded corners missing**
    

So we discover a platform difference.

---

# 3) Why iOS behaves differently (important React Native reality)

React Native components are not “real HTML elements”.  
They are translated into **native UI components**:

- Android → one native text component
    
- iOS → another native text component
    

In this case:

- Android’s native text component seems to support rounded corners with background
    
- iOS’s native text component does **not** support border radius in the same way
    

So `borderRadius` on `Text` can behave differently across platforms.

---

# 4) Fix: Wrap Text inside a View, apply styling to the View

Instead of styling `Text`, we wrap it:

```jsx
{courseGoals.map(goal => (
  <View key={goal} style={styles.goalItem}>
    <Text>{goal}</Text>
  </View>
))}
```

### Why this works

`View` maps to a native container element on both platforms that supports:

✅ background color  
✅ border radius  
✅ spacing  
✅ consistent rendering

So now iOS shows rounded corners too.

---

# 5) New issue after wrapping: text is no longer white

The instructor points out a key difference from CSS:

## 🚨 React Native styles do NOT cascade / inherit like CSS

On the web, if a parent has:

```css
color: white;
```

children often inherit it automatically.

In React Native:

> Styles do not automatically inherit from parent View to child Text.

So if we keep `color: 'white'` inside `goalItem` (applied to `View`), it won’t affect the `<Text>`.

That’s why the text becomes default (black).

---

# 6) Fix: Create a separate `goalText` style for the Text

Move the text color to a `Text` style:

```js
goalItem: {
  margin: 8,
  padding: 8,
  borderRadius: 6,
  backgroundColor: '#5e0acc'
},
goalText: {
  color: 'white'
}
```

Then apply it to the `Text`:

```jsx
{courseGoals.map(goal => (
  <View key={goal} style={styles.goalItem}>
    <Text style={styles.goalText}>{goal}</Text>
  </View>
))}
```

✅ Now you get:

- Rounded corners on iOS and Android
    
- White text visible again
    

---

# 🧠 Mental models to remember forever

## Mental model 1: “Style must be applied to the component that supports it”

- `borderRadius` works reliably on `View`
    
- might be inconsistent on `Text` depending on platform
    

## Mental model 2: “No cascading”

- Styling a parent does **not** style children automatically
    
- Especially for things like `color`, `fontSize`, etc.
    

So:

✅ Put container styles on `View`  
✅ Put text styles on `Text`

# ⚠️ Important note about keys (ties to previous lesson)

Here they use:

```jsx

```

It works for now, but it’s not guaranteed unique if the same goal text is added twice. The course will improve this later (usually by adding ids).

---

## Key takeaways from this lecture

- Style list items using `StyleSheet`
    
- Some styles behave differently across iOS/Android
    
- `Text` may not support `borderRadius` consistently → use a wrapper `View`
    
- React Native styling is CSS-like but **not CSS**
    
- No inheritance/cascading → style `Text` directly for text color
