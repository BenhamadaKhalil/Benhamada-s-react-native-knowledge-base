---

## 🧱 View vs Text — Different Roles

React Native components have **strict responsibilities**.

### `Text`
Used for:
- Displaying text

Example concept:

```

Hello World

```

Only the `Text` component can display text.

---

### `View`
Used for:
- Layout
- Containers
- Grouping components

Example concept:



The `View` component is similar to a `div` in web development.

---

## ❌ Important Rule: Text Cannot Be Inside View Directly

This is invalid:

<View>
  Hello World
</View>


Error:


Text strings must be rendered within a Text component


Reason:

- `View` cannot render text
    
- It can only hold other components
    

Correct version:


<View>
  <Text>Hello World</Text>
</View>


---

## 🧩 Component Nesting

React Native allows nesting components.

Example structure:


<View>
  <Text>First text</Text>
  <Text>Second text</Text>
</View>


You can also nest Views:


<View>
  <View>
    <Text>Nested text</Text>
  </View>
</View>


This creates a UI hierarchy.

---

## 🧠 Mental Model

Think of components like this:

- View → container
    
- Text → displays text
    
- View groups components
    
- Text displays content
    

Hierarchy example:


App
 └── View
      ├── Text
      └── View
           └── Text

## 🧩 Other Core Components Exist

React Native provides additional components such as:

- `Button`
    
- `Image`
    
- `TextInput`
    
- Scroll-related components
    

Each component has a specific purpose.

---

## 🔘 Button Component

Unlike HTML buttons, React Native buttons:

- Must be imported manually
    
- Use a `title` prop instead of inner text
    
- Are self-closing
    

Example concept:

```
<Button title="Press me" />
```

Important differences from web:

Web:

```
<button>Press me</button>
```

React Native:

```
<Button title="Press me" />
```

---

## 📦 Importing Components Is Required

Unlike HTML elements, React Native components must be imported.

Example concept:

```
import { View, Text, Button } from 'react-native';
```

React Native does not provide components globally.

---

## 📱 Platform-Specific Rendering

React Native automatically adjusts components:

- iOS → native iOS button style
    
- Android → native Android button style
    

Same code → native appearance on each platform.

---

## 🧠 Core Principle: Component Composition

React Native UI is built by combining components:

```
Small components → combined → larger components → full UI
```

This is the foundation of React Native development.

---

## 🧠 Key Takeaways

- `Text` displays text
    
- `View` is a container component
    
- `View` cannot display text directly
    
- Text must always be wrapped in `Text`
    
- Components can be nested
    
- Components must be imported manually
    
- Button uses a `title` prop, not inner text
    
- React Native components render differently per platform
    
- UI is built by composing core components
