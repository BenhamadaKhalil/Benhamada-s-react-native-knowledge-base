# 📱 React Native — Closing the Modal (Add Goal + Cancel)

## 🎯 Goal

The modal is controlled by state in `App.js`:

- `modalIsVisible = true` → show modal
    
- `modalIsVisible = false` → hide modal
    

So to close the modal, we must **update the state in App.js** when the user taps:

- ✅ **Add Goal**
    
- ✅ **Cancel**
    

---

# 🧠 1) Add an “end” handler in App.js

You already have:

- `startAddGoalHandler()` → opens modal
    

Now add:

- `endAddGoalHandler()` → closes modal
    

Behavior:

```
endAddGoalHandler → setModalIsVisible(false)
```

This will hide the modal.

---

# 🧠 2) Close modal after “Add Goal”

When the user presses **Add Goal**, this already triggers:

- GoalInput → calls `props.onAddGoal(enteredGoalText)`
    
- which calls `addGoalHandler` in App.js
    

So the easiest way to close the modal after adding:

✅ inside `addGoalHandler` (App.js), also do:

- `setModalIsVisible(false)`
    
- OR call `endAddGoalHandler()`
    

So now:

```
Add Goal → adds item → closes modal
```

---

# 🧠 3) Close modal when “Cancel” is pressed

Cancel button is inside `GoalInput.js`, but the modal state is in `App.js`.

So we pass a function **from App.js to GoalInput.js** via props.

### In GoalInput.js

- Add `onPress` to the Cancel button
    
- Call a prop function like `props.onCancel`
    

Example logic:

```
<Button title="Cancel" onPress={props.onCancel} />
```

---

# 🧠 4) Provide onCancel prop in App.js

When rendering GoalInput:

- pass a new prop: `onCancel`
    
- value should be `endAddGoalHandler`
    

Example behavior:

```
<GoalInput onCancel={endAddGoalHandler} />
```

Now:

```
Cancel → calls endAddGoalHandler → modal closes
```

---

# ✅ Final Behavior Achieved

### Modal open

- Press “Add New Goal” button
    
- `startAddGoalHandler()` → `modalIsVisible = true`
    

### Modal close (Cancel)

- Press “Cancel”
    
- `endAddGoalHandler()` → `modalIsVisible = false`
    

### Modal close (Add Goal)

- Press “Add Goal”
    
- Goal is added
    
- Modal closes
    

Works on both:

- iOS ✅
    
- Android ✅
    

---

# 🧠 Key Pattern Used (Important)

This is the standard React pattern:

✅ **Parent holds state**  
✅ **Child triggers change via function props**

```
App.js (state owner)
   │
   ├ passes functions
   ▼
GoalInput.js (UI)
   │
   ├ calls parent functions on press
   ▼
App.js updates state → UI updates
```
