# 📱 React Native — Flexbox Basics (Core Layout System)

## 🎯 Objective

Understand the **Flexbox layout system**, which is the **most important layout mechanism in React Native**.

Flexbox controls:

- Position of elements
    
- Spacing between elements
    
- Layout direction (vertical or horizontal)
    
- How much space elements occupy
    

---

# 🧠 Core Concept: Flexbox = Layout Engine of React Native

Flexbox is a system used to **position and size elements inside containers**.

It works by applying styles to a **container**, which then controls its **children**.

Example:

```jsx
<View style={styles.container}>
  <Text>Item 1</Text>
  <Text>Item 2</Text>
</View>
```

The container controls layout of Item 1 and Item 2.

---

# 📦 Container vs Children Relationship

```
Container (View)
│
├── Child 1 (Text)
├── Child 2 (Text)
└── Child 3 (Text)
```

Flexbox styles are applied to:

```
Container → controls children layout
```

NOT directly to children (in most cases).

---

# 🧭 Main Concept: Axes in Flexbox

Flexbox works with 2 axes:

```
Main Axis
Cross Axis
```

Example visualization:

```
COLUMN layout:

Main Axis
↓
Item
Item
Item

Cross Axis →
```

---

# 📏 flexDirection — Controls Layout Direction

This is the MOST important Flexbox property.

Controls main axis direction.

---

## flexDirection: column (Default in React Native)

```jsx
flexDirection: 'column'
```

Layout:

```
Item 1
Item 2
Item 3
```

Main axis = vertical

---

## flexDirection: row

```jsx
flexDirection: 'row'
```

Layout:

```
Item 1   Item 2   Item 3
```

Main axis = horizontal

---

# ⚠️ IMPORTANT Difference from Web Flexbox

|Platform|Default flexDirection|
|---|---|
|React Native|column|
|Web CSS|row|

This is VERY important to remember.

---

# 📏 flex Property — Controls Space Occupation

Example:

```jsx
flex: 1
```

Means:

```
Take all available space
```

Example:

```jsx
<View style={{ flex: 1 }}>
  <Text>Hello</Text>
</View>
```

This View expands to fill screen.

---

# 📊 Example: Multiple Containers with flex

```jsx
<View style={{ flex: 1 }}>
  <View style={{ flex: 1, backgroundColor: 'red' }} />
  <View style={{ flex: 2, backgroundColor: 'blue' }} />
</View>
```

Result:

```
Red = 1 part
Blue = 2 parts

Blue is twice bigger
```

Ratio:

```
1 : 2
```

---

# 📐 justifyContent — Controls Position on Main Axis

Controls spacing between children.

Example:

```jsx
justifyContent: 'center'
```

Example layout:

```
(empty space)
Item
Item
(empty space)
```

Common values:

|Value|Result|
|---|---|
|flex-start|top / left|
|center|center|
|flex-end|bottom / right|
|space-between|space between elements|
|space-around|equal spacing|

---

# 📐 alignItems — Controls Position on Cross Axis

Controls horizontal alignment (if column layout).

Example:

```jsx
alignItems: 'center'
```

Layout:

```
   Item
   Item
   Item
```

Centered horizontally.

---

# 🧠 Mental Model (CRITICAL)

Flexbox works like this:

```
Container controls children layout
```

NOT:

```
Children control layout
```

Think:

```
Parent = Boss
Children = Workers
```

Parent decides:

- Direction
    
- Position
    
- Spacing
    

---

# 📊 Example Full Flexbox Layout

```jsx
<View style={{
  flex: 1,
  flexDirection: 'column',
  justifyContent: 'center',
  alignItems: 'center'
}}>
  <Text>Item 1</Text>
  <Text>Item 2</Text>
</View>
```

Result:

- Items centered vertically
    
- Items centered horizontally
    

---

# 💡 Why Flexbox is EXTREMELY Important

Flexbox is used for:

- Every layout
    
- Buttons next to inputs
    
- Navigation bars
    
- Lists
    
- Cards
    
- Entire screens
    

React Native layout = Flexbox

---

# ⚠️ Common Mistakes

❌ Forgetting default direction is column

❌ Applying Flexbox to children instead of container

❌ Not using flex: 1 when needed

---

# 📝 Summary

Flexbox is the core layout system in React Native.

Key properties:

- flexDirection → row or column
    
- flex → controls size ratio
    
- justifyContent → position on main axis
    
- alignItems → position on cross axis
    

Flexbox allows you to:

- Control layout direction
    
- Control spacing
    
- Control positioning
    
- Control element size
