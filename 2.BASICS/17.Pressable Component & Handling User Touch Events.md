# 📱 React Native — Pressable Component & Handling User Touch Events

## 🎯 Concept

In React Native, making elements clickable is different from React Web.

React Web uses:

```
onClick
```

React Native uses:

```
Pressable component
```

To make any element pressable, you must wrap it inside:

```
<Pressable>
```

---

# ⚠️ Why Pressable exists

React Native does not use HTML elements like:

```
<div>
<button>
```

Instead, it uses native mobile components.

To detect touch events, React Native provides special components like:

- Pressable ✅ (Recommended)
    
- TouchableOpacity ⚠️ (Old)
    
- TouchableHighlight ⚠️ (Old)
    
- TouchableNativeFeedback ⚠️ (Old)
    

Pressable is the modern solution.

---

# 🧠 Basic Pressable usage

Example:

```
import { Pressable, Text } from "react-native";

<Pressable onPress={() => console.log("Pressed!")}>
   <Text>Tap me</Text>
</Pressable>
```

When user taps → function executes.

---

# 📦 Making GoalItem pressable

GoalItem.js:

Before:

```
<View>
   <Text>{text}</Text>
</View>
```

After:

```
import { Pressable, View, Text } from "react-native";

<Pressable onPress={props.onDeleteItem}>
   <View>
      <Text>{props.text}</Text>
   </View>
</Pressable>
```

Now the entire item is pressable.

---

# 🧠 Pressable event flow

```
User taps item
     │
     ▼
Pressable detects press
     │
     ▼
onPress function executes
```

---

# 🧠 Step 1 — Create delete handler in App.js

App.js:

```
function deleteGoalHandler() {
   console.log("DELETE");
}
```

This function will later delete the goal.

---

# 🧠 Step 2 — Pass function via props

App.js:

```
<GoalItem
   text={itemData.item.text}
   onDeleteItem={deleteGoalHandler}
/>
```

This passes function to GoalItem.

---

# 🧠 Step 3 — Use function inside GoalItem

GoalItem.js:

```
function GoalItem(props) {

   return (
      <Pressable onPress={props.onDeleteItem}>
         <View>
            <Text>{props.text}</Text>
         </View>
      </Pressable>
   );
}
```

Now pressing GoalItem triggers deleteGoalHandler.

---

# 📊 Full Interaction Flow

```
User taps GoalItem
      │
      ▼
Pressable detects press
      │
      ▼
GoalItem calls props.onDeleteItem()
      │
      ▼
App.js deleteGoalHandler executes
```

# 🚨 Common mistakes

### ❌ Using onClick (React Web habit)

Wrong:

```
<View onClick={handler}>
```

Correct:

```
<Pressable onPress={handler}>
```

---

### ❌ Forgetting to pass function

Wrong:

```
<GoalItem />
```

Correct:

```
<GoalItem onDeleteItem={deleteGoalHandler} />
```

---

### ❌ Calling function instead of passing it

Wrong:

```
onPress={deleteGoalHandler()}
```

Correct:

```
onPress={deleteGoalHandler}
```

---

# 🧠 Pressable vs Button

Button:

```
<Button title="Click" onPress={handler} />
```

Pressable:

```
<Pressable onPress={handler}>
   <Text>Click</Text>
</Pressable>
```

Pressable is more customizable.

---

# 🧠 Summary

Pressable is used to detect touch events.

Steps:

1. Wrap element in Pressable
    
2. Add onPress prop
    
3. Pass function via props
    
4. Execute function on press
    

Pressable replaces old Touchable components and is the modern way to handle touch in React Native.
