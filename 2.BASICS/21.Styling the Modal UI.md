# 📱 React Native — Styling the Modal UI (Layout, Button Row, Spacing)

## 🎯 Goal

Inside `GoalInput` (Modal), improve layout:

- TextInput on top
    
- Two buttons below (Add + Cancel)
    
- Buttons side-by-side with spacing
    
- Better spacing/padding overall
    
- Prepare for closing the modal on Add/Cancel (next step)
    

---

# 🧠 1) Restructure the JSX inside GoalInput

### Before

- TextInput + one Button in the same row layout.
    

### After

- Keep TextInput alone
    
- Put buttons inside a **new container View** under the TextInput
    
- Add a second button: **Cancel**
    

Structure:

```
<Modal ...>
  <View style={styles.inputContainer}>
    <TextInput ... />

    <View style={styles.buttonContainer}>
      <View style={styles.button}>
        <Button title="Add Goal" ... />
      </View>

      <View style={styles.button}>
        <Button title="Cancel" ... />
      </View>
    </View>
  </View>
</Modal>
```

---

# 🎨 2) Update the outer container styles (inputContainer)

### Key changes

✅ `flex: 1`  
So the container takes the full Modal height.

✅ `flexDirection: "column"` is default  
So you can remove it (no need to set it).

✅ Center items properly  
Instead of spacing them across the whole screen:

- Change `justifyContent: "space-between"` → `justifyContent: "center"`
    

This prevents everything from being stretched.

---

# 🧠 3) Make the buttons sit next to each other

For the buttons wrapper View:

```
buttonContainer: {
  flexDirection: "row"
}
```

Then apply it:

```
<View style={styles.buttonContainer}>
```

---

# 🧠 4) “Styling Buttons” even though Button can’t be styled

React Native’s built-in `Button`:

- ❌ doesn’t accept `style`
    
- ✅ only accepts simple props like `color`
    

So to control width/margins/spacing:

✅ Wrap each `Button` inside a `View`  
Then style the wrapping View.

Example style:

```
button: {
  width: 100,
  marginHorizontal: 8
}
```

Alternative (responsive) approach:

```
button: {
  width: "40%",
  marginHorizontal: 8
}
```

---

# 📏 5) Add spacing between TextInput and Buttons

Add margin on button container:

```
buttonContainer: {
  flexDirection: "row",
  marginTop: 16
}
```

---

# 🧾 6) Make TextInput wider + clean margins

- Set TextInput width to full:
    

```
textInput: {
  width: "100%"
}
```

- Remove extra right spacing (e.g. `marginRight`) if it existed before, since it was needed for a row layout earlier but not anymore.
    

---

# 🧸 7) Add padding around modal content

To avoid elements touching screen edges, add padding to the main container:

```
inputContainer: {
  flex: 1,
  justifyContent: "center",
  padding: 16
}
```

- Better padding and overall layout
