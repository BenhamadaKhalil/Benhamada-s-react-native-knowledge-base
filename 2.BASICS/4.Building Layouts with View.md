## 🎯 Objective

Learn how to build real UI layouts using:

- `View` as layout containers
    
- `TextInput` for user input
    
- `Button` for actions
    
- Structuring UI into logical sections
    
- Preparing layout for Flexbox positioning
    

---

# 🧠 Core Concept: Layout is Built Using View Containers

In React Native, layout is created using the `View` component.

Think of `View` like:

|Web|React Native|
|---|---|
|div|View|

`View` is a container used to:

- Group elements
    
- Structure layout
    
- Apply styling
    
- Control positioning
    

---

# 🧩 Basic Layout Structure Example

Goal app layout:

```
Outer View (App Container)
│
├── View (Input Area)
│     ├── TextInput
│     └── Button
│
└── View (Goals List Area)
      └── Text
```

Code:

```jsx
<View style={styles.appContainer}>

  <View>
    <TextInput placeholder="Your course goal" />
    <Button title="Add Goal" />
  </View>

  <View>
    <Text>List of goals</Text>
  </View>

</View>
```

# 📦 Important Core Components

## 1️⃣ View

Purpose:

- Container
    
- Layout structuring
    
- Equivalent to div in web
    

Example:

```jsx
<View>
  <Text>Hello</Text>
</View>
```

---

## 2️⃣ TextInput

Purpose:

Allows user to enter text.

Import:

```jsx
import { TextInput } from 'react-native';
```

Example:

```jsx
<TextInput placeholder="Your course goal" />
```

---

### TextInput vs HTML input

|HTML|React Native|
|---|---|
|input|TextInput|
|placeholder|placeholder|
|value|value|
|onChange|onChangeText|

---

## 3️⃣ Button

Purpose:

Triggers an action.

Import:

```jsx
import { Button } from 'react-native';
```

Example:

```jsx

```

# 🧱 Why Use Multiple Views?

Example:

```jsx
<View>
  <TextInput />
  <Button />
</View>

<View>
  <Text>List of goals</Text>
</View>
```

This creates logical separation:

|View|Purpose|
|---|---|
|First View|Input area|
|Second View|Goals list|

Benefits:

- Easier styling
    
- Better structure
    
- Cleaner code
    
- Easier layout control
    

---

# 📏 Adding Space Using Padding

Problem:

Everything appears too close to screen edges and status bar.

Solution:

Use padding.

---

# Using StyleSheet

```jsx
const styles = StyleSheet.create({
  appContainer: {
    padding: 50
  }
});
```

Apply it:

```jsx
<View style={styles.appContainer}>
```

Result:

- Space around entire UI
    
- Content moves away from edges
    

---

# 🧠 Default Layout Behavior in React Native

By default, elements stack vertically.

Example:

```jsx
<View>
  <TextInput />
  <Button />
</View>
```

Result:

```
TextInput
Button
```

NOT:

```
TextInput Button
```

This is because React Native uses Flexbox with default:

```
flexDirection: column
```
