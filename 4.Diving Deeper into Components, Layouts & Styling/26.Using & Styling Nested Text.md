
# 📱 React Native - Nested Text & Highlight Styling

## 🧩 Key Concepts

- You can **nest `<Text>` components inside other `<Text>`**
- This allows applying **different styles to specific parts** of a sentence
- Useful for highlighting dynamic values (like X and Y)

---

## ⚙️ How It Works

### 📝 Basic Idea

```tsx id="n1kq2w"
<Text>
  Your phone needed <Text>5</Text> rounds to guess <Text>22</Text>.
</Text>
````

- Outer `<Text>` → general sentence
    
- Inner `<Text>` → highlighted values
    

---

## 🚫 Important Rule

- ✅ `<Text>` can contain other `<Text>`
    
- ❌ `<Text>` should NOT wrap `<View>` or other components
    

---

## 🎨 Styling Text

### General text style

```tsx
summaryText: {
  fontFamily: 'open-sans',
  fontSize: 24,
  textAlign: 'center',
  marginBottom: 24,
}
```

### Highlighted text

```tsx
highlight: {
  fontFamily: 'open-sans-bold',
  color: Colors.primary500,
}
```

---

## 💻 Full Example

```tsx
<Text style={styles.summaryText}>
  Your phone needed{' '}
  <Text style={styles.highlight}>X</Text>{' '}
  rounds to guess the number{' '}
  <Text style={styles.highlight}>Y</Text>.
</Text>
```

---

## 🔍 Key Behavior (Very Important)

- Nested `<Text>` **inherits text-related styles**
    
- Example:
    
    - If parent has `fontSize: 24`
        
    - Child text will also appear bigger
        

⚠️ This is **NOT classic CSS inheritance**, but how React Native renders text internally

---

## 💡 Tips

- Use nested `<Text>` for:
    
    - Dynamic values
        
    - Highlighting important info
        
- Keep styles reusable (`highlight`)
    
- Use `textAlign: 'center'` for better UI balance
    
- Prefer `marginBottom` instead of full margin for better control
