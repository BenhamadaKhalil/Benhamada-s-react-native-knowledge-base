# 1️⃣ Wrap the Screen in `SafeAreaView`

The `SafeAreaView` is a special component from React Native that automatically **adds padding to avoid the notch, status bar, and home indicator** on modern phones. This is much cleaner than manually adding margins or padding at the top.

```tsx
import React from 'react';
import { View, Text, StyleSheet, SafeAreaView } from 'react-native';

export default function GameScreen() {
  return (
    <SafeAreaView style={styles.screen}>
      <Text>Opponent's Guess</Text>
      {/* Placeholder for guessed number */}
      {/* Placeholder for controls (higher/lower buttons) */}
      {/* Placeholder for round log */}
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({
  screen: {
    flex: 1,
    padding: 12,       // padding inside the screen
    alignItems: 'center', // center items horizontally
    justifyContent: 'flex-start', // start from top vertically
  },
});
```

✅ **Why SafeAreaView is useful here**:

- Avoids overlap with device status bars.
    
- Makes your UI more consistent across devices.
    
- Works especially well when you want the screen centered but not hidden under the notch.
    

---

### 2️⃣ Layout Placeholders

Now you can safely add **placeholders** for the rest of the elements, like:

```tsx
<SafeAreaView style={styles.screen}>
  <Text style={styles.title}>Opponent's Guess</Text>
  
  <View style={styles.guessContainer}>
    <Text>42</Text> {/* Temporary guessed number */}
  </View>

  <View style={styles.controls}>
    <Text>Higher or Lower?</Text>
    <View style={styles.buttons}>
      <Text>-</Text>
      <Text>+</Text>
    </View>
  </View>

  <View style={styles.roundLog}>
    <Text>Round 1: 42</Text>
    <Text>Round 2: 37</Text>
  </View>
</SafeAreaView>
```

### 3️⃣ Initial Styles

You already started with `flex: 1` and padding. You can further enhance:

```tsx
const styles = StyleSheet.create({
  screen: {
    flex: 1,
    padding: 24,
    alignItems: 'center',
  },
  title: {
    fontSize: 24,
    fontWeight: 'bold',
    marginVertical: 12,
  },
  guessContainer: {
    marginVertical: 20,
    padding: 16,
    borderWidth: 2,
    borderColor: '#72063c',
    borderRadius: 8,
    alignItems: 'center',
    justifyContent: 'center',
  },
  controls: {
    marginVertical: 20,
    alignItems: 'center',
  },
  buttons: {
    flexDirection: 'row',
    justifyContent: 'space-between',
    width: 120,
    marginTop: 12,
  },
  roundLog: {
    marginTop: 30,
    alignItems: 'center',
  },
});
```
