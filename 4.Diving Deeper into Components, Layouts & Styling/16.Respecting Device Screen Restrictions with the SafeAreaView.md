### 1️⃣ Use `SafeAreaView` at the App Root

Instead of wrapping each screen individually, it’s cleaner to wrap **all screen content** in a `SafeAreaView` in `App.js`. This ensures:

- The **background gradient or image** still goes edge-to-edge, including under the notch.
    
- The **main content** (buttons, text, input fields, etc.) stays **within the visible, safe area**.
    
- Works automatically on devices **with or without notches**, without hardcoding padding.
    

Example:

```tsx
import { SafeAreaView, StyleSheet } from 'react-native';
import { LinearGradient } from 'expo-linear-gradient';
import StartGameScreen from './screens/StartGameScreen';
import GameScreen from './screens/GameScreen';

export default function App() {
  const [userNumber, setUserNumber] = useState<number | null>(null);

  const pickedNumberHandler = (pickedNumber: number) => {
    setUserNumber(pickedNumber);
  };

  let screen = <StartGameScreen onPickNumber={pickedNumberHandler} />;

  if (userNumber) {
    screen = <GameScreen />;
  }

  return (
    <LinearGradient colors={['#72063c', '#fcd34d']} style={styles.rootScreen}>
      <SafeAreaView style={styles.rootScreen}>
        {screen}
      </SafeAreaView>
    </LinearGradient>
  );
}

const styles = StyleSheet.create({
  rootScreen: {
    flex: 1,
  },
});
```

---

### 2️⃣ Key Points

- **Background under notch**: `LinearGradient` or `ImageBackground` is still full-screen; it visually fills the notch area.
    
- **Content stays safe**: Everything inside `SafeAreaView` automatically gets padding at the top and bottom based on device specifics.
    
- **Consistent spacing**: Works across iPhones, Android devices, tablets, and future devices with different notch sizes.
    

---

### 3️⃣ Enhancing Game Screen Layout

Even inside each screen, you can still add extra padding for better spacing, e.g., on the `GameScreen`:

```tsx
const styles = StyleSheet.create({
  screen: {
    flex: 1,
    padding: 24, // extra spacing beyond the safe area
    alignItems: 'center',
  },
});
```

This keeps things **visually appealing** while remaining safe.

---

In short:

- **Gradient/image** → edge-to-edge (under notch).
    
- **SafeAreaView** → wraps the content so it never gets hidden by notch/status bar.
    
- **Extra padding** → optional, for design spacing.
