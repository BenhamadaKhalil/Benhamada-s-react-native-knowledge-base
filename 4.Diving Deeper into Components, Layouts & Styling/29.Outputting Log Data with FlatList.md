# 📱 React Native - Using FlatList for Rendering Guess Logs

## 🧠 Core Idea

Instead of manually rendering a list with `.map()`, we now use **`FlatList`**, which is the **recommended and optimized way** to render lists in React Native.

---

## ⚙️ Key Concepts

### 1. Basic FlatList Setup

```js
<FlatList 
  data={guessRounds}
/>
```

👉 `data`:

- The array you want to display
    
- Here: `guessRounds` (list of guessed numbers)
    

---

### 2. Rendering Each Item (`renderItem`)

```js
<FlatList 
  data={guessRounds}
  renderItem={(itemData) => (
    <Text>{itemData.item}</Text>
  )}
/>
```

### Important:

- `renderItem` is a **function**
    
- It runs **for every item in the array**
    

👉 `itemData` contains:

- `itemData.item` → actual value (number here)
    

---

### 3. Accessing Data Correctly

❌ If data were objects:

```js
itemData.item.value
```

✅ In our case (numbers):

```js
itemData.item
```

👉 Because each item is just a **primitive number**, not an object

---

### 4. Handling Keys (`keyExtractor`)

FlatList **automatically handles keys**, but:

👉 It expects:

- Each item to have a `key` property
    

❌ Problem:

- Our data = numbers → no `key` field
    

---

### Solution:

```js
<FlatList 
  data={guessRounds}
  renderItem={(itemData) => (
    <Text>{itemData.item}</Text>
  )}
  keyExtractor={(item) => item}
/>
```

### Explanation:

- `keyExtractor` tells FlatList:  
    👉 “Use this value as the key”
    

👉 Why it works:

- Each guessed number is **unique**
    
- So it’s a perfect key
    

---

## 🔄 How FlatList Works (Internally)

- Takes your `data`
    
- Loops through it
    
- Calls `renderItem()` for each element
    
- Automatically assigns keys using:
    
    - `key` OR
        
    - `keyExtractor`
        

---

## ⚠️ Important Differences vs `.map()`

|Feature|`.map()`|`FlatList`|
|---|---|---|
|Performance|❌ Basic|✅ Optimized|
|Large lists|❌ Slow|✅ Efficient|
|Built-in features|❌ None|✅ Many (scrolling, lazy load)|
|Key handling|Manual|Semi-automatic|

---

## 💡 Practical Notes

- Always use `FlatList` in **real-world apps**
    
- Use `.map()` only for:
    
    - Very small lists
        
    - Simple UI
        
- `keyExtractor` is **mandatory** when:
    
    - Your data is not an object with `key`
