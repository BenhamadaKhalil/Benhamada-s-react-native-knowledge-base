# 🎨 React Native – Adding a Linear Gradient Background

## 🧩 Goal
- Replace the solid background color with a **linear gradient**
- Use `expo-linear-gradient` package for easy gradient support

---

## 📌 Step 1 – Install `expo-linear-gradient`

In your terminal:

```bash
expo install expo-linear-gradient
````

> Notes:
> 
> - Always use `expo install` with Expo projects
>     
> - Ensures the installed version is compatible with your Expo SDK
>     

---

## 📌 Step 2 – Import the LinearGradient Component

In `App.js`:

```tsx
import { StyleSheet } from 'react-native';
import { LinearGradient } from 'expo-linear-gradient';
import StartGameScreen from './screens/StartGameScreen';
```

---

## 📌 Step 3 – Replace Root View with LinearGradient

```tsx
export default function App() {
  return (
    <LinearGradient
      colors={['#4e0329', '#ddb52f']} // plum → yellow gradient
      style={styles.rootScreen}
    >
      <StartGameScreen />
    </LinearGradient>
  );
}

const styles = StyleSheet.create({
  rootScreen: {
    flex: 1, // fill the entire screen
  },
});
```

> Notes:
> 
> - `colors` prop takes an **array of colors** from start to end
>     
> - `style` still needs `flex: 1` to cover full screen
>     
> - No `backgroundColor` is needed because gradient replaces it
>     

---

## 📌 Step 4 – Optional: Adjust Contrast

- For better contrast between input container and background:
    

```tsx
inputContainer: {
  backgroundColor: '#3b021f', // darker plum
  ...
}
```

✅ Result:

- Beautiful gradient background
    
- Input container stands out clearly on top of the gradient
    

---

### 💡 Tips

- You can add **more than 2 colors** to create richer gradients
    
- Use **official docs**: [Expo Linear Gradient](https://docs.expo.dev/versions/latest/sdk/linear-gradient/)
    
- `LinearGradient` behaves like a `View`, so all children work normally
