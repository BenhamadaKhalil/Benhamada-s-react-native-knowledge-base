# 📱 Add Icons in React Native (Expo)

## ✅ 1. Import Icons

Expo already includes the icon library, so just import:

```tsx
import { Ionicons } from "@expo/vector-icons";
```

👉 No install needed (if using Expo)

---

## ✅ 2. Replace Text with Icons

### ❌ Before (using text):

```tsx
<Text>-</Text>
<Text>+</Text>
```

---

### ✅ After (using icons):

```tsx
<Ionicons name="md-remove" size={24} color="white" />
<Ionicons name="md-add" size={24} color="white" />
```

---

## ✅ 3. Full Example (Buttons)

```tsx
<View style={{ flexDirection: "row" }}>
  <Pressable style={styles.button}>
    <Ionicons name="md-remove" size={24} color="white" />
  </Pressable>

  <Pressable style={styles.button}>
    <Ionicons name="md-add" size={24} color="white" />
  </Pressable>
</View>
```

---

## 🎨 4. Styling Example

```tsx
const styles = StyleSheet.create({
  button: {
    backgroundColor: "#72063c",
    padding: 12,
    borderRadius: 8,
    marginHorizontal: 10,
    alignItems: "center",
  },
});
```

# 🔎 5. How to Find Icons

👉 Go to: **Expo Vector Icons docs**

Search for:

- `add` → ➜ `md-add`
    
- `remove` → ➜ `md-remove`
    

---

# 🧠 Key Concepts

- Icons are just **components**
    
- `name` = icon identifier
    
- `size` = pixels
    
- `color` = any color
    

---

# ⚠️ Common Error (you had this before)

If you see:

```
Cannot find module '@expo/vector-icons'
```

👉 Fix:

```bash
npx expo install @expo/vector-icons
```
