# 📱 React Native – Game Project Overview (Course Section Start)

## 🧠 Core Idea
This section of the course focuses on building a complete **React Native game** using Expo.  
We start from a **simple base project** and progressively add features, screens, and custom components.

---

## ⚙️ Starting Point
- A **fresh Expo project**
- Only one component: `App`
- Contains:
  - Dummy content
  - Basic styles

👉 This minimal setup will evolve into a full app.

---

## 🎮 Final App Overview (Game Features)

### 1️⃣ Start Screen
- User picks a number between **1 and 99**
- Features:
  - Input validation (no values < 1 or > 99)
  - Reset button → clears input
  - Confirm/Start button → begins the game

---

### 2️⃣ Game Screen
- The **phone guesses the user's number**
- User gives hints:
  - "Higher"
  - "Lower"

#### Extra Features:
- ⚠️ **Validation logic**
  - Detects if the user gives wrong hints
  - Shows an alert if the hint is inconsistent

- 📜 **Guess Log**
  - Displays all guesses made by the phone
  - Scrollable when content exceeds screen height

---

### 3️⃣ Game Over Screen
- Displayed when the phone guesses correctly

#### Contains:
- Summary of the game (e.g., number of rounds)
- A visual (image)
- Button to **start a new game**

---
