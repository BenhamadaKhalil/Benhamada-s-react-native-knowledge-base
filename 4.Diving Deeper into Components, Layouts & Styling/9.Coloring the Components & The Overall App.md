# 🎨 React Native – Adding a Background to the Screen

## 🧩 Goal
- Set a **background color** for the entire screen
- Prepare for future **gradient or image backgrounds**

---

## 📌 Step 1 – Wrap the Screen in a Root View

In `App.js`:

```tsx id="s4v7q1"
import { View, StyleSheet } from 'react-native';
import StartGameScreen from './screens/StartGameScreen';

export default function App() {
  return (
    <View style={styles.rootScreen}>
      <StartGameScreen />
    </View>
  );
}

const styles = StyleSheet.create({
  rootScreen: {
    backgroundColor: '#ddb52f', // same yellow as input border
    flex: 1,                     // fill the entire screen
  },
});
````

> Notes:
> 
> - `View` by default only takes the space required by its children
>     
> - `flex: 1` ensures the View expands to cover the full screen
>     

---

## 📌 Step 2 – Why Flex 1 is Important

- Without `flex: 1`, background color only covers the area of `StartGameScreen`
    
- Adding `flex: 1` makes the root container stretch to **all available space**
    

```text
Root View (flex: 1, yellow)
│
└─ StartGameScreen (input area + buttons)
```

✅ Result:

- Entire screen is covered with yellow
    
- Input area and buttons appear on top
    

---

## 💡 Next Steps

- Replace solid color with **linear gradient**
    
- Optionally add **background image** combined with gradient
    
- This root View will ensure consistency across multiple screens
    

---

### ⚠️ Tip

- Always wrap your screens in a **root container** when planning **global backgrounds**
    
- `flex: 1` is key for any full-screen layout in React Native
