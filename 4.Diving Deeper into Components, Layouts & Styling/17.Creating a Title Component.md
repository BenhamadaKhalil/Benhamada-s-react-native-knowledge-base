# 1️⃣ Create a Reusable Title Component

Instead of repeating the same styled `Text` element in multiple screens, you created a dedicated `Title.js` component:

```tsx
// components/Title.js
import { Text, StyleSheet } from 'react-native';

function Title({ children }: { children: React.ReactNode }) {
  return <Text style={styles.title}>{children}</Text>;
}

export default Title;

const styles = StyleSheet.create({
  title: {
    fontSize: 24,        // larger font size for a title
    fontWeight: 'bold',   // bold text
    color: '#fcd34d',     // yellow color
    textAlign: 'center',  // center the title
    borderWidth: 2,       // border around text
    borderColor: '#fcd34d',
    padding: 12,          // spacing inside the border
  },
});
```

✅ Key points:

- The `children` prop allows the component to display **any text** passed between the opening and closing tags.
    
- All styling is encapsulated inside the component, making it reusable and consistent.
    

---

### 2️⃣ Use the Title Component in GameScreen

Instead of writing:

```tsx
<Text style={styles.title}>Opponent's Guess</Text>
```

You now do:

```tsx
import Title from '../components/Title';

<Title>Opponent's Guess</Title>
```

This is **cleaner, easier to maintain**, and ready for future screens.

---

### 3️⃣ Why This Approach Matters

1. **Consistency** – All titles across your app will look the same without copying style objects everywhere.
    
2. **Maintainability** – If you want to tweak the title style (color, font size, padding), you do it in **one place**.
    
3. **Reusability** – You can use `Title` in other screens like the start screen, end screen, or game-over screen.
