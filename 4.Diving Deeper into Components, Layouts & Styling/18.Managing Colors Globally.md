### 1️⃣ Create a centralized `colors` file

You created a `constants/colors.js` file like this:

```ts
// constants/colors.js
const colors = {
  primary500: '#72063c', // main plum shade
  primary600: '#640233', // slightly darker for ripple effect
  primary700: '#4e0329', // extra dark shade for backgrounds
  primary800: '#3b021f', // very dark shade
  accent500: '#ddb52f',   // yellow accent
};

export default colors;
```

This file is now the **single source of truth** for all color values in your app.

---

### 2️⃣ Use the colors in components

Instead of hardcoding hex values in multiple places, you import the colors:

```ts
import colors from '../constants/colors';

// Example in Title.js
<Text style={{ color: colors.accent500, borderColor: colors.accent500 }}>Opponent's Guess</Text>

// Example in PrimaryButton.js
backgroundColor: colors.primary500
rippleColor: colors.primary600
```

✅ Benefits:

- **Consistency:** All components use the same colors.
    
- **Maintainability:** To change a color, you only update it in `colors.js`, and it propagates everywhere.
    
- **Scalability:** You can add shades for different purposes (`primary500`, `primary600`, etc.) without breaking anything.
    

---

### 3️⃣ Apply it globally

You also updated `App.js` and `StartGameScreen` to use these constants instead of hardcoded colors. This ensures a unified color theme across the entire app.

### 4️⃣ Optional next step

You could extend this pattern to **fonts, spacing, and other theme-related values**, e.g.,

```ts
// constants/theme.js
export const spacing = { small: 8, medium: 16, large: 24 };
export const fonts = { regular: 'Roboto-Regular', bold: 'Roboto-Bold' };
```

Then everything in your app can refer to these constants, making your app **more maintainable and scalable**.
