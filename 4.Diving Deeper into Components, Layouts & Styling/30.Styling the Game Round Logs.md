# 📱 React Native - Custom List Items & Styling (GuessLogItem)

## 🧠 Core Idea

Instead of rendering plain text inside the `FlatList`, we:

- Create a **custom component (`GuessLogItem`)**
    
- Display **round number + guessed value**
    
- Apply **clean styling**
    
- Compute **round number dynamically**
    

---

## ⚙️ Key Concepts

### 1. Creating a Reusable Component

📁 `components/game/GuessLogItem.js`

```js
function GuessLogItem({ roundNumber, guess }) {
  return (
    <View style={styles.listItem}>
      <Text style={styles.itemText}>#{roundNumber}</Text>
      <Text style={styles.itemText}>Opponent's Guess: {guess}</Text>
    </View>
  );
}

export default GuessLogItem;
```

👉 Props:

- `roundNumber` → current round index
    
- `guess` → guessed number
    

---

### 2. Styling the List Item

```js
const styles = StyleSheet.create({
  listItem: {
    borderColor: Colors.primary800,
    borderWidth: 1,
    borderRadius: 40,
    padding: 12,
    marginVertical: 8,
    backgroundColor: Colors.accent500,
    flexDirection: 'row',
    justifyContent: 'space-between',
    width: '100%',
    elevation: 4, // Android shadow

    // iOS shadow
    shadowColor: 'black',
    shadowOffset: { width: 0, height: 0 },
    shadowOpacity: 0.25,
    shadowRadius: 3,
  },
  itemText: {
    fontFamily: 'open-sans',
  },
});
```

---

### 🎨 Styling Breakdown

- `flexDirection: 'row'` → horizontal layout
    
- `justifyContent: 'space-between'` → push items left & right
    
- `borderRadius: 40` → rounded UI
    
- `marginVertical` → spacing between items
    
- `width: '100%'` → full width
    

👉 Platform differences:

- Android → `elevation`
    
- iOS → `shadow*` properties
    

---

### 3. Using the Component in FlatList

Replace old `<Text>` with:

```js
<GuessLogItem
  roundNumber={...}
  guess={itemData.item}
/>
```

---

### 4. Calculating the Round Number

👉 Problem:

- Latest guess is at index `0`
    
- But it’s actually the **latest round**, not round 1
    

---

### Solution:

```js
const guessRoundsListLength = guessRounds.length;
```

```js
roundNumber={guessRoundsListLength - itemData.index}
```

---

### 💡 Why This Works

|Value|Meaning|
|---|---|
|`guessRounds.length`|total rounds|
|`itemData.index`|position in array|
|Result|actual round number|

---

### Example:

|Index|Value|Round|
|---|---|---|
|0|latest guess|round 5|
|1|previous|round 4|

👉 Formula fixes reversed order

---

## 💡 Practical Notes

- Always extract UI into **reusable components**
    
- Styling improves readability & UX
    
- Use **index carefully** (it’s not always what you think)
    
- Think about **data order vs display order**

## ⚠️ UI Issue Observed

👉 Problem:

- Last item in the list is **hard to fully scroll into view**
    

👉 Cause:

- `FlatList` doesn't have enough **bottom spacing**
    

👉 This will be fixed later (likely with padding or contentContainerStyle)
