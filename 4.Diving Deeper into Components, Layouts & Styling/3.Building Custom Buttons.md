
# 📱 React Native – Building Custom Buttons (PrimaryButton)

## 🧠 Core Idea
Instead of using the default React Native `<Button />`, we build a **custom reusable button component**.

👉 This gives us full control over:
- Styling
- Layout
- Behavior

---

## 🧩 Creating a Custom Button

### 📁 File:
`components/PrimaryButton.js`

```tsx
function PrimaryButton({ children }) {
  return (
    <View>
      <Text>{children}</Text>
    </View>
  );
}

export default PrimaryButton;
````

---

## ⚙️ Key Concepts

### 1️⃣ Combine Core Components

- React Native UI is built using **basic building blocks**
    
- Even the default Button is made from:
    
    - `View`
        
    - `Text`
        

👉 You are doing the same thing manually

---

### 2️⃣ `children` Prop (Very Important)

```tsx
function PrimaryButton({ children }) {
```

- `children` = content between component tags
    

#### Example:

```tsx
<PrimaryButton>Reset</PrimaryButton>
```

👉 Inside the component:

```tsx
<Text>{children}</Text>
```

---

### 3️⃣ Destructuring Props

Instead of:

```tsx
function PrimaryButton(props) {
  return <Text>{props.children}</Text>;
}
```

We use:

```tsx
function PrimaryButton({ children }) {
```

✅ Cleaner and easier to read

---

## 🧪 Using the Custom Button

### In `StartGameScreen.js`

```tsx
import PrimaryButton from '../components/PrimaryButton';

<View>
  <TextInput />
  
  <PrimaryButton>Reset</PrimaryButton>
  <PrimaryButton>Confirm</PrimaryButton>
</View>
```

---

## 🚀 Rendering the Screen

### In `App.js`

```tsx
import StartGameScreen from './screens/StartGameScreen';

export default function App() {
  return <StartGameScreen />;
}
```

---

## ⚙️ Important Setup

- `App.js` is the **entry point**
    
- The component exported there is what gets rendered
    

👉 So to show a screen:

- You must render it inside `App`
