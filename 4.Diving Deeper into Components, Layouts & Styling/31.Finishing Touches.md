# 📱 React Native - Fixing FlatList Scroll & Counting Rounds

## 🧠 Core Idea

This part focuses on:

- Fixing **FlatList scrolling issues**
    
- Controlling layout using a **container with flex**
    
- Calculating **total number of rounds**
    
- Passing data from **GameScreen → App → GameOverScreen**
    

---

## ⚙️ Key Concepts

### 1. Fixing FlatList Scrolling Issue

👉 Problem:

- FlatList grows infinitely in height
    
- Content goes خارج screen (overflow)
    

---

### ✅ Solution: Wrap FlatList in a Container

```js
<View style={styles.listContainer}>
  <FlatList ... />
</View>
```

---

### 2. Restricting Height with Flexbox

```js
const styles = StyleSheet.create({
  listContainer: {
    flex: 1,
    padding: 16,
  },
});
```

### Why this works:

- `flex: 1` → container takes available space
    
- FlatList becomes **scrollable inside that space**
    
- Prevents overflow خارج الشاشة
    

---

### 🎯 Result:

- Smooth scrolling ✅
    
- Items stay داخل الشاشة ✅
    
- Better UX ✅
    

---

## 🔢 Counting Number of Rounds

### Key Insight:

👉 Number of rounds = length of `guessRounds` array

```js
guessRounds.length
```

---

## 🔄 Passing Data Up (Child → Parent)

### Step 1: Modify `gameOverHandler` in App

```js
function gameOverHandler(numberOfRounds) {
  setGuessRounds(numberOfRounds);
}
```

👉 Now it accepts data from GameScreen

---

### Step 2: Send Data from GameScreen

```js
onGameOver(guessRounds.length);
```

👉 This passes:

- Total rounds
    
- When game ends
    

---

### 🔗 Data Flow Overview

```
GameScreen
   ↓ (rounds count)
App Component (gameOverHandler)
   ↓ (props)
GameOverScreen
```

👉 Classic React pattern:

- Lift state up
    
- Pass data down
    

---

## 💡 Practical Notes

- FlatList needs a **bounded container** to behave correctly
    
- `flex: 1` is essential in layouts
    
- Array length is a simple but powerful way to track counts
    
- Always think about **data flow direction** in React:
    
    - Up via functions
        
    - Down via props
        

---

## ⚠️ Common Mistake

❌ Forgetting to pass data in function:

```js
onGameOver();
```

✅ Correct:

```js
onGameOver(guessRounds.length);
```
