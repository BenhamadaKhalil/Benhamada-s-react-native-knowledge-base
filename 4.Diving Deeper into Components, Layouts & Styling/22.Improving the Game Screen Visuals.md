## 2️⃣ Creating a Reusable `Card` Component

- Extracted the **input container box** styling into its own component:
    

```tsx
// components/ui/Card.js
import { View, StyleSheet } from 'react-native';
import Colors from '../../constants/colors';

export default function Card({ children }) {
  return <View style={styles.card}>{children}</View>;
}

const styles = StyleSheet.create({
  card: {
    padding: 16,
    marginTop: 36,
    marginHorizontal: 24,
    backgroundColor: Colors.primary500,
    borderRadius: 8,
    elevation: 4, // shadow for Android
    shadowColor: 'black',
    shadowOffset: { width: 0, height: 2 },
    shadowRadius: 6,
    shadowOpacity: 0.25,
  },
});
```

- Usage in **StartGameScreen**:
    

```tsx
<Card>
  <InstructionText>Enter a number</InstructionText>
  <TextInput ... />
</Card>
```

- Usage in **GameScreen** for buttons:
    

```tsx
<Card>
  <InstructionText>Higher or Lower?</InstructionText>
  <View style={{ flexDirection: 'row' }}>
    <PrimaryButton onPress={...}>-</PrimaryButton>
    <PrimaryButton onPress={...}>+</PrimaryButton>
  </View>
</Card>
```

## 3️⃣ Creating a Reusable `InstructionText` Component

- Extracted the styled text into a reusable component:

```tsx
// components/ui/InstructionText.js
import { Text, StyleSheet } from 'react-native';
import Colors from '../../constants/colors';

export default function InstructionText({ children }) {
  return <Text style={styles.instructionText}>{children}</Text>;
}

const styles = StyleSheet.create({
  instructionText: {
    color: Colors.accent500,
    fontSize: 24,
    textAlign: 'center',
    marginBottom: 12,
  },
});
```
