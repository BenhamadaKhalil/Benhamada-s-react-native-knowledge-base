
# 📱 React Native – Making a Real Button with Pressable

## 🧠 Core Idea
Our button was just a `View + Text`.  
Now we turn it into a **real interactive button** using `Pressable`.

👉 This allows us to:
- Detect taps
- Add feedback (visual effects)
- Improve UX

---

## 🧩 Making the Button Clickable

### Using `Pressable`

```tsx
import { Pressable } from 'react-native';

function pressHandler() {
  console.log('Pressed!');
}

<Pressable onPress={pressHandler}>
  <View>
    <Text>Reset</Text>
  </View>
</Pressable>
````

---

## 🔑 Key Concept

### `onPress`

```tsx
onPress={pressHandler}
```

- Pass a **function reference**
    
- NOT `pressHandler()`
    

👉 React Native will call it when pressed

---

## 🎨 Styling the Button

### Styles Setup

```tsx
const styles = StyleSheet.create({
  buttonOuterContainer: {
    borderRadius: 28,
    margin: 4,
    overflow: 'hidden',
  },
  buttonInnerContainer: {
    backgroundColor: '#72063c',
    paddingVertical: 8,
    paddingHorizontal: 16,
    elevation: 2,
  },
  buttonText: {
    color: 'white',
    textAlign: 'center',
  },
});
```

---

## 🧩 Applying Styles

```tsx
<View style={styles.buttonOuterContainer}>
  <Pressable onPress={pressHandler} style={styles.buttonInnerContainer}>
    <Text style={styles.buttonText}>Reset</Text>
  </Pressable>
</View>
```

---

## ⚠️ Important Concept: No Style Inheritance

❌ This does NOT work:

```tsx
<View style={{ color: 'white' }}>
  <Text>Text</Text>
</View>
```

✅ Must style directly:

```tsx
<Text style={{ color: 'white' }}>Text</Text>
```

---

## 🌊 Android Ripple Effect

```tsx
<Pressable
  android_ripple={{ color: '#640233' }}
>
```

👉 Adds wave effect when pressed (Android only)

---

## 🚨 Common Problem: Ripple Outside Button

### ❌ Issue:

- Ripple goes outside rounded corners
    

### ✅ Fix:

1. Wrap Pressable inside a `View`
    
2. Add:
    

```tsx
overflow: 'hidden'
borderRadius: 28
```

👉 This clips the ripple inside the button

---

## 🍎 iOS Press Feedback

iOS has **no ripple effect**

👉 Solution: change opacity

---

## 🎯 Press Feedback with Dynamic Styles

```tsx
<Pressable
  onPress={pressHandler}
  style={({ pressed }) =>
    pressed
      ? [styles.buttonInnerContainer, styles.pressed]
      : styles.buttonInnerContainer
  }
>
```

---

### Add Pressed Style

```tsx
pressed: {
  opacity: 0.75,
}
```

---

## 🔑 Key Concept: Dynamic `style`

- `style` can be:
    
    - Object ✅
        
    - Array ✅
        
    - Function ✅ (for Pressable)
        

### `pressed` value:

- `true` → user is pressing
    
- `false` → normal state
    

---

## 🎉 Final Button Structure

```tsx
<View style={styles.buttonOuterContainer}>
  <Pressable
    onPress={pressHandler}
    android_ripple={{ color: '#640233' }}
    style={({ pressed }) =>
      pressed
        ? [styles.buttonInnerContainer, styles.pressed]
        : styles.buttonInnerContainer
    }
  >
    <Text style={styles.buttonText}>Confirm</Text>
  </Pressable>
</View>
```

---

## 💡 Important Notes

- Use **Pressable (modern)** instead of old Touchable components
    
- Always handle:
    
    - Android → ripple
        
    - iOS → opacity
        
- Use **outer + inner container pattern** for clean UI
