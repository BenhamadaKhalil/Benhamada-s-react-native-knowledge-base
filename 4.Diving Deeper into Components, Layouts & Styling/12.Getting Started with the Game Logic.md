## 1️⃣ Manage the Input with `useState`

Since `TextInput` always provides a string, we keep the state as a string and convert it later:

```tsx
import { useState } from 'react';
import { TextInput, Alert } from 'react-native';

const [enteredNumber, setEnteredNumber] = useState('');

function numberInputHandler(inputText: string) {
  // Update state on every keystroke
  setEnteredNumber(inputText);
}
```

Bind this to the `TextInput`:

```tsx
<TextInput
  value={enteredNumber}
  onChangeText={numberInputHandler}
  keyboardType="number-pad"
/>
```

✅ Now the state reflects the current user input.

## 2️⃣ Add the `Confirm` Button Logic

We want to **validate the input** and proceed only if it's a valid number (1–99):

```tsx
function confirmInputHandler() {
  const chosenNumber = parseInt(enteredNumber);

  if (isNaN(chosenNumber) || chosenNumber <= 0 || chosenNumber > 99) {
    Alert.alert(
      'Invalid number!',
      'Number has to be between 1 and 99.',
      [{ text: 'Okay', style: 'destructive' }]
    );
    return;
  }

  // Proceed to the game screen with chosenNumber
  console.log('Valid number:', chosenNumber);
}
```

> Notes:
> 
> - `parseInt` converts the string to a number.
>     
> - `isNaN` checks if the input is a valid number.
>     
> - `Alert.alert` shows a pop-up message for invalid input.
>

## 3️⃣ Make Your `PrimaryButton` Reusable

Currently, your `PrimaryButton` just logs something. We want it to **accept a function via props**:

```tsx
import { Pressable, Text, StyleSheet } from 'react-native';

interface PrimaryButtonProps {
  children: React.ReactNode;
  onPress: () => void;
}

export default function PrimaryButton({ children, onPress }: PrimaryButtonProps) {
  return (
    <Pressable style={styles.button} onPress={onPress}>
      <Text style={styles.buttonText}>{children}</Text>
    </Pressable>
  );
}

const styles = StyleSheet.create({
  button: {
    padding: 12,
    backgroundColor: '#72063c',
    borderRadius: 8,
    alignItems: 'center',
  },
  buttonText: {
    color: 'white',
    fontWeight: 'bold',
  },
});
```

> Key point: `onPress` is passed **from the parent component** and directly forwarded to `Pressable`.

---

## 4️⃣ Connect the Button in `StartGameScreen`

```tsx
<PrimaryButton onPress={confirmInputHandler}>
  Confirm
</PrimaryButton>
```

✅ Now pressing the button runs `confirmInputHandler`, which validates the input and either shows an alert or proceeds to the game screen.

## 5️⃣ Optional: Reset Input

You can also add a **Reset** button that clears the input:

```tsx
function resetInputHandler() {
  setEnteredNumber('');
}

<PrimaryButton onPress={resetInputHandler}>
  Reset
</PrimaryButton>
```
