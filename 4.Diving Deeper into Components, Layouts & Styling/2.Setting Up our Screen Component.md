
# 📱 React Native – App Structure & First Screen Setup

## 🧠 Core Idea
Before building features, we first organize the project into a **clear structure** and start creating the **first screen component**.

👉 Important: In React Native, a *screen* is just a **regular React component**.

---

## 📁 Project Structure

### 1️⃣ `screens/` Folder
- Contains **full-screen components**
- Each file represents one full screen in the app

#### Screens in this project:
- `StartGameScreen.js` → Pick a number & start the game
- `GameScreen.js` → Main gameplay (guessing logic)
- `GameOverScreen.js` → End screen with results

---

### 2️⃣ `components/` Folder
- Contains **reusable components**
- Used inside screens

#### Examples:
- Custom buttons
- Input components
- UI elements

## ⌨️ Adding Input Field

### Using `TextInput`

```tsx
import { TextInput } from 'react-native';
```

- Used to enter data
    
- Can handle:
    
    - Text
        
    - Numbers (our case)
        

---

## 📦 Using a Container (`View`)

```tsx
import { View } from 'react-native';
```

- Wraps and organizes elements:
    
    - Input
        
    - Buttons
        

---

## 🎨 Why NOT Use Default Button?

Instead of:

```tsx
import { Button } from 'react-native';
```

We will:

👉 Build a **custom button**

### Why?

- Full control over:
    
    - Styling
        
    - Behavior
        
    - Reusability
        

---

## ⚠️ Important Rule

❌ This will NOT work:

```tsx
<View>
  Hello World
</View>
```

✅ Correct way:

```tsx
import { Text } from 'react-native';

<View>
  <Text>Hello World</Text>
</View>
```

👉 Text must always be wrapped inside `<Text>`
