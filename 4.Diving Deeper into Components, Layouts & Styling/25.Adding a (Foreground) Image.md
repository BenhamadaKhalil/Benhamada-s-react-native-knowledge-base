
# 📱 React Native - Game Over Screen UI + Image Styling

## 🧩 Key Concepts

- Build a **Game Over screen UI**
- Use `View` as a **main container**
- Reuse existing components (like `Title`)
- Display and style images using `Image`
- Create a **circular image** using:
  - `borderRadius`
  - `overflow: hidden`
- Center content with Flexbox

---

## 🎯 Goal of the Screen

The Game Over screen should contain:
- 🏁 A title → "Game Over"
- 🖼️ A success image
- 📊 A summary:
  - Number of rounds (X)

## 🎨 Creating a Circular Image

### 🔑 Trick:

- Wrap `Image` inside a `View`
    
- Apply styles to the container
    

```tsx
imageContainer: {
  width: 300,
  height: 300,
  borderRadius: 150, // half of width/height
  overflow: 'hidden',
  borderWidth: 3,
  borderColor: Colors.primary800,
  margin: 36,
}
```

### Image style:

```tsx
image: {
  width: '100%',
  height: '100%',
}
```

### 💡 Important Rule

- `% values` refer to the **parent container size**
    

---

## 📦 Root Container Styling

```tsx
rootContainer: {
  flex: 1,
  padding: 24,
  justifyContent: 'center',
  alignItems: 'center',
}
```

### 🔍 What this does:

- `flex: 1` → take full screen
    
- `justifyContent: center` → vertical centering
    
- `alignItems: center` → horizontal centering

## 💡 Tips

- Always wrap complex UI in a `View`
    
- Use containers for advanced styling (like circular images)
    
- Keep width = height for perfect circles
    
- `borderRadius = width / 2`
    
- Use margin/padding to improve spacing
    
- Reuse components (like `Title`) for consistency
