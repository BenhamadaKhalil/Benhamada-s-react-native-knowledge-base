## 2️⃣ Dynamic min/max boundaries

- Keep track of the **current min and max boundaries** **outside** the component so they don’t reset on re-render:
    

```ts
let minBoundary = 1;
```

- Update boundaries based on user feedback:
    

```ts
function nextGuessHandler(direction) {
  if (
    (direction === 'lower' && currentGuess < userNumber) ||
    (direction === 'greater' && currentGuess > userNumber)
  ) {
    Alert.alert("Don't lie!", 'You know that this is wrong.', [{ text: 'Sorry', style: 'cancel' }]);
    return;
  }

  if (direction === 'lower') {
    maxBoundary = currentGuess; // exclude currentGuess automatically
  } else {
    minBoundary = currentGuess + 1; // include only numbers higher than currentGuess
  }

  const newRndNumber = generateRandomBetween(minBoundary, maxBoundary, currentGuess);
  setCurrentGuess(newRndNumber);
```

## ✅ Summary of the Game Flow

1. GameScreen renders and generates an **initial guess** using `generateRandomBetween`.
    
2. The guess is displayed in the `NumberContainer`.
    
3. The user clicks `+` or `-` to give feedback:
    
    - `+` → new number should be **greater**.
        
    - `-` → new number should be **lower**.
        
4. `nextGuessHandler`:
    
    - Validates the hint.
        
    - Updates min/max boundaries.
        
    - Generates a new guess within boundaries.
        
    - Updates `currentGuess` state → UI updates automatically.
        
5. Alerts the user if they give an **incorrect hint**.
    
6. Repeat until the phone guesses the correct number (we still need an **exit condition** for that).
