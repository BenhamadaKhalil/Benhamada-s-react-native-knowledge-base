
# 🎨 React Native – Laying Out the Input Area

## 🧩 Goal
- Center the **TextInput**  
- Arrange buttons **side by side**  
- Learn flexbox in React Native for nested layouts

---

## 📌 Step 1 – Center TextInput

```tsx id="x7t7q9"
inputContainer: {
  alignItems: 'center', // centers along cross axis (horizontal)
}
````

> Notes:
> 
> - Default `flexDirection` is `column`
>     
> - Main axis = top → bottom
>     
> - Cross axis = left → right
>     
> - `alignItems: 'center'` centers children horizontally
>     

✅ Effect:

- Text input is centered
    
- Buttons shrink to fit content (no more stretching)
    

---

## 📌 Step 2 – Wrap Buttons in a Row

1. Wrap buttons in a **new View**:
    

```tsx
<View style={styles.buttonsContainer}>
  <View style={styles.buttonContainer}>
    <PrimaryButton>Reset</PrimaryButton>
  </View>
  <View style={styles.buttonContainer}>
    <PrimaryButton>Confirm</PrimaryButton>
  </View>
</View>
```

2. Add new style:
    

```tsx
buttonsContainer: {
  flexDirection: 'row', // buttons sit next to each other
}
```

---

## 📌 Step 3 – Equal Width Buttons

- Wrap each button in its **own View**
    
- Use `flex: 1` to distribute space evenly
    

```tsx
buttonContainer: {
  flex: 1, // take available space
  marginHorizontal: 4, // optional spacing between buttons
}
```

✅ Now:

- Buttons share equal width
    
- Layout is consistent
    
- Buttons still have inner padding and rounded corners
    

---

## 🔑 Key Flexbox Concepts

|Property|Role in Layout|
|---|---|
|`flexDirection`|Main axis direction (row / column)|
|`justifyContent`|Align items along main axis|
|`alignItems`|Align items along cross axis|
|`flex: 1`|Take up available space in parent container|
|Nesting Views|Allows independent flex behavior at different levels|

---

## 💡 Tips

- React Native flexbox is **column by default**
    
- Nesting Views is **common** to achieve complex layouts
    
- You can combine **flexDirection, flex, justifyContent, alignItems** at multiple levels
    
- This pattern is widely used for forms, input areas, and responsive designs
