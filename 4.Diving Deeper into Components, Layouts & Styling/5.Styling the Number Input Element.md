
# 📱 React Native – Styling & Controlling the TextInput

## 🧠 Core Idea
Now we improve the **input field** by:
- Styling it (size, color, spacing)
- Limiting user input
- Improving user experience

---

## 🎨 Styling the Input Field

### Add a New Style

```tsx
const styles = StyleSheet.create({
  numberInput: {
    height: 50,
    fontSize: 32,
    borderBottomColor: '#ddb52f',
    borderBottomWidth: 2,
    color: '#ddb52f',
    marginVertical: 8,
    fontWeight: 'bold',
    width: 50,
    textAlign: 'center',
  },
});
````

---

## 🔑 Key Styling Properties

### 1️⃣ Size & Layout

```tsx
height: 50
width: 50
```

- Fixed height
    
- Narrow width (since only 1–2 digits needed)
    

---

### 2️⃣ Text Styling

```tsx
fontSize: 32
fontWeight: 'bold'
color: '#ddb52f'
```

👉 Makes input:

- Large
    
- Visible
    
- Styled consistently
    

---

### 3️⃣ Bottom Border (Custom Input Look)

```tsx
borderBottomColor: '#ddb52f'
borderBottomWidth: 2
```

👉 Creates a **modern underline input style**

---

### 4️⃣ Spacing

```tsx
marginVertical: 8
```

- Adds space above & below
    

---

### 5️⃣ Centering Text

```tsx
textAlign: 'center'
```

👉 Centers text inside the input

---

## 🧩 Applying the Style

```tsx
<TextInput style={styles.numberInput} />
```

---

## 🔒 Limiting Input Length

### ❌ Wrong (string → causes error)

```tsx
maxLength="2"
```

### ✅ Correct (number)

```tsx
maxLength={2}
```

👉 React Native expects a **number**, not a string

---

## ⚙️ What This Fixes

- Prevents long input
    
- Limits to **2 characters**
    
- Matches game logic (1–99)
    

---

## 🚨 Important Behavior

Even with `maxLength={2}`:

- Users can still enter:
    
    - Letters ❌
        
    - Symbols ❌
        

👉 So input is still **not restricted to numbers yet**

---

## ⚠️ Current Limitations

- ❌ Any character allowed
    
- ❌ Full keyboard shown
    
- ❌ Not optimized UX
    

---

## 💡 Important Notes

- Always match UI with logic:
    
    - If max number = 99 → maxLength = 2
        
- Use `{}` when passing non-string values:
    
    - numbers
        
    - booleans
        
    - objects
