
# 🎨 React Native – Overlaying a Background Image on a Gradient

## 🧩 Goal
- Keep the **linear gradient** as base
- Overlay a **semi-transparent image** on top of the gradient
- Ensure all UI elements (buttons, input) appear above the image

---

## 📌 Step 1 – Add the Image Asset

1. Create a folder structure in your project:

```

assets/  
└── images/  
└── background.png

````

2. Add your image file (`background.png`) inside this folder.

> Tip: Use free images from **[Unsplash](https://unsplash.com/)**. Give attribution if needed.

---

## 📌 Step 2 – Import `ImageBackground`

```tsx id="g0zq2h"
import { ImageBackground, StyleSheet } from 'react-native';
import { LinearGradient } from 'expo-linear-gradient';
import StartGameScreen from './screens/StartGameScreen';
````

---

## 📌 Step 3 – Wrap Content with `ImageBackground`

```tsx
export default function App() {
  return (
    <LinearGradient
      colors={['#4e0329', '#ddb52f']}
      style={styles.rootScreen}
    >
      <ImageBackground
        source={require('./assets/images/background.png')}
        resizeMode="cover"
        style={styles.rootScreen}
        imageStyle={styles.backgroundImage} // for transparency
      >
        <StartGameScreen />
      </ImageBackground>
    </LinearGradient>
  );
}
```

---

## 📌 Step 4 – Add Transparency to the Image

```tsx
const styles = StyleSheet.create({
  rootScreen: {
    flex: 1, // fill the full screen
  },
  backgroundImage: {
    opacity: 0.15, // 15% visible, 85% transparent
  },
});
```

> Notes:
> 
> - `imageStyle` prop is applied **only to the image inside ImageBackground**
>     
> - `opacity` controls transparency so the gradient "shimmers through"
>     
> - UI elements inside `<ImageBackground>` appear above the image automatically
>     

---

## ✅ Result

- **Gradient base** remains visible
    
- **Background image** overlays gradient with partial transparency
    
- **Input box and buttons** remain fully interactive and visible
    
- Easy to adjust `opacity` and `colors` for different visual effects
    

---

### 💡 Tips

- Use `resizeMode="cover"` to fill screen without distortion
    
- You can also experiment with `contain` or `stretch` if needed
    
- Combine with additional styling (padding, margins) for perfect layout
