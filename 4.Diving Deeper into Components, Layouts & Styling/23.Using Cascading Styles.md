# 1️⃣ Fixing Button Layout (Row + Spacing)

You correctly changed the layout from column → row:

```tsx
<View style={styles.buttonsContainer}>
  <View style={styles.buttonContainer}>
    <PrimaryButton onPress={nextGuessHandler.bind(this, 'lower')}>-</PrimaryButton>
  </View>

  <View style={styles.buttonContainer}>
    <PrimaryButton onPress={nextGuessHandler.bind(this, 'greater')}>+</PrimaryButton>
  </View>
</View>
```

### Styles:

```ts
buttonsContainer: {
  flexDirection: 'row',
  justifyContent: 'space-between',
  marginTop: 16,
},

buttonContainer: {
  flex: 1,
},
```

👉 Wrapping each button in its own container:

- gives better control over spacing
    
- allows equal width (`flex: 1`)
    
- avoids layout bugs later

# 2️⃣ The KEY Concept: Style Merging (VERY IMPORTANT)

React Native **does NOT support CSS cascading**, but you can simulate it using:

```tsx
style={[defaultStyle, incomingStyle]}
```

---

## ✅ Step 1: Accept a `style` prop

```tsx
export default function InstructionText({ children, style }) {
  return (
    <Text style={[styles.instructionText, style]}>
      {children}
    </Text>
  );
}
```

---

## ✅ Step 2: Use it from parent

```tsx
<InstructionText style={styles.instructionTextSpacing}>
  Higher or Lower?
</InstructionText>
```

```ts
instructionTextSpacing: {
  marginBottom: 12,
}
```

---

## 🔥 Why this is powerful

You now have:

- **Default styles** → defined inside the component
    
- **Extra styles** → passed from outside
    
- **Override capability** → parent can override child styles
    

---

## ⚠️ Order Matters

```tsx
style={[styles.instructionText, style]}
```

👉 Means:

- `styles.instructionText` applied first
    
- `style` (from parent) applied after → can override
    

---

### Example:

```ts
// inside component
fontSize: 20

// passed from parent
fontSize: 30
```

👉 Final result = **30** ✅

---

## 🧠 Mental Model

Think of it like:

```
Final Style = Default Style + Extra Style
```

---

# 3️⃣ Why This is Better Than Adding Margin in Parent

Instead of doing this:

```tsx
<View style={{ marginBottom: 12 }}>
  <InstructionText>...</InstructionText>
</View>
```

You do:

```tsx
<InstructionText style={{ marginBottom: 12 }}>
  ...
</InstructionText>
```

👉 Cleaner  
👉 More reusable  
👉 More flexible

---

# 4️⃣ What You Achieved Here

✅ Buttons aligned horizontally  
✅ Clean spacing between text and buttons  
✅ Reusable styling system  
✅ Component flexibility increased

---

# 5️⃣ Pro Tip (Advanced but Useful)

You can also combine multiple styles:

```tsx
<InstructionText style={[styles.spacing, styles.highlight]}>
  Text
</InstructionText>
```

---

# ✅ Final Summary

- Use `flexDirection: 'row'` for horizontal layout
    
- Wrap buttons for better spacing control
    
- Use `style={[default, incoming]}` to simulate CSS cascading
    
- Order matters → last style wins
    
- This pattern is used **everywhere in React Native**
