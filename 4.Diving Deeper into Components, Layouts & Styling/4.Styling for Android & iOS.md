
# 📱 React Native – Layout, Spacing & Cross-Platform Shadows

## 🧠 Core Idea
Now we improve the UI by:
- Positioning elements properly
- Adding spacing from screen edges
- Creating a styled container (card-like box)
- Handling **shadows differently for Android & iOS**

---

## 📦 Styling the Container (`inputContainer`)

### Create Styles

```tsx
import { StyleSheet } from 'react-native';

const styles = StyleSheet.create({
  inputContainer: {
    padding: 16,
    marginTop: 100,
    marginHorizontal: 24,
    backgroundColor: '#27063c',
    borderRadius: 8,
  },
});
````

---

## 🔑 Key Layout Concepts

### 1️⃣ `padding`

- Space **inside** the container
    
- Pushes content away from edges
    

```tsx
padding: 16
```

---

### 2️⃣ `margin`

- Space **outside** the container
    

```tsx
marginTop: 100
marginHorizontal: 24
```

👉 Keeps UI away from screen edges (better UX)

---

### 3️⃣ `flex`

#### With:

```tsx
flex: 1
```

- Takes **entire screen**
    

#### Without:

- Takes **only needed space**
    

👉 Removing `flex: 1` creates a **compact box** (what we want)

---

## 🎨 Creating a Card-Like UI

### Add Background

```tsx
backgroundColor: '#27063c'
```

👉 Visually separates the input area from the screen

---

### Add Rounded Corners

```tsx
borderRadius: 8
```

👉 Makes UI modern and clean

---

## 🌑 Adding Shadows (IMPORTANT)

### 🚨 Problem:

- No `box-shadow` like CSS
    

---

## 🤖 Android Shadow

```tsx
elevation: 4
```

- Simple
    
- Works **only on Android**
    

---

## 🍎 iOS Shadow

```tsx
shadowColor: 'black',
shadowOffset: { width: 0, height: 2 },
shadowOpacity: 0.25,
shadowRadius: 6,
```

### Explanation:

- `shadowColor` → color of shadow
    
- `shadowOffset` → position (x, y)
    
- `shadowOpacity` → transparency
    
- `shadowRadius` → blur/spread
    

---

## 🔥 Final Combined Style

```tsx
const styles = StyleSheet.create({
  inputContainer: {
    padding: 16,
    marginTop: 100,
    marginHorizontal: 24,
    backgroundColor: '#27063c',
    borderRadius: 8,

    // Android
    elevation: 4,

    // iOS
    shadowColor: 'black',
    shadowOffset: { width: 0, height: 2 },
    shadowOpacity: 0.25,
    shadowRadius: 6,
  },
});
```

---

## 🧩 Applying the Style

```tsx
<View style={styles.inputContainer}>
  <TextInput />
  <PrimaryButton>Reset</PrimaryButton>
  <PrimaryButton>Confirm</PrimaryButton>
</View>
```

---

## ⚙️ Why Platform Differences Exist

- React Native uses **native components**
    
- Android & iOS have:
    
    - Different rendering systems
        
    - Different styling capabilities
        

👉 So some styles:

- Work on both ✅
    
- Work only on one ❌
    

---

## 💡 Important Notes

- No `box-shadow` in React Native
    
- Always combine:
    
    - `elevation` (Android)
        
    - `shadow*` (iOS)
        
- UI building process:
    
    1. Structure
        
    2. Layout (spacing)
        
    3. Styling
        
    4. Polish (shadows, borders, etc.)
