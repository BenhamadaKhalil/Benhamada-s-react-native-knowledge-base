# ⚙️ Implementing Context Logic (Favorites State)

## 🧠 Core Idea
Now we move from a **context structure (shell)** → to a **fully working global state system**.

👉 We:
- Store favorite meal IDs using `useState`
- Implement logic to:
  - ➕ Add favorites
  - ➖ Remove favorites
- Expose everything through the Context Provider

---

## ⚙️ Key Concepts

### 📌 1. Managing State Inside Context

```js id="z7k2lm"
import { useState } from 'react';

const [favoriteMealIds, setFavoriteMealIds] = useState([]);
````

- `favoriteMealIds` → array of favorite meal IDs
    
- Initially empty: `[]`
    

---

### 📌 2. Updating State Based on Previous State

⚠️ VERY IMPORTANT RULE in React:

> When new state depends on old state → use a function

---

### ➕ Add Favorite

```js
function addFavorite(id) {
  setFavoriteMealIds((currentFavIds) => {
    return [...currentFavIds, id];
  });
}
```

#### 🧠 What happens:

- Take previous IDs
    
- Spread them into a new array
    
- Add new `id`
    

➡️ Immutable update (React best practice)

---

### ➖ Remove Favorite

```js
function removeFavorite(id) {
  setFavoriteMealIds((currentFavIds) => {
    return currentFavIds.filter((mealId) => mealId !== id);
  });
}
```

#### 🧠 What happens:

- Loop through IDs
    
- Keep only those NOT equal to `id`
    
- Effectively removes the selected favorite
    

---

## 📦 3. Preparing Context Value

```js
const value = {
  ids: favoriteMealIds,
  addFavorite: addFavorite,
  removeFavorite: removeFavorite,
};
```

#### 🧠 Important:

- Keys (`ids`, `addFavorite`, `removeFavorite`) must match context definition
    
- These names are what components will use later
    

---

## 🔗 4. Passing Value to Provider

```js
<FavoritesContext.Provider value={value}>
  {children}
</FavoritesContext.Provider>
```

---

## 🧩 Final Flow

```text
Component → calls addFavorite(id)
        ↓
Context updates state (useState)
        ↓
All subscribed components re-render
        ↓
Favorites screen updates automatically
```

---

## 💡 Notes & Tips

- ⚠️ NEVER mutate arrays like this:
    
    ```js
    currentFavIds.push(id) ❌
    ```
    
    Always create a **new array**
    
- ✅ Always use:
    
    - Spread operator (`...`)
        
    - `filter()` for removal
        
- 🧠 Context + useState = simple global state system
    
- 🔁 Any component using this context will:
    
    - Automatically re-render when data changes
