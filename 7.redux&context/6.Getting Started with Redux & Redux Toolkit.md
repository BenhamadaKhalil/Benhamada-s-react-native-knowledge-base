# 🧰 Redux Setup (Using Redux Toolkit)

## 🧠 Core Idea
We now switch from **Context API → Redux** to manage the same app-wide state.

👉 Important:
- You **only need ONE solution** (Context OR Redux)
- Redux is better for **large & complex apps**

---

## ⚙️ Key Concepts

### 📌 1. Redux Toolkit (Modern Redux)

👉 We use:
- `@reduxjs/toolkit` → core Redux logic (simplified)
- `react-redux` → connects Redux with React

---

```bash
npm install @reduxjs/toolkit react-redux
````

## 🏗️ Creating the Redux Store

### 📌 4. store.js

```js id="p4x7la"
import { configureStore } from '@reduxjs/toolkit';

export const store = configureStore({
  reducer: {},
});
````

---

### 🧠 What is the Store?

- Central place for:
    
    - All state (data)
        
    - All logic (reducers)
        

👉 Comparable to:

- Context Provider (but more powerful)
    

---

### 📌 5. Reducers (Concept)

- Store is made of **slices**
    
- Each slice manages:
    
    - A piece of state
        
    - Logic to update it
        

```text
Store
 ├── favoritesSlice
 ├── authSlice
 └── cartSlice
```

---

## 🔌 Connecting Redux to App

### 📌 6. Wrap App with Provider

In `App.js`:

```js
import { Provider } from 'react-redux';
import { store } from './store/redux/store';

export default function App() {
  return (
    <Provider store={store}>
      <NavigationContainer>
        {/* all screens */}
      </NavigationContainer>
    </Provider>
  );
}
```

---

### 🧠 Why Provider?

- Makes Redux store available globally
    
- Same concept as Context Provider

## 🔁 Context vs Redux (So Far)

|Feature|Context API|Redux Toolkit|
|---|---|---|
|Setup|Simple|More setup|
|Scalability|Medium|High|
|Structure|Flexible|Strict & predictable|
|Best for|Small/medium apps|Large apps|

## 💡 Notes & Tips

- 🧠 Redux = **centralized + predictable state management**
    
- ⚡ Redux Toolkit simplifies:
    
    - Boilerplate code
        
    - Setup complexity
        
- 📦 `react-redux` provides:
    
    - `<Provider />`
        
    - Hooks (later: `useSelector`, `useDispatch`)
