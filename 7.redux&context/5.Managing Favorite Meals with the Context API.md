# ♻️ Reusable Components + Favorites Screen Logic

## 🧠 Core Idea
Instead of duplicating code, we:
1. Extract the **meal list logic into a reusable component**
2. Use it in:
   - Meals Overview Screen
   - Favorites Screen

👉 This is a key concept: **Component Reusability**

---

## ⚙️ Key Concepts

### 📌 1. Extracting a Reusable Component

Create:
```

/components/MealsList/MealsList.js

````

👉 Move logic from:
- `MealsOverviewScreen`

Into:
- `MealsList` component

---

### 📌 2. MealsList Component

```js id="q2m7xa"
function MealsList({ items }) {
  function renderMealItem(itemData) {
    return <MealItem {...itemData.item} />;
  }

  return (
    <View>
      <FlatList
        data={items}
        keyExtractor={(item) => item.id}
        renderItem={renderMealItem}
      />
    </View>
  );
}
````

#### 🧠 Key Idea:

- `items` prop = dynamic data source
    
- Component is now **reusable anywhere**
    

---

### 📌 3. Using MealsList in Overview Screen

```js
<MealsList items={displayedMeals} />
```

➡️ Clean + modular code

---

## ❤️ Favorites Screen Implementation

### 📌 4. Access Context Again

```js
const favoritesCtx = useContext(FavoritesContext);
```

---

### 📌 5. Get Favorite Meals from Data

We don’t store full meals in context → only IDs

👉 So we must **map IDs → actual meal objects**

```js
const favoriteMeals = MEALS.filter((meal) =>
  favoritesCtx.ids.includes(meal.id)
);
```

#### 🧠 Logic:

- Loop through all meals
    
- Keep only meals whose ID is in favorites
    

---

### 📌 6. Render Favorites List

```js
<MealsList items={favoriteMeals} />
```

---

## ⚠️ 7. Handle Empty Favorites

```js
if (favoriteMeals.length === 0) {
  return (
    <View style={styles.rootContainer}>
      <Text style={styles.text}>
        You have no favorite meals yet.
      </Text>
    </View>
  );
}
```

## 🧩 Final Flow

```text
User favorites meals ⭐
        ↓
IDs stored in Context
        ↓
Favorites Screen loads
        ↓
Filter MEALS using IDs
        ↓
Render MealsList
```

## 💡 Notes & Tips

- ♻️ Reusability = cleaner + scalable apps
    
- 🧠 Store minimal data in context:
    
    - IDs instead of full objects (better performance)
        
- ⚡ `filter + includes` is a powerful combo:
    
    ```js
    array.filter(item => ids.includes(item.id))
    ```
    
- 🔁 Navigation still works:
    
    - Because all screens share same navigator
