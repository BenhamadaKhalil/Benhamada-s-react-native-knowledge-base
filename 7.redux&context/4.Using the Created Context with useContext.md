# ⭐ Using Context in Components (Meal Detail Screen)

## 🧠 Core Idea
Now we **consume the global state (Context)** inside a screen.

👉 Goal:
- Toggle favorite status when pressing ⭐
- Dynamically update the icon (filled vs outlined)
- Sync UI with global state

---

## ⚙️ Key Concepts

### 📌 1. Accessing Context with `useContext`

```js
import { useContext } from 'react';
import { FavoritesContext } from '../store/context/favorites-context';

const favoritesCtx = useContext(FavoritesContext);
````

#### 🧠 Important:

- `useContext` gives access to:
    
    - `ids`
        
    - `addFavorite`
        
    - `removeFavorite`
        
- ✅ Works exactly like React (web)
    
- ❗ Not React Native-specific
    

---

### 📌 2. Check if Meal is Favorite

```js
const mealIsFavorite = favoritesCtx.ids.includes(mealId);
```

#### 🧠 How it works:

- `ids` → array of favorite IDs
    
- `includes(mealId)` → returns:
    
    - `true` → is favorite
        
    - `false` → not favorite
        

---

### 📌 3. Dynamic Icon Rendering

```js
icon={mealIsFavorite ? 'star' : 'star-outline'}
```

#### 🧠 Behavior:

- ⭐ Filled → if favorite
    
- ☆ Empty → if NOT favorite
    

➡️ UI reacts automatically to state changes

---

### 📌 4. Toggle Favorite Status

```js
function changeFavoriteStatusHandler() {
  if (mealIsFavorite) {
    favoritesCtx.removeFavorite(mealId);
  } else {
    favoritesCtx.addFavorite(mealId);
  }
}
```

#### 🧠 Logic:

- If already favorite → remove it
    
- Else → add it
    

---

### 📌 5. Connect to Button

```js
onPress={changeFavoriteStatusHandler}
```

---

## 🧩 Full Flow

```text
User taps ⭐
      ↓
changeFavoriteStatusHandler()
      ↓
Context function called (add/remove)
      ↓
State updates (useState)
      ↓
Component re-renders
      ↓
Icon updates automatically
```

---

## 💡 Notes & Tips

- ⚡ `includes()` works best with:
    
    - Primitive values (like IDs)
        
- 🔁 No manual UI update needed:
    
    - React re-renders automatically
        
- 🧠 This is **reactive UI**:
    
    - UI = function(state)
        
- 📛 Rename handlers clearly:
    
    - `changeFavoriteStatusHandler` > `pressHandler`
        

---

## 🔗 Connections

- Uses:
    
    - Context (global state)
        
    - useState (inside provider)
        
- Connects:
    
    - UI (button) ↔ Global State
        

➡️ This is the **core React pattern**
