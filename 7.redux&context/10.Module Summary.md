## 🧰 Two Approaches to Global State

### 🟢 Context API
- Built into React
- Simple & lightweight
- Good for small to medium apps

---

### 🔵 Redux Toolkit
- External library
- More structured & scalable
- Better for large/complex apps

---

## 🔁 Key Takeaway

> React Native = React (same concepts, different platform)

👉 There is **nothing React Native-specific** about:
- Context API
- Redux
- State management

---

## 🧩 Architecture You Learned

```text id="m2z9vr"
UI (Screens / Components)
        ↓
State Management (Context / Redux)
        ↓
Shared Global Data
        ↓
Reactive UI Updates
````
