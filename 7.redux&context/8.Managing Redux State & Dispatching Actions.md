# 🔄 Using Redux in Components (Meal Detail Screen)

## 🧠 Core Idea
Now we **replace Context with Redux** inside components.

👉 We need to:
- 📖 Read data from Redux → `useSelector`
- ⚡ Update data → `useDispatch`

---

## ⚙️ Key Concepts

### 📌 1. Reading Data with `useSelector`

```js
import { useSelector } from 'react-redux';

const favoriteMealIds = useSelector((state) => state.favoriteMeals.ids);
````

#### 🧠 How it works:

- `state` → entire Redux store
    
- `favoriteMeals` → slice name (from store.js)
    
- `ids` → actual data
    

---

### 📌 2. Check if Meal is Favorite

```js
const mealIsFavorite = favoriteMealIds.includes(mealId);
```

➡️ Same logic as Context, but data comes from Redux

---

### 📌 3. Dispatching Actions

```js
import { useDispatch } from 'react-redux';

const dispatch = useDispatch();
```

#### 🧠 Dispatch:

- Sends actions to Redux store
    
- Triggers reducers
    

---

### 📌 4. Import Actions

```js
import { addFavorite, removeFavorite } 
from '../store/redux/favorites';
```

---

### 📌 5. Toggle Favorite Status

```js
function changeFavoriteStatusHandler() {
  if (mealIsFavorite) {
    dispatch(removeFavorite({ id: mealId }));
  } else {
    dispatch(addFavorite({ id: mealId }));
  }
}
```

---

### 📌 6. Why `{ id: mealId }`?

Because reducers expect:

```js
action.payload.id
```

➡️ So payload must be an object with `id`

---

## 🧩 Full Flow

```text
User taps ⭐
      ↓
dispatch(action)
      ↓
Redux reducer runs
      ↓
State updated
      ↓
useSelector detects change
      ↓
Component re-renders
      ↓
Icon updates
```

---

## 💡 Notes & Tips

- ⚡ `useSelector` automatically subscribes to store  
    → component re-renders on change
    
- 🧠 Redux pattern:
    
    - Read → `useSelector`
        
    - Write → `dispatch()`
        
- ❗ Never call reducers directly:
    
    ```js
    addFavorite() ❌
    dispatch(addFavorite()) ✅
    ```
    
- 🔁 Same UI logic as Context:
    
    - Only data source changed
        

---

## 🔗 Connections

- Replaces:
    
    - `useContext`
        
- Uses:
    
    - Redux store
        
    - Slice reducers
        

➡️ Same architecture, different tool
