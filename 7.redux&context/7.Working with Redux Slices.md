# 🧩 Redux Logic with createSlice (Favorites Feature)

## 🧠 Core Idea
In Redux Toolkit, we organize logic using **Slices**.

👉 A slice = 
- State (data)
- Reducers (functions to update state)
- Actions (auto-generated)

---

## ⚙️ Key Concepts

### 📌 1. Create a Slice File

```

/store/redux/favorites.js

````id="p1x8cm"

👉 Keep logic **modular per feature**

---

### 📌 2. Creating the Slice

```js
import { createSlice } from '@reduxjs/toolkit';

const favoritesSlice = createSlice({
  name: 'favorites',
  initialState: {
    ids: [],
  },
  reducers: {
    addFavorite: (state, action) => {},
    removeFavorite: (state, action) => {},
  },
});
````

---

### 📌 3. Initial State

```js
initialState: {
  ids: [],
}
```

- Same idea as Context
    
- Stores favorite meal IDs
    

---

### 📌 4. Reducers (State Logic)

#### ➕ Add Favorite

```js
addFavorite: (state, action) => {
  state.ids.push(action.payload.id);
}
```

---

#### ➖ Remove Favorite

```js
removeFavorite: (state, action) => {
  const index = state.ids.indexOf(action.payload.id);
  state.ids.splice(index, 1);
}
```

---

### 🧠 Important Redux Toolkit Feature

⚠️ This looks like mutation:

```js
state.ids.push(...)
```

BUT 👉 it’s SAFE because:

- Redux Toolkit uses **Immer internally**
    
- It converts mutations → immutable updates
    

---

### 📌 5. Action Payload

```js
action.payload.id
```

#### 🧠 Meaning:

- `action` = object created by Redux
    
- `payload` = custom data we send
    

Example later:

```js
dispatch(addFavorite({ id: 'm1' }));
```

---

## 📦 6. Exporting

### Reducer (for store)

```js
export default favoritesSlice.reducer;
```

---

### Actions (for components)

```js
export const addFavorite = favoritesSlice.actions.addFavorite;
export const removeFavorite = favoritesSlice.actions.removeFavorite;
```

---

## 🔗 7. Connect Slice to Store

In `store.js`:

```js
import { configureStore } from '@reduxjs/toolkit';
import favoritesReducer from './favorites';

export const store = configureStore({
  reducer: {
    favoriteMeals: favoritesReducer,
  },
});
```

---

### 🧠 Store Structure Now

```text
store
 └── favoriteMeals
       └── ids: []
```

---

## 🧩 Final Flow

```text
Component → dispatch(addFavorite({ id }))
        ↓
Reducer runs (addFavorite)
        ↓
State updated in store
        ↓
Subscribed components update
```

---

## 💡 Notes & Tips

- 🧠 Slice = feature-based structure (best practice)
    
- 📦 Keep each feature in its own file
    
- ⚡ Redux Toolkit advantages:
    
    - Less boilerplate
        
    - Simpler reducers
        
    - Built-in immutability
        
- 🔁 Difference from Context:
    
    - Context → manual logic
        
    - Redux → structured system with actions
        

---

## 🔗 Connections

- Similar to Context:
    
    - Global state
        
    - Central logic
        
- But Redux adds:
    
    - Actions (dispatch system)
        
    - Better scalability
