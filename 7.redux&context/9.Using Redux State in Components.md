
# ❤️ Using Redux in Favorites Screen

## 🧠 Core Idea
We now complete the Redux integration by using it in the **Favorites Screen**.

👉 Goal:
- Read favorite IDs from Redux
- Filter meals
- Display them using the reusable `MealsList` component

---

## ⚙️ Key Concepts

### 📌 1. Replace Context with Redux

❌ Remove:
```js
useContext(FavoritesContext)
````

✅ Use Redux instead:

```js
import { useSelector } from 'react-redux';
```

---

### 📌 2. Read Favorite IDs from Store

```js
const favoriteMealIds = useSelector(
  (state) => state.favoriteMeals.ids
);
```

#### 🧠 Reminder:

- `state.favoriteMeals` → slice name
    
- `.ids` → stored data
    

---

### 📌 3. Filter Favorite Meals

```js
const favoriteMeals = MEALS.filter((meal) =>
  favoriteMealIds.includes(meal.id)
);
```

#### 🧠 Logic:

- Loop through all meals
    
- Keep only meals that are in favorites
    

---

### 📌 4. Render Meals List

```js
<MealsList items={favoriteMeals} />
```

---

## 🧩 Full Flow

```text
Redux Store (ids)
        ↓
Favorites Screen (useSelector)
        ↓
Filter meals
        ↓
Render MealsList
```

---

## 💡 Notes & Tips

- 🔁 Same logic as Context version:
    
    - Only difference = data source (Redux instead of Context)
        
- ⚡ `useSelector` auto-updates UI:
    
    - When state changes → screen re-renders
        
- 🧠 Redux is **global + reactive**
    
    - No manual syncing needed
