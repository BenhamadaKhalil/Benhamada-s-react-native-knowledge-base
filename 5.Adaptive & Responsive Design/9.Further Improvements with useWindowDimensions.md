
# 📱 React Native – Game Over Screen (Responsive + Scrollable)

## 🚀 Main Idea
The Game Over screen had two problems:

- Image too large ❌
- Content not accessible (no scrolling) ❌

👉 Solution:
- Use **dynamic image sizing (useWindowDimensions)**
- Add **ScrollView for accessibility**

---

## 🧠 Key Concepts

### 1. 📏 Dynamic Image Size (Width + Height)

Instead of static values:
```js
width: 300,
height: 300
````

👉 Use responsive logic based on:

- **device width**
    
- **device height**
    

---

### 2. 🔄 Reacting to Orientation Changes

Using:

```js
const { width, height } = useWindowDimensions();
```

✔ Automatically updates when rotating device

---

### 3. 🎯 Multiple Conditions

We can adjust image size based on:

- Small width → smaller image
    
- Small height (landscape) → even smaller image
    

---

## ⚛️ In React Native

### Step 1: Get Dimensions

```js
const { width, height } = useWindowDimensions();
```

---

### Step 2: Calculate Image Size

```js
let imageSize = 300;

if (width < 380) {
  imageSize = 150;
}

if (height < 400) {
  imageSize = 80;
}
```

---

### Step 3: Create Dynamic Style

```js
const imageStyle = {
  width: imageSize,
  height: imageSize,
  borderRadius: imageSize / 2,
};
```

---

### Step 4: Merge Styles

```js
<View style={[styles.imageContainer, imageStyle]}>
```

---

## 🔄 Behavior

|Condition|Image Size|
|---|---|
|Large screen|300|
|Small width|150|
|Small height|80|

👉 Works perfectly in portrait & landscape

---

## 📜 Making Screen Scrollable

### Step 5: Add ScrollView

```js
import { ScrollView } from "react-native";

<ScrollView style={styles.screen}>
  <View style={styles.rootContainer}>
    {/* content */}
  </View>
</ScrollView>
```

---

### Step 6: Ensure Full Height

```js
screen: {
  flex: 1,
}
```

---

## 💡 Tips

- Always consider both:
    
    - **width** (device size)
        
    - **height** (orientation)
        
- Use **multiple breakpoints** if needed
    
- Merge styles instead of replacing them
    
- Add ScrollView for:
    
    - small devices
        
    - landscape mode
        

---

## 🔥 Key Insight

> Good UI is not fixed —  
> it adapts to **space, orientation, and constraints**

---

## 📌 Summary

- Replace static image size with dynamic logic
    
- Use `useWindowDimensions` for real-time updates
    
- Adjust size based on width AND height
    
- Merge dynamic styles with existing styles
    
- Add ScrollView for better accessibility
    
- Result → usable UI on all devices & orientations
