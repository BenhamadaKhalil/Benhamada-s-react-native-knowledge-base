
# 📱 React Native – Responsive Sizing (Width, Min/Max)

## 🚀 Main Idea
To improve UI on different screen sizes, we can use:
- **relative units (%)**
- **minWidth / maxWidth**

👉 This allows components to **adapt instead of staying fixed**

---

## 🧠 Key Concepts

### 1. 📏 Fixed vs Flexible Width

- ❌ `width: 300` → always 300px (not responsive)
- ✅ `width: "80%"` → always 80% of parent
- ✅ `maxWidth: "80%"` → flexible limit (better)

---

### 2. 🎯 maxWidth vs width

- `width` → forces exact size
- `maxWidth` → sets an **upper limit**

👉 Best practice:
```js
width: 300,
maxWidth: "80%"
````

✔ Behavior:

- On **large screens** → uses 300px
    
- On **small screens** → shrinks to 80%
    

---

### 3. 📦 Parent-Child Relationship

⚠️ Important rule:

> Percentages (%) are always based on the **parent container**

Example:

```js
maxWidth: "80%"
```

👉 Means:

- 80% of the **parent View width**, NOT the screen
    

---

## ⚛️ In React Native

### Example: Fixing a Title Component

```js
// inside Title component
title: {
  width: 300,
  maxWidth: "80%",
}
```

---

### Centering Issue (Flexbox)

After applying maxWidth, element may not be centered.

✔ Fix in parent container:

```js
<View style={{ alignItems: "center" }}>
```

👉 Because:

- React Native uses **Flexbox by default**
    
- `alignItems: "center"` centers horizontally
    

---

## 💡 Tips

- Use **maxWidth instead of width** for responsiveness
    
- Combine:
    
    - fixed value (for large screens)
        
    - percentage (for small screens)
        
- Always remember:
    
    - `%` depends on **parent**, not screen
        
- Same logic applies to:
    
    - `height`
        
    - `minWidth`
        
    - `minHeight`
        
    - `maxHeight`
        

---

## 🔥 Key Insight

> Responsive design = **constraints, not fixed values**

---

## 📌 Summary

- Fixed sizes break on small devices
    
- `maxWidth` allows flexible resizing
    
- Combine `width + maxWidth` for best results
    
- Percentages are based on **parent container**
    
- Use Flexbox (`alignItems`) to fix alignment issues
