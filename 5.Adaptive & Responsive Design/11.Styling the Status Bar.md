# ⬆️ StatusBar Component

### 1️⃣ What It Is

- The **StatusBar** component allows you to control the **appearance of the status bar** on iOS and Android.
    
- Can be used **globally** in your app or **per screen/component**.
    

---

### 2️⃣ How to Import

From Expo:

```js
import { StatusBar } from 'expo-status-bar';
```

---

### 3️⃣ How to Use

Add it inside your root component (or specific screen component):

```js
import { StatusBar } from 'expo-status-bar';

export default function App() {
  return (
    <>
      <LinearGradient /* your root component */>
        {/* app content */}
      </LinearGradient>
      <StatusBar style="light" />
    </>
  );
}
```

- Wrap with a fragment `<> </>` if you have **multiple root components**.
    

---

### 4️⃣ Styling Options

- `style="light"` → white text/icons (good for dark backgrounds)
    
- `style="dark"` → dark text/icons (good for light backgrounds)
    

You can pick the one that **matches your app design**.

---

### 5️⃣ Why It’s Important

- Ensures the **status bar is visible**.
    
- Lets you **customize appearance per screen**.
    
- Adds polish to your app and avoids **default or missing status bars**.
