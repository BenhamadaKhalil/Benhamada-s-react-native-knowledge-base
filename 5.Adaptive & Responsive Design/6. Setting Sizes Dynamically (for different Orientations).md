
# 📱 React Native – Dynamic Orientation Handling (useWindowDimensions)

## 🚀 Main Idea
Using `Dimensions.get()` is **static** ❌  
👉 It does NOT update when the screen rotates

✔ Solution: use **`useWindowDimensions()` hook**  
→ Automatically reacts to **screen size & orientation changes**

---

## 🧠 Key Concepts

### 1. ❌ Problem with Static Dimensions

```js
const deviceHeight = Dimensions.get("window").height;
````

- Runs **only once**
    
- Does NOT update on rotation
    
- Can cause **wrong layout after orientation change**
    

---

### 2. ✅ Dynamic Solution: useWindowDimensions

```js
import { useWindowDimensions } from "react-native";

const { width, height } = useWindowDimensions();
```

✔ Benefits:

- Updates automatically 🔄
    
- Triggers re-render when size changes
    
- Perfect for **responsive + orientation-aware UI**
    

---

### 3. ⚠️ Important Rule

> Code that depends on screen size must be **inside the component function**

❌ Outside → runs once  
✅ Inside → runs on every re-render

---

## ⚛️ In React Native

### Example: Dynamic Margin Based on Height

```js
const { height } = useWindowDimensions();

const marginTopDistance = height < 400 ? 30 : 100;
```

---

### Applying Dynamic Styles

```js
<View style={[styles.container, { marginTop: marginTopDistance }]}>
```

✔ This merges:

- Static styles (`styles.container`)
    
- Dynamic styles (based on screen size)
    

---

## 🔄 Behavior

|Orientation|Height|Margin|
|---|---|---|
|Portrait|Large|100|
|Landscape|Small|30|

👉 Automatically updates when rotating device

---

## 💡 Tips

- Use:
    
    - `Dimensions.get()` → for **fixed initial values**
        
    - `useWindowDimensions()` → for **dynamic UI**
        
- Always compute responsive values:
    
    - **inside component**
        
- Combine with:
    
    - conditional styles
        
    - flexbox
        

---

## 🔥 Key Insight

> Responsive design is not just about size —  
> it's about **reacting to changes in real time**

---

## 📌 Summary

- `Dimensions.get()` is static
    
- `useWindowDimensions()` is dynamic
    
- Hook re-runs on orientation change
    
- Must be used inside component
    
- Enables real-time responsive UI updates
