
# 📱 React Native – Conditional Layout (Portrait vs Landscape)

## 🚀 Main Idea
Responsive design is not just about resizing ❌

👉 Sometimes you need to **change the entire layout structure**

✔ Solution: **Conditional rendering based on screen width**

---

## 🧠 Key Concepts

### 1. 📐 Detecting Landscape Mode

Using `useWindowDimensions`:

```js id="d1f8kl"
const { width, height } = useWindowDimensions();
````

👉 Example condition:

```js
const isLandscape = width > 500;
```

---

### 2. 🔄 Conditional UI Rendering

Instead of adjusting styles only:

👉 You can render **completely different JSX**

---

## ⚛️ In React Native

### Step 1: Default Layout (Portrait)

```js
let content = (
  <>
    <NumberContainer>{currentGuess}</NumberContainer>
    <Card>{/* buttons */}</Card>
  </>
);
```

---

### Step 2: Change Layout for Landscape

```js
if (width > 500) {
  content = (
    <View style={styles.buttonsContainerWide}>
      <View>{/* button */}</View>
      <NumberContainer>{currentGuess}</NumberContainer>
      <View>{/* button */}</View>
    </View>
  );
}
```

---

### Step 3: Render Dynamic Content

```js
return (
  <>
    <Title>Opponent's Guess</Title>
    {content}
  </>
);
```

---

### Step 4: Styling for Landscape

```js
buttonsContainerWide: {
  flexDirection: "row",
  alignItems: "center",
}
```

---

## 🎯 What Changed?

### Portrait Mode 📱

- Vertical layout
    
- Number + buttons below
    

### Landscape Mode 📲

- Horizontal layout
    
- Buttons on sides
    
- Number in center
    

---

## 💡 Tips

- You can:
    
    - Remove unnecessary elements in landscape
        
    - Rearrange components completely
        
- Use **fragments (`<> </>`)** for multiple root elements
    
- Choose breakpoints carefully (e.g. `500`, `600`)
    
- Combine with spacing adjustments (margin/padding)
    

---

## 🔥 Key Insight

> True responsiveness =  
> **changing layout structure, not just sizes**

---

## ⚠️ Important Note

- Landscape often means:
    
    - Less height ❌
        
    - More width ✅
        

👉 Optimize for usability, not just appearance

---

## 📌 Summary

- Use `useWindowDimensions` to detect layout changes
    
- Apply conditional rendering for different UIs
    
- Landscape may require **completely different structure**
    
- Flexbox (`row`) is key for horizontal layouts
    
- Improves usability on all devices
