
# 📱 React Native – Responsive Images with Dimensions API

## 🚀 Main Idea
Hardcoded sizes (e.g. `300px`) can break your UI ❌

👉 Especially for **images**, which may look:
- Too big on small devices
- Too small on large devices

✔ Solution: Use **Dimensions API** to scale dynamically

---

## 🧠 Key Concepts

### 1. ❌ Problem with Hardcoded Values

```js
width: 300,
height: 300
````

- Works on some devices ✅
    
- Breaks on smaller screens ❌
    

---

### 2. ⚠️ Why % Doesn't Work Here

```js
width: "50%",
height: "50%"
```

❌ Problem:

- Width % → based on parent width
    
- Height % → based on parent height
    

👉 Result:

- Not equal → **not a square**
    
- Circle becomes distorted ❌
    

---

### 3. ✅ Best Solution: Dimensions API

We want:

- Same width & height (square)
    
- Different sizes depending on device
    

---

## ⚛️ In React Native

### Step 1: Get Device Width

```js
import { Dimensions } from "react-native";

const deviceWidth = Dimensions.get("window").width;
```

---

### Step 2: Apply Responsive Logic

```js
const imageSize = deviceWidth < 380 ? 150 : 300;
```

---

### Step 3: Use in Styles

```js
imageContainer: {
  width: imageSize,
  height: imageSize,
  borderRadius: imageSize / 2,
}
```

---

### Step 4: Image Fills Container

```js
image: {
  width: "100%",
  height: "100%",
}
```

---

## 💡 Tips

- Always keep **width = height** for circles
    
- `borderRadius = width / 2` → perfect circle
    
- Use **one variable (imageSize)** to avoid duplication
    
- Prefer **Dimensions over %** when shape matters
    

---

## 🔥 Key Insight

> Use percentages for layout,  
> use Dimensions when **precision and shape matter**

---

## 📌 Summary

- Hardcoded sizes are not responsive
    
- % values can break aspect ratio
    
- Dimensions API allows dynamic sizing
    
- Use same value for width & height
    
- Adjust borderRadius accordingly
    
- Result → consistent UI across devices
