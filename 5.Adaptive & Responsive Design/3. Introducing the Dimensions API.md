
# 📱 React Native – Dimensions API (Responsive Logic)

## 🚀 Main Idea
Sometimes **min/max width is not enough** ❌

👉 You need **dynamic behavior based on screen size**

✔ Solution: **Dimensions API**

---

## 🧠 Key Concepts

### 1. 📊 What is Dimensions API?

- Built-in React Native API
- Gives access to:
  - device **width**
  - device **height**
  - **font scaling**

👉 Used in **JavaScript logic**, not JSX

---

### 2. 📱 Getting Screen Size

```js id="zq9k2m"
import { Dimensions } from "react-native";

const deviceWidth = Dimensions.get("window").width;
const deviceHeight = Dimensions.get("window").height;
````

---

### 3. ⚠️ "window" vs "screen"

- `"window"` ✅ → usable UI area
    
- `"screen"` → includes status bar (Android)
    

👉 Best practice: use `"window"`

---

### 4. 🎯 Responsive Logic with Conditions

Instead of fixed values, use conditions:

```js
padding: deviceWidth < 380 ? 12 : 24
```

✔ Behavior:

- Small device → smaller padding
    
- Large device → bigger padding
    

---

### 5. 🧩 What Can You Adjust?

Using Dimensions, you can dynamically change:

- 📏 Padding
    
- 📐 Margin
    
- 🔤 Font size
    
- 📦 Layout spacing
    

---

## ⚛️ In React Native

### Example: Responsive Styles

```js
const deviceWidth = Dimensions.get("window").width;

const styles = StyleSheet.create({
  container: {
    padding: deviceWidth < 380 ? 12 : 24,
    margin: deviceWidth < 380 ? 10 : 20,
  },
  text: {
    fontSize: deviceWidth < 380 ? 28 : 36,
  },
});
```

---

### Example: Fixing Layout Spacing

```js
marginTop: deviceWidth < 380 ? 18 : 36
```

👉 Reduces large gaps on small devices

---

## 💡 Tips

- Choose good **breakpoints** (e.g. 380px)
    
- Use:
    
    - **ternary operators** for simple logic
        
    - **calculations** for advanced scaling
        
- Apply changes **only where needed** (don’t overcomplicate)
    
- Combine with:
    
    - `maxWidth`
        
    - Flexbox
        

---

## 🔥 Key Insight

> Responsive UI = **Reacting to available space, not guessing it**

---

## 📌 Summary

- Some UI issues need **dynamic adjustments**
    
- `Dimensions` gives access to device size
    
- Use `"window"` for accurate layout size
    
- Apply conditions to:
    
    - padding
        
    - margin
        
    - font size
        
- Helps create **better UX on small devices**
