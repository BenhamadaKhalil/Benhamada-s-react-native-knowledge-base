# 🎬 Styling Custom Inputs in React Native (Expense Form)

## 🧠 Core Concept
In this step, we style our reusable `Input` component to improve:

- Layout spacing
- Readability
- Input clarity
- UX consistency across platforms

We also introduce **conditional styling** for multiline inputs.

---

## 🎨 1. Setting Up Styles with StyleSheet

We define a `styles` object using React Native:

```js id="s1k2pl"
import { StyleSheet } from 'react-native';

const styles = StyleSheet.create({
  inputContainer: {},
  label: {},
  input: {},
  inputMultiline: {}
});
````

👉 We style 3 main parts:

- Container (wrapper)
    
- Label
    
- TextInput field
    

---

## 📦 2. Input Container Styling

### 📌 Purpose

Controls spacing between multiple inputs

```js
inputContainer: {
  marginHorizontal: 4,
  marginVertical: 8
}
```

---

### 🧠 Why it matters

- `marginHorizontal`: spacing left/right
    
- `marginVertical`: spacing between inputs
    

👉 Without this → form looks cramped

---

## 🏷️ 3. Label Styling

```js
label: {
  fontSize: 12,
  color: GlobalStyles.colors.primary100,
  marginBottom: 4
}
```

---

### 🧠 Key ideas

- Smaller font size (12) → subtle label
    
- Color from `GlobalStyles` → design consistency
    
- `marginBottom` → separates label from input
    

---

## ⌨️ 4. Input Field Styling

```js
input: {
  backgroundColor: GlobalStyles.colors.primary100,
  padding: 6,
  borderRadius: 6,
  fontSize: 18,
  color: GlobalStyles.colors.primary700
}
```

---

### 🧠 Why these styles matter

- Background color → improves visibility
    
- Padding → better spacing inside input
    
- Border radius → modern UI feel
    
- Font size → improves readability
    
- Text color → ensures contrast
    

---

## 📏 5. Multiline Input Styling

We create a special style for larger text input:

```js
inputMultiline: {
  minHeight: 100,
  textAlignVertical: 'top'
}
```

---

### 🧠 Explanation

- `minHeight`: ensures visible height even when empty
    
- `textAlignVertical: 'top'`:
    
    - Ensures text starts at top (Android fix)
        
    - Matches iOS behavior
        

👉 Important for cross-platform consistency

---

## 🔁 6. Conditional Styling Logic

We dynamically apply styles based on props:

### 📌 Step 1: Base styles array

```js
const inputStyles = [styles.input];
```

---

### 📌 Step 2: Check config

```js
if (textInputConfig?.multiline) {
  inputStyles.push(styles.inputMultiline);
}
```

---

### 🧠 Why this works

- Always start with base input style
    
- Add extra styles only when needed
    
- Keeps component flexible and reusable
    

---

## 🧩 7. Applying Styles in JSX

```js
<View style={styles.inputContainer}>
  <Text style={styles.label}>{label}</Text>

  <TextInput
    style={inputStyles}
    {...textInputConfig}
  />
</View>
```

---

## ⚙️ Mental Model

Think of styling like layers:

```
Base Input Style
   ↓
Conditional Enhancements (e.g. multiline)
   ↓
Final Combined Style Array
```

👉 React Native allows multiple styles via arrays

---

## 🚨 Common Mistakes

- ❌ Forgetting `marginVertical` between inputs
    
- ❌ Not using `textAlignVertical: 'top'` on Android
    
- ❌ Hardcoding styles instead of using conditional logic
    
- ❌ Not separating base vs conditional styles
    
- ❌ Forgetting that style arrays are mergeable
    

---

## 🧪 Takeaways

- Use `StyleSheet` for structured styling
    
- Keep input layout consistent with spacing
    
- Use conditional styles for features like multiline
    
- Always think in reusable components
    
- Style arrays = powerful React Native pattern
    

---

## ⚡ Quick Summary

- Style container, label, input separately
    
- Add spacing using margins
    
- Improve UX with padding + font size
    
- Add multiline styling (`minHeight`, `textAlignVertical`)
    
- Use conditional style array logic for flexibility
