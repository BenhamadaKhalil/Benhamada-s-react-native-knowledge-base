# 🔥 Setting Up Firebase as a Backend (React Native)

## 🧩 Concept
Instead of building a custom backend, we use **Firebase** as a **ready-to-use backend service**.

Firebase provides:
- A **database**
- An automatically generated **REST API**
- Easy setup with no backend coding required

---

## ⚙️ Why Firebase?

- No need to build backend (Node.js, Django, etc.)
- Provides a **REST API out of the box**
- Lets us:
  - Store data
  - Fetch data
  - Update data
  - Delete data

💡 Important:
> Even though we use Firebase, the same concepts apply to any backend API.

---

## 🔄 REST API vs GraphQL

Two common ways to communicate with a backend:

- **REST API** (used here)
  - Multiple endpoints (URLs)
  - Simple and widely used

- **GraphQL**
  - More flexible queries
  - More complex setup

👉 Firebase gives us a **simple REST API**, perfect for learning.

---

## 🚀 Firebase Setup Steps

### 1. Create Account
- Go to Firebase website
- Sign in with a Google account

---

### 2. Create a Project
- Click **Create Project**
- Choose any name (e.g. `react-native-course`)
- Disable analytics (optional)
- Create project

---

### 3. Choose Database

Firebase provides two options:
- **Realtime Database ✅ (used here)**
- Firestore (more advanced)

👉 We use **Realtime Database** because:
- Easier to use
- Works well with REST API

---

### 4. Create Database

- Click **Realtime Database**
- Click **Create Database**
- Choose region (default is fine)

---

### 5. Security Rules

- Select **Test Mode**

⚠️ This allows:
- Read & write without authentication

👉 Only for development (not production)

---

## 🔗 How Firebase Works Behind the Scenes

Even though it looks like we are sending requests directly to a database:

👉 Actually:
- We send HTTP requests to a **Firebase REST API**
- Firebase translates those into **database operations**

---

## 🌐 Important: Database URL

- Firebase gives you a **URL**
- This URL will be used to:
  - Send requests
  - Fetch data

Example:
```

[https://your-project-id.firebaseio.com/](https://your-project-id.firebaseio.com/)

````

👉 This is your **API endpoint**

---

## 💻 Example Request Idea

```js
fetch("https://your-project-id.firebaseio.com/data.json", {
  method: "POST",
  body: JSON.stringify({ title: "Test" }),
});
````

---

## ⚠️ Notes / Pitfalls

- Test mode is **not secure** → never use in production
    
- Always include `.json` at the end of Firebase URLs
    
- You are **not directly accessing DB**, but an API layer
    
- Keep your base URL stored in a config file later
    

---

## 🔑 Key Takeaways

- Firebase is a **backend-as-a-service**
    
- It provides a **REST API automatically**
    
- Realtime Database is used for simplicity
    
- You interact using **HTTP requests**
    
- The **database URL is crucial** for all requests
