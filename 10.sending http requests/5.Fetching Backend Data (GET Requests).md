
# 📥 Fetching Data from Firebase (GET Request + Transformation)

## 🧩 Concept
After storing data, the next step is to **retrieve expenses from the backend**.

This means:
- Sending a **GET request** to Firebase
- Receiving data in a Firebase-specific format
- Transforming it into a usable array for the app

---

## ⚙️ Improving URL Structure

Instead of repeating the Firebase URL everywhere:

❌ Bad:
```js
"https://project.firebaseio.com/expenses.json"
````

👉 Create a reusable constant:

```js
const BACKEND_URL = "https://your-project-id.firebaseio.com/";
```

Now build URLs like:

```js
BACKEND_URL + "expenses.json"
```

💡 Benefit:

- Easier maintenance
    
- Easy switch between dev / production backend
    

---

## 🚀 Creating fetchExpenses Function

In `http.js`:

```js
import axios from "axios";

const BACKEND_URL = "https://your-project-id.firebaseio.com/";

export async function fetchExpenses() {
  const response = await axios.get(BACKEND_URL + "expenses.json");

  const expenses = [];

  for (const key in response.data) {
    const expenseObj = {
      id: key,
      amount: response.data[key].amount,
      date: new Date(response.data[key].date),
      description: response.data[key].description,
    };

    expenses.push(expenseObj);
  }

  return expenses;
}
```

---

## 🔥 Understanding Firebase Response Shape

Firebase returns data like this:

```json
{
  "abc123": {
    "amount": 50,
    "date": "2026-04-18",
    "description": "Food"
  },
  "xyz456": {
    "amount": 20,
    "date": "2026-04-17",
    "description": "Transport"
  }
}
```

### Problem:

- Data is an **object**, not an array
    
- Keys = unique IDs
    

---

## 🔄 Transformation Step

We convert:

👉 Firebase object  
➡️ Into  
👉 Array of expense objects

Final format:

```js
[
  {
    id: "abc123",
    amount: 50,
    date: Date,
    description: "Food"
  }
]
```

---

## ⚙️ Why We Transform Date

Firebase stores dates as strings:

```txt
"2026-04-18"
```

We convert it:

```js
new Date("2026-04-18")
```

💡 Reason:

- Easier manipulation (sorting, formatting, filtering)
    

---

## 📲 Using fetchExpenses in RecentExpenses

### 1. Create async helper inside useEffect

```js
useEffect(() => {
  async function getExpenses() {
    const expenses = await fetchExpenses();
    setExpenses(expenses);
  }

  getExpenses();
}, []);
```

---

## ⚠️ Why Not Make useEffect async?

❌ Wrong:

```js
useEffect(async () => { ... })
```

### Why:

- `useEffect` must NOT return a Promise
    
- React expects either:
    
    - nothing
        
    - or a cleanup function
        

👉 Solution: inner async function (wrapper pattern)

---

## 🔄 Full Flow

1. Component mounts (`RecentExpenses`)
    
2. `useEffect` runs
    
3. `getExpenses()` is called
    
4. `fetchExpenses()` sends GET request
    
5. Firebase returns object data
    
6. We transform it into array
    
7. UI state is updated (`setExpenses`)
    

---

## ⚠️ Notes / Pitfalls

- Firebase returns **objects, not arrays**
    
- Always convert IDs into `id` field manually
    
- Never make `useEffect` async directly
    
- Always convert date strings back into `Date`
    
- Centralize backend URL in one constant
    

---

## 🔑 Key Takeaways

- Use **GET request** to fetch data from Firebase
    
- Firebase returns **keyed objects**
    
- You must **transform data into arrays**
    
- Always handle async logic inside `useEffect` safely
    
- Backend logic should stay in a **separate HTTP utility file**
