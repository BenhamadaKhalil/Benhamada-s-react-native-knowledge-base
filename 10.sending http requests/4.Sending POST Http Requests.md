# ➕ Sending Data to Firebase (POST Request with Axios)

## 🧩 Concept
The first backend interaction is **adding (storing) expenses** in Firebase.

Even though we keep a **local copy (context)** for offline use, we also:
- Send the data to the backend
- Store it permanently in the database

---

## ⚙️ Organizing HTTP Logic

Instead of writing requests inside components ❌  
👉 Create a **helper file**:

```

/util/http.js

````

This file will:
- Contain all HTTP-related functions
- Keep components clean and focused on UI

---

## 🚀 Creating a Store Function

In `http.js`, create a function to send data:

```js id="a2v7kp"
import axios from "axios";

export function storeExpense(expenseData) {
  return axios.post(
    "https://your-project-id.firebaseio.com/expenses.json",
    expenseData
  );
}
````

---

## 🌐 Understanding the Firebase URL

```
https://your-project-id.firebaseio.com/expenses.json
```

### Breakdown:

- `your-project-id` → your Firebase project
    
- `/expenses` → creates a **node (collection)**
    
- `.json` → required by Firebase REST API ⚠️
    

💡 You can think of:

- `expenses` = folder
    
- Each expense = file inside that folder
    

---

## 🔥 What Happens When Sending Data

- A **POST request** is sent
    
- Firebase:
    
    - Stores the data
        
    - Generates a **unique ID automatically**
        
- Data is saved like:
    

```json
{
  "random-id-123": {
    "description": "Test",
    "amount": 10,
    "date": "2026-04-18"
  }
}
```

---

## 📲 Using the Function in the App

Inside `ManageExpense`:

```js
import { storeExpense } from "../util/http";

async function confirmHandler(expenseData) {
  await storeExpense(expenseData);
}
```

- `expenseData` includes:
    
    - description
        
    - amount
        
    - date

## ⚠️ Important Behavior

- Data is:
    
    - Stored locally (context) ✅
        
    - Sent to backend ✅
        
- UI doesn’t change immediately from backend yet
    

👉 Backend sync is happening, but not fully integrated yet

---

## ⚠️ Notes / Pitfalls

- Always return the Axios call → so you can `await` it
    
- Firebase auto-generates IDs → don’t send your own
    
- `.json` is mandatory in Firebase URLs
    
- Currently no:
    
    - Loading state
        
    - Error handling
