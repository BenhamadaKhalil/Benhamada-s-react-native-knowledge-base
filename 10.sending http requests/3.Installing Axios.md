# 📡 Sending HTTP Requests in React Native (Axios Setup)

## 🧩 Concept
Before sending HTTP requests, we must identify **when** they should happen in the app.

HTTP requests are triggered by **user actions** or **screen loading**.

---

## 📍 When to Send Requests

### 1. ➕ Add / Update Expense
- When saving an expense in `ManageExpense`
- Send data to backend
- Optionally still store it in local state (context)

---

### 2. 📥 Fetch Expenses
- When opening screens like `RecentExpenses`
- Load data from backend into the app

---

### 3. ❌ Delete Expense
- When removing an expense
- Send delete request to backend

---

## ⚙️ How to Send Requests

React Native gives multiple options:

### 1. Fetch API (Built-in)
- Same as browser `fetch()`
- No installation required

```js
fetch("https://example.com/data");
````

---

### 2. Axios (Recommended ✅)

- Third-party library
    
- Based on **XMLHttpRequest**
    
- Easier syntax
    
- Better error handling
    
- Promise-based
    

---

## 🚀 Installing Axios

Run in your project:

```bash
npm install axios
```

---

## 💻 Basic Axios Example

```js
import axios from "axios";

// GET request
const response = await axios.get("https://example.com/data");

// POST request
await axios.post("https://example.com/data", {
  title: "New Expense",
  amount: 20,
});
```

---

## 🔥 Why Axios is Preferred

- Cleaner syntax than Fetch
    
- Automatically parses JSON
    
- Better error handling
    
- Works in both:
    
    - React Native
        
    - Browser apps
        

💡 That’s why it’s widely used in real projects (including MERN apps).

---

## ⚠️ Notes / Pitfalls

- Axios must be installed manually
    
- Always handle errors (`try/catch`)
    
- Don’t mix too much logic in components → later move requests to helper files
    
- Requests are async → use `async/await`
    

---

## 🔑 Key Takeaways

- HTTP requests are triggered by **user actions & screen loads**
    
- Main operations: **fetch, add, update, delete**
    
- React Native supports:
    
    - Fetch API
        
    - Axios (preferred here)
        
- Axios simplifies request handling and improves readability
