# 🔄 4. Data Flow in the App

## 📥 Fetching
- GET request to Firebase
- Transform object → array
- Store in context

## ➕ Adding
- POST request
- Firebase generates ID
- Store locally + backend sync

## ✏️ Updating
- PUT request using ID in URL
- Replace existing backend data

## 🗑️ Deleting
- DELETE request using ID in URL
- Remove from backend + context
