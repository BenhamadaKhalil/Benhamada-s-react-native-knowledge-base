## 📌 Passing Data Between Screens (Route Params in React Navigation)

---

## 🧠 Key Concept

Navigation is not only about switching screens 👆

👉 It also allows you to **pass data between screens**

This is done using **route parameters (params)**.

---

## 🚀 1. Passing Data When Navigating

### 📦 `navigation.navigate`

You can pass a **second argument (params object)**:

```js
navigation.navigate("MealsOverview", {
  categoryId: itemData.item.id,
});
```

---

### 💡 What happens here?

- First argument → screen name
    
- Second argument → data you want to send
    

```txt
CategoriesScreen → MealsOverviewScreen
        (categoryId sent)
```

---

## 🧠 2. Why This is Important

Now the next screen knows:

- Which category was selected
    
- What data it should display
    
- What title it should show
    

👉 This enables **dynamic screens**

---

## 📥 3. Receiving Data in Target Screen

Every screen gets a special prop:

```js
route
```

So in `MealsOverviewScreen`:

```js
function MealsOverviewScreen({ route, navigation }) {
```

---

## 📦 4. Extracting Params

All passed data is inside:

```js
route.params
```

So you can access:

```js
const catId = route.params.categoryId;
```

---

## 📱 5. Full Flow Example

### 🔹 Send data:

```js
navigation.navigate("MealsOverview", {
  categoryId: itemData.item.id,
});
```

---

### 🔹 Receive data:

```js
const catId = route.params.categoryId;
```

---

## 🧠 Mental Model

```txt
Press Category
   ↓
navigate("MealsOverview", { categoryId })
   ↓
MealsOverviewScreen receives:
route.params.categoryId
```

---

## ⚠️ Important Rules

- Params are **optional**
    
- You can pass:
    
    - strings
        
    - numbers
        
    - objects
        
    - arrays
        

Example:

```js
navigation.navigate("Screen", {
  user: { id: 1, name: "Khalil" },
});
```

---

## 🔍 6. Using Params in UI

Example:

```js
<Text>{catId}</Text>
```

👉 Now UI becomes dynamic based on selected category

---

## 🔁 7. Alternative: useRoute Hook

Instead of props:

```js
import { useRoute } from "@react-navigation/native";

const route = useRoute();
const catId = route.params.categoryId;
```

---

## ⚖️ Props vs Hook

|Method|When to use|
|---|---|
|route prop|inside screen components|
|useRoute()|nested / child components|

---

## 🧠 8. Why This Pattern Matters

This is one of the MOST used patterns in React Native:

👉 Select item → pass ID → load detail screen

Examples in real apps:

- Instagram → postId
    
- Amazon → productId
    
- Spotify → songId
    

---

## 📚 Quick Summary

- You pass data using:
    
    ```js
    navigation.navigate("Screen", { params })
    ```
    
- You receive data using:
    
    ```js
    route.params
    ```
    
- This enables **dynamic screens**
    
- Alternative access method:
    
    - `useRoute()` hook
        
- This is essential for real-world apps
    

---

👉 Navigation = not just moving screens  
👉 It’s also about **data flow between screens**
