## 📌 Adding a Second Screen + Navigation Between Screens

---

## 🧠 Key Concepts

- Navigation is **not automatic**
    
- You must:
    
    1. Create a new screen
        
    2. Register it in the navigator
        
    3. Manually trigger navigation on user actions (e.g. press)
        

---

## 🧩 1. Create the Second Screen

### 📄 `MealsOverviewScreen.js`

```js
import { View, Text, StyleSheet } from "react-native";

export default function MealsOverviewScreen() {
  return (
    <View style={styles.container}>
      <Text>Meals Overview Screen</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    padding: 16,
  },
});
```

---

## 🧠 Purpose of This Screen

- Will show meals belonging to a selected category
    
- Later we will:
    
    - Filter meals using category ID
        
    - Display only relevant meals
        

👉 For now: just a placeholder screen

---

## 🧭 2. Register the Screen in Stack Navigator

In `App.js`:

```js
<Stack.Screen
  name="MealsOverview"
  component={MealsOverviewScreen}
/>
```

---

## ⚠️ Important Rule

Registering a screen:

- ✅ Makes it available in navigation system
    
- ❌ Does NOT automatically navigate to it
    

👉 You must still manually trigger navigation

---

## 👆 3. Make Category Items Clickable

We use `Pressable` → but we don’t handle navigation inside it directly.

Instead, we use **prop forwarding**

---

## 🔁 4. Forward onPress from Parent

### 📄 `CategoryGridTile`

```js
export default function CategoryGridTile({ title, color, onPress }) {
  return (
    <Pressable onPress={onPress}>
      ...
    </Pressable>
  );
}
```

---

## 🧠 Why this pattern?

- Keeps UI component reusable
    
- Avoids hardcoding navigation inside child component
    
- Parent decides behavior
    

---

## 🧭 5. Handle Press in CategoriesScreen

```js
function pressHandler() {
  navigation.navigate("MealsOverview");
}
```

## 🚀 7. Navigate to Second Screen

```js
navigation.navigate("MealsOverview");
```

### 💡 Important:

- Must match the `name` in `Stack.Screen`
    

---

## 🔗 8. Connect Everything Together

### In `CategoriesScreen`:

```js
<CategoryGridTile
  title={itemData.item.title}
  color={itemData.item.color}
  onPress={pressHandler}
/>
```

---

## 🎬 9. What Happens Now

When user taps a category:

1. Pressable triggers `onPress`
    
2. `pressHandler` runs
    
3. `navigation.navigate("MealsOverview")`
    
4. React Navigation:
    
    - Pushes new screen on stack
        
    - Animates transition 🎬
        
    - Adds Back button automatically 🔙
        

---

## ✨ 10. What React Navigation Gives You Automatically

- Smooth screen transition
    
- Header bar
    
- Back button
    
- Gesture navigation (swipe back on iOS)
    
- Platform-specific animations
    

---

## 🧠 Big Idea (Very Important)

👉 Navigation is **declarative**

You don’t say:

> “replace screen manually”

You say:

> “go to this screen”

React Navigation handles everything else.
