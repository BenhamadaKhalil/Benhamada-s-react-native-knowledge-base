## 🧭 React Native Notes — Adding Header Buttons (React Navigation)

---

## 🎯 Goal of this lesson

Learn how to:

- Add buttons to the **navigation header**
    
- Understand **two different approaches**
    
- Handle interaction with the screen component
    

---

## 🧩 1. Adding elements to the header (basic idea)

React Navigation allows customizing the header via **screen options**.

### 📌 Key properties:

- `headerRight` → element on the right
    
- `headerLeft` → element on the left
    

---

## ⚙️ 2. Adding a header button in `App.js` (static approach)

```js
<Stack.Screen
  name="MealDetail"
  component={MealDetailScreen}
  options={{
    headerRight: () => {
      return <Text>In the header</Text>;
    },
  }}
/>
```

---

### 💡 Important

- `headerRight` must return a **component function**
    
- You can return ANY JSX (Text, Button, Icon, etc.)
    

---

## 🔘 3. Adding a button instead of text

```js
headerRight: () => (
  <Button
    title="Tap me"
    onPress={() => {}}
  />
)
```

---

## ⚠️ 4. Limitation of this approach

This method:

- ❌ Cannot easily interact with the screen logic
    
- ❌ Cannot access component state or functions
    

👉 Because it’s defined **outside the screen component**

---

## 🧠 5. Dynamic approach (recommended)

When interaction is needed → define header inside the screen

---

## ⚛️ 6. Using `useLayoutEffect`

```js
import { useLayoutEffect } from 'react';
```

---

### 📌 Inside `MealDetailScreen`:

```js
useLayoutEffect(() => {
  navigation.setOptions({
    headerRight: () => (
      <Button
        title="Tap me"
        onPress={headerButtonPressHandler}
      />
    ),
  });
}, [navigation, headerButtonPressHandler]);
```

---

## 🔘 7. Handling button press

```js
function headerButtonPressHandler() {
  console.log('Pressed!');
}
```

---

### ✅ Result

- Button is in header
    
- Can interact with screen logic
    
- Can access state, props, etc.
    

---

## 🔁 8. Why `useLayoutEffect`?

### ✔ Runs before UI is painted

- Prevents flickering
    
- Ensures header updates immediately
    

---

## 🔗 9. Dependencies in `useLayoutEffect`

```js
[navigation, headerButtonPressHandler]
```

### 💡 Why?

- React needs to re-run effect when values change
    

---

## ⚖️ 10. Static vs Dynamic approach

|Approach|Where|Use case|
|---|---|---|
|Static (`App.js`)|Outside screen|Simple UI, no interaction|
|Dynamic (`useLayoutEffect`)|Inside screen|Needs logic / state|

---

## 📱 11. What can be added to header?

You can add:

- Text
    
- Button
    
- Custom components
    
- Icons (later)
    

---

## ⚠️ Common mistakes

- ❌ Forgetting `return` in `headerRight`
    
- ❌ Using wrong dependencies in `useLayoutEffect`
    
- ❌ Expecting access to screen state in `App.js`
    
- ❌ Not importing `Button` or `Text`
