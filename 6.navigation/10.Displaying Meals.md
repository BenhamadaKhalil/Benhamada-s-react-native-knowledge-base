## 📌 Filtering Data + Displaying Meals (React Native Navigation Flow)

---

## 🧠 Key Concepts

- Use **route params (categoryId)** to filter data
    
- Use JavaScript **array methods (filter)** for dynamic UI
    
- Render filtered results using **FlatList**
    
- Create reusable UI components (**MealItem**)
    

---

## 🔄 1. Goal of This Step

👉 When user selects a category:

- Get `categoryId`
    
- Find meals that belong to it
    
- Display only those meals
    

---

## 🧩 2. Understanding the Data Structure

### 🔹 Meals have multiple categories

```js
meal.categoryIds = ["c1", "c3", "c5"];
```

👉 One meal can belong to MANY categories

---

## ⚙️ 3. Filtering Meals by Category

### 📌 Step 1: Get categoryId

```js
const catId = route.params.categoryId;
```

---

### 📌 Step 2: Filter meals

```js
const displayedMeals = MEALS.filter((mealItem) => {
  return mealItem.categoryIds.indexOf(catId) >= 0;
});
```

---

## 🧠 How filter works here

For each meal:

- Check if `catId` exists in `categoryIds`
    
- If YES → keep meal
    
- If NO → remove meal
    

---

### 💡 Why `indexOf`?

```js
mealItem.categoryIds.indexOf(catId)
```

Returns:

- `>= 0` → found ✅
    
- `-1` → not found ❌
    

---

## 📱 4. Display Meals with FlatList

```js
<FlatList
  data={displayedMeals}
  keyExtractor={(item) => item.id}
  renderItem={renderMealItem}
/>
```

---

## 🧠 Why FlatList again?

- Handles performance automatically
    
- Scales for large datasets
    
- Better than manual `.map()`
    

---

## 🧩 5. Creating MealItem Component

### 📄 `components/MealItem.js`

```js
import { View, Text } from "react-native";

export default function MealItem({ title }) {
  return (
    <View>
      <Text>{title}</Text>
    </View>
  );
}
```

---

## 🧠 Why separate component?

- Keeps screen clean
    
- Makes UI reusable
    
- Prepares for complex layout (image, price, duration, etc.)
    

---

## 🔁 6. Using MealItem in Screen

```js
<MealItem title={itemData.item.title} />
```

---

## 🧠 Mapping FlatList → Component

```txt
displayedMeals
   ↓
FlatList
   ↓
renderMealItem
   ↓
MealItem(title)
```

---

## ⚙️ 7. renderItem function

```js
function renderMealItem(itemData) {
  return <MealItem title={itemData.item.title} />;
}
```

---

## 🧠 8. Full Flow of Data

```txt
CategoriesScreen
   ↓ (navigate + categoryId)
MealsOverviewScreen
   ↓ (route.params.categoryId)
filter(MEALS)
   ↓
displayedMeals
   ↓
FlatList
   ↓
MealItem UI
```

---

## 💡 9. What You Achieved

Now your app:

- Navigates between screens
    
- Passes data (categoryId)
    
- Filters data dynamically
    
- Renders filtered results
    
- Uses reusable components
    

---

## 🚨 Common Mistakes

- ❌ Forgetting `route.params`
    
- ❌ Using wrong categoryId key
    
- ❌ Not returning in `.filter()`
    
- ❌ Using `.map()` instead of FlatList for large lists
    

---

## 📚 Quick Summary

- Route params give you selected category
    
- `filter()` selects matching meals
    
- `indexOf` checks membership in array
    
- FlatList renders filtered results
    
- MealItem is reusable UI component
