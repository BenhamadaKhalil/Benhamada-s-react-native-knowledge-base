## 📌 What is Navigation in React Native?

---

## 🧠 Key Concepts

- **Navigation = moving between screens** in a mobile app.
    
- In simple apps, this can be:
    
    - Replacing one screen with another
        
- In real apps, navigation is:
    
    - **More advanced**
        
    - Includes **history (back/forward)**
        
    - Includes **animations**
        

---

## 🔄 Basic vs Advanced Navigation

### ❌ Basic (what we used before)

- Replace screen manually
    
- No back functionality
    
- No animations
    
- Limited UX
    

---

### ✅ Advanced (what we want)

- Navigate **forward and backward**
    
- Smooth transitions 🎬
    
- Structured navigation system
    
- Combine multiple navigation types
    

---

## 📱 Mobile vs 🌐 Web Navigation

### 🌐 Web (Browser)

- Navigation via **URLs**
    
- Example:
    
    ```
    /home → /products → /details
    ```
    
- Uses links (`<a>` tags)
    

---

### 📱 Mobile (React Native)

- No URLs
    
- Navigation via:
    
    - Buttons
        
    - Touch interactions 👆
        
- Flow example:
    
    ```
    Categories → Meals → Meal Details → Back
    ```
    

---

## 🧩 Navigation Patterns You Will Learn

- **Stack Navigation**
    
    - Forward & backward navigation
        
- **Tabs**
    
    - Switch between main screens
        
- **Combining patterns**
    
    - Example: Tabs + Stack together

---

### 🧠 Why Models?

- Define **structure (blueprint)** of data
    
- Help organize and standardize objects
    

Example idea:

```js
class Meal {
  constructor(id, title, imageUrl, duration) {
    this.id = id;
    this.title = title;
    this.imageUrl = imageUrl;
    this.duration = duration;
  }
}
```
