## 🧭 1. Navigating to a New Screen (Meal Detail)

### ✅ Goal

- Add a **MealDetailScreen**
    
- Navigate to it when a meal is pressed
    
- Pass the **meal ID** as data
    

### 🔹 Steps

#### 1. Create Screen

```js
function MealDetailScreen() {
  return <Text>This is the meal detail screen</Text>;
}
export default MealDetailScreen;
```

#### 2. Register Screen (Stack Navigator)

```js
<Stack.Screen name="MealDetail" component={MealDetailScreen} />
```

#### 3. Navigate from MealItem

- Use `useNavigation()` (because it's NOT a screen component)
    

```js
import { useNavigation } from '@react-navigation/native';

const navigation = useNavigation();

function selectMealItemHandler() {
  navigation.navigate('MealDetail', {
    mealId: id,
  });
}
```

#### 4. Trigger Navigation on Press

```js
<Pressable onPress={selectMealItemHandler}>
```

#### 5. Receive Params in Screen

```js
function MealDetailScreen({ route }) {
  const mealId = route.params.mealId;
}
```

## ⭐ 5. Header Buttons (React Navigation)

### 🔹 Static Header Button (App.js)

```js
options={{
  headerRight: () => <Button title="Tap me" />
}}
```

⚠️ Cannot access screen logic here easily

---

### 🔹 Dynamic Header Button (Best Practice)

Use `useLayoutEffect` inside screen:

```js
useLayoutEffect(() => {
  navigation.setOptions({
    headerRight: () => (
      <Button title="Tap me" onPress={handler} />
    )
  });
}, [navigation]);
```

## 🔘 6. Custom Icon Button

### 🔹 Create IconButton

```js
import { Pressable } from 'react-native';
import { Ionicons } from '@expo/vector-icons';

function IconButton({ icon, color, onPress }) {
  return (
    <Pressable onPress={onPress}>
      <Ionicons name={icon} size={24} color={color} />
    </Pressable>
  );
}
```

---

### 🔹 Add Press Feedback

```js
style={({ pressed }) =>
  pressed ? styles.pressed : null
}
```

```js
pressed: {
  opacity: 0.7
}
```

## 🧭 7. Drawer Navigator

### 🔹 Install

```bash
npm install @react-navigation/drawer
```

---

### 🔹 Setup

```js
const Drawer = createDrawerNavigator();

<Drawer.Navigator>
  <Drawer.Screen name="Welcome" component={WelcomeScreen} />
  <Drawer.Screen name="User" component={UserScreen} />
</Drawer.Navigator>
```

---

### 🔹 Styling Drawer

```js
screenOptions={{
  headerStyle: { backgroundColor: '#3c0a6b' },
  headerTintColor: 'white',
  drawerActiveTintColor: '#3c0a6b',
  drawerActiveBackgroundColor: '#f0e1ff'
}}
```

---

### 🔹 Add Icons

```js
drawerIcon: ({ color, size }) => (
  <Ionicons name="home" color={color} size={size} />
)
```

---

### 🔹 Open Drawer Programmatically

```js
navigation.toggleDrawer();
```

## 🧩 9. Nested Navigators (IMPORTANT 🔥)

### 💡 Concept

👉 You can **combine navigators inside each other**

---

### 🔹 Example (Meals App)

```
Stack Navigator
 └── Drawer Navigator
      ├── Categories Screen
      └── Favorites Screen
```

---

### 🔹 Create Drawer Component

```js
function DrawerNavigator() {
  return (
    <Drawer.Navigator>
      <Drawer.Screen name="Categories" component={CategoriesScreen} />
      <Drawer.Screen name="Favorites" component={FavoritesScreen} />
    </Drawer.Navigator>
  );
}
```

---

### 🔹 Use Inside Stack

```js
<Stack.Screen
  name="Drawer"
  component={DrawerNavigator}
  options={{ headerShown: false }}
/>
```

---

### 🔹 Fix Double Header

```js
options={{ headerShown: false }}
```

---
