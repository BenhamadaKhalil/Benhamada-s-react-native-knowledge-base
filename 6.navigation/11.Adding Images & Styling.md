## 🧩 2. Making MealItem Pressable

Wrap content with:

```js
import { Pressable } from "react-native";
```

```js
<Pressable onPress={onPress}>
  {/* content */}
</Pressable>
```

---

## 💡 Why Pressable?

- Handles user interaction
    
- Supports platform-specific feedback:
    
    - Android → ripple effect
        
    - iOS → opacity effect

## 🖼️ 3. Loading Images from URL

```js
<Image source={{ uri: imageUrl }} style={styles.image} />
```

---

## ⚠️ Important Rule

👉 For **remote images**, you MUST define:

```js
style={{
  width: "100%",
  height: 200
}}
```

Otherwise → image won’t appear ❌

## 🧠 6. Cleaner Props Handling (Best Practice)

```js
const item = itemData.item;

const mealItemProps = {
  title: item.title,
  imageUrl: item.imageUrl,
  duration: item.duration,
  complexity: item.complexity,
  affordability: item.affordability,
};
```

```js
<MealItem {...mealItemProps} />
```

## 💡 Why this is good?

- Cleaner code
    
- Avoid repetition
    
- Scalable

## 🧠 Flexbox Insight

```txt
flexDirection: "row" → horizontal layout
justifyContent → horizontal alignment
alignItems → vertical alignment
```

---

## 🌑 8. Shadows (Cross-Platform Problem)

### Android:

```js
elevation: 4
```

### iOS:

```js
shadowColor: "black",
shadowOpacity: 0.25,
shadowOffset: { width: 0, height: 2 },
shadowRadius: 8,
```

---

## ⚠️ Important Issue

```txt
overflow: hidden ❌ removes shadow on iOS
```

---

## ✅ Solution

Use **two containers**:

```txt
Outer → shadow
Inner → overflow hidden + borderRadius
```

---

## 📱 9. Press Feedback

### Android Ripple

```js
android_ripple={{ color: "#ccc" }}
```

---

### iOS Opacity

```js
style={({ pressed }) =>
  pressed ? styles.buttonPressed : null
}
```

```js
buttonPressed: {
  opacity: 0.5,
}
```

---

## 🧠 Result

- Android → ripple + opacity
    
- iOS → opacity only

## 🚨 Common Mistakes

- ❌ Forgetting width/height for image
    
- ❌ Using overflow hidden on outer container
    
- ❌ Not passing props correctly
    
- ❌ Forgetting keyExtractor in FlatList
    
- ❌ Not using Pressable for interaction
    

---

## 📚 Quick Summary

- Use `Pressable` for interaction
    
- Use `{ uri: ... }` for remote images
    
- Use Flexbox for layout
    
- Use double container for shadows + border radius
    
- Use spread operator (`...props`) for clean code
