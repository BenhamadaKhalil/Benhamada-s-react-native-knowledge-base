## 🧠 Key Concepts

- Create a **screen component** to display data
    
- Use **FlatList** to render lists efficiently
    
- Separate UI into **reusable components**
    
- Organize project into:
    
    - `screens/` → full pages
        
    - `components/` → reusable UI parts

## 🧩 Step 1: Create Categories Screen

### 📄 `screens/CategoriesScreen.js`

- A normal React component
    
- Responsible for displaying all categories
    

```js
import { FlatList } from "react-native";
import { CATEGORIES } from "../data/dummy-data";
import CategoryGridTile from "../components/CategoryGridTile";

function renderCategoryItem(itemData) {
  return (
    <CategoryGridTile
      title={itemData.item.title}
      color={itemData.item.color}
    />
  );
}

export default function CategoriesScreen() {
  return (
    <FlatList
      data={CATEGORIES}
      keyExtractor={(item) => item.id}
      renderItem={renderCategoryItem}
    />
  );
}
```

---

## ⚙️ Important Techniques

### 🔹 FlatList

Used to render lists efficiently

```js
<FlatList
  data={CATEGORIES}
  keyExtractor={(item) => item.id}
  renderItem={renderCategoryItem}
/>
```

#### Why use it?

- Optimized performance
    
- Lazy rendering (only visible items)
    

👉 Even though data is small here, it's used for **practice**

---

### 🔹 keyExtractor

```js
(item) => item.id
```

- FlatList needs a unique key
    
- Our data uses `id` instead of `key`
    

---

### 🔹 renderItem

- Function that defines how each item is displayed
    

```js
function renderCategoryItem(itemData) {
  return <CategoryGridTile ... />;
}
```

## 🧱 Step 2: Create Reusable Component

### 📄 `components/CategoryGridTile.js`

```js
import { View, Text, Pressable } from "react-native";

export default function CategoryGridTile({ title, color }) {
  return (
    <View>
      <Pressable>
        <View>
          <Text>{title}</Text>
        </View>
      </Pressable>
    </View>
  );
}
```

---

## 💡 Why This Structure?

### 🔹 Separate Components

- Keeps code **clean and maintainable**
    
- Reusable UI blocks
    

---

### 🔹 Pressable

- Makes items clickable 👆
    
- Will be used later for navigation
    

---

### 🔹 Props Usage

```js
<CategoryGridTile title={...} color={...} />
```

- Pass dynamic data into components
    
- Makes components reusable
    

---

## ⚠️ Important Optimization

```js
function renderCategoryItem() { ... }
```

- Defined **outside** the component
    
- Prevents unnecessary re-creation on re-renders
    
- Improves performance
    

---

## 🚨 Common Mistakes

- ❌ Forgetting `keyExtractor` → causes warnings
    
- ❌ Using `item.title` instead of `itemData.item.title`
    
- ❌ Putting everything in one file (bad practice)
    
- ❌ Not exporting components
