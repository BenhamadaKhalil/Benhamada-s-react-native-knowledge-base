## 🧭 1. What are Nested Navigators?

👉 **Nested Navigators = Navigator inside another navigator**

Example:

```text
Stack Navigator
   └── Drawer Navigator
          ├── Categories Screen
          └── Favorites Screen
```

---

## 🧠 Why use nested navigation?

Because real apps need:

- Multiple navigation patterns
    
- Separation of features
    
- Better UX (drawer + deep navigation)

## 🧩 3. Creating a Drawer Navigator component

Inside `App.js`:

```js
const Drawer = createDrawerNavigator();

function DrawerNavigator() {
  return (
    <Drawer.Navigator>
      <Drawer.Screen
        name="Categories"
        component={CategoriesScreen}
      />
      <Drawer.Screen
        name="Favorites"
        component={FavoritesScreen}
      />
    </Drawer.Navigator>
  );
}
```

## 🔁 5. Replacing Stack screen with Drawer

Before:

```js
<Stack.Screen
  name="Categories"
  component={CategoriesScreen}
/>
```

---

After:

```js
<Stack.Screen
  name="Drawer"
  component={DrawerNavigator}
/>
```

---

## 🔑 Key idea

👉 A navigator **can be used as a screen**

---

## ⚠️ 6. Problem: Double headers

After nesting:

- Stack header ❌
    
- Drawer header ❌  
    → Two headers appear
    

---

## ✅ Solution: Hide Stack header

```js
<Stack.Screen
  name="Drawer"
  component={DrawerNavigator}
  options={{ headerShown: false }}
/>
```

---

## 🎯 Result:

- Only Drawer header remains
    
- Cleaner UI
    

---

## 🎨 7. Fixing styling (background issue)

### Problem:

- Background color disappears
    

---

### Solution (Drawer uses different property!)

```js
<Drawer.Navigator
  screenOptions={{
    headerStyle: { backgroundColor: '#351401' },
    headerTintColor: 'white',
    sceneContainerStyle: { backgroundColor: '#3f2f25' },
  }}
>
```

---

## ⚠️ Important difference

|Navigator|Property|
|---|---|
|Stack|`contentStyle`|
|Drawer|`sceneContainerStyle`|

## 🧠 Key concepts

### 🔁 Navigator hierarchy

```text
App
 └── Stack Navigator
      ├── Drawer Navigator (as screen)
      │     ├── Categories
      │     └── Favorites
      └── Meal Detail Screen
```

---

### ⚙️ Navigation behavior

- Drawer → switches main sections
    
- Stack → handles deeper navigation
    

---

### 🎯 Real-world pattern

This is VERY common:

- Drawer = main navigation
    
- Stack = detailed screens
    

---

## ⚠️ Common mistakes

- ❌ Forgetting `headerShown: false`
    
- ❌ Using same screen names (causes warnings)
    
- ❌ Styling drawer with `contentStyle` (wrong!)
    
- ❌ Not importing screens properly
