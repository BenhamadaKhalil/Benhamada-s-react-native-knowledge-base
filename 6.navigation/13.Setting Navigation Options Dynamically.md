## 🚀 Dynamic Navigation Options (React Navigation)

Now you're entering a **more advanced and real-world pattern**: making your navigation **react to data**.

---

# 🧠 Two Ways to Set Options Dynamically

---

## ✅ 1. Using `options` as a Function (Config-Level)

Instead of passing an object:

```js
options={{ title: "Static Title" }}
```

👉 You pass a function:

```js
<Stack.Screen
  name="MealsOverview"
  component={MealsOverviewScreen}
  options={({ route, navigation }) => {
    const catId = route.params.categoryId;

    return {
      title: catId, // dynamic
    };
  }}
/>
```

---

## 🧠 What Happens Here

- React Navigation **calls this function automatically**
    
- Provides:
    
    - `route` → contains params
        
    - `navigation` → navigation methods
        
- You return an **options object**
    

---

## 📌 Real Use Case

```js
const catId = route.params.categoryId;

const categoryTitle = CATEGORIES.find(
  (cat) => cat.id === catId
).title;

return {
  title: categoryTitle,
};
```

---

## ⚡ When to Use This Approach

✔ When logic is **simple**  
✔ When everything can be derived from `route`  
✔ When you want **clean central config**

---

# 🔥 2. Using `navigation.setOptions` Inside Component

This is the **most flexible & commonly used approach**.

---

## ❌ Wrong Way (causes warning)

```js
navigation.setOptions({
  title: categoryTitle,
});
```

👉 Don't do this directly in component body

---

## ✅ Correct Way: `useLayoutEffect`

```js
import { useLayoutEffect } from "react";

function MealsOverviewScreen({ route, navigation }) {
  const catId = route.params.categoryId;

  const categoryTitle = CATEGORIES.find(
    (cat) => cat.id === catId
  ).title;

  useLayoutEffect(() => {
    navigation.setOptions({
      title: categoryTitle,
    });
  }, [navigation, catId]);

  return (...);
}
```

---

## 🧠 Why `useLayoutEffect`?

|Hook|Behavior|
|---|---|
|`useEffect`|Runs **after render** → causes flicker|
|`useLayoutEffect`|Runs **before paint** → smooth UI|

---

## ⚠️ Visual Difference

### ❌ useEffect:

```txt
Screen loads → Title appears later (ugly jump)
```

### ✅ useLayoutEffect:

```txt
Title appears during transition (smooth)
```

---

# ⚖️ Comparison

|Method|Pros|Cons|
|---|---|---|
|`options` function|Simple, clean|Less flexible|
|`setOptions` + hook|Powerful, flexible|Slightly more complex|

# ⚠️ Common Mistakes

- ❌ Using `setOptions` outside hooks
    
- ❌ Using `useEffect` instead of `useLayoutEffect`
    
- ❌ Forgetting dependencies (`navigation`, `route params`)
    
- ❌ Overcomplicating when `options` function is enough
    

---

# 📚 Final Summary

- `options: ({ route }) => ({})` → quick dynamic setup
    
- `navigation.setOptions()` → advanced control
    
- `useLayoutEffect` → smooth UI updates
    
- Always derive data from **route.params**
