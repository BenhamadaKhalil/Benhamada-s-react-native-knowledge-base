## 📌 Adding Navigation with React Navigation (Setup)

---

## 🧠 Key Concepts

- Manual screen switching (like before) works but is **not scalable**
    
- Real apps use a navigation system with:
    
    - Smooth transitions 🎬
        
    - Back functionality 🔙
        
    - Screen history stack 🧠
        

👉 That’s why we use **React Navigation**

---

## 🚫 Why Not Manual Navigation?

Previously:

- `if (state === "screen1") render A`
    
- `else render B`
    

❌ Problems:

- No animations
    
- No back button
    
- Hard to scale
    
- Messy logic in `App.js`
    

---

## 🚀 Solution: React Navigation

### 📦 What it is

- A library for **routing and navigation in React Native**
    
- Works with Expo and bare React Native
    
- Provides ready-made navigation systems
    

---

## 📥 1. Installation

### Core package:

```bash
npm install @react-navigation/native
```

### Expo dependencies:

```bash
expo install react-native-screens react-native-safe-area-context
```

---

## 🧱 2. Navigation Container

### 📌 Purpose:

Wraps your entire app and enables navigation system

```js
import { NavigationContainer } from "@react-navigation/native";
```

### Usage:

```js
<NavigationContainer>
  <CategoriesScreen />
</NavigationContainer>
```

### 💡 Think of it like:

👉 The "brain" of navigation  
It manages:

- Navigation state
    
- Screen history
    
- Transitions
    

---

## 🧭 3. Stack Navigator (First Navigation Type)

### 📦 Install:

```bash
expo install @react-navigation/native-stack
```

---

## 🧠 What is Stack Navigation?

- Screens behave like a **stack of pages**
    
- New screen = pushed on top
    
- Back = pop previous screen
    

Example:

```
Categories → Meals → Meal Details
```

---

## ⚙️ 4. Create Stack Navigator

```js
import { createNativeStackNavigator } from "@react-navigation/native-stack";

const Stack = createNativeStackNavigator();
```

---

## 🧩 5. Register Screens

Inside your app:

```js
<NavigationContainer>
  <Stack.Navigator>
    <Stack.Screen
      name="Categories"
      component={CategoriesScreen}
    />
  </Stack.Navigator>
</NavigationContainer>
```

---

## 📌 Important Rules

### 🔹 `name`

- Unique identifier for the screen
    
- Used later for navigation
    

### 🔹 `component`

- The actual screen function
    
- Pass reference ONLY (not JSX)
    

❌ Wrong:

```js
component={<CategoriesScreen />}
```

✅ Correct:

```js
component={CategoriesScreen}
```

---

## 🎨 6. What React Navigation Gives You Automatically

After setup, you instantly get:

- 📱 Header bar
    
- 🔙 Back button (later screens)
    
- 🧠 Navigation state management
    
- 🛡 Safe area handling (notch protection)
    

---

## ⚠️ Observed Changes

After adding navigation:

- Background styling may reset
    
- StatusBar may disappear → fix with:
    

```js
<StatusBar style="dark" />
```

---

## 💡 Why This Happens

React Navigation wraps your app with its own structure:

- It controls layout
    
- It injects screen containers
    
- It adds default UI (header, spacing)

## 📚 Quick Summary

- Manual navigation = simple but not scalable
    
- React Navigation = professional navigation system
    
- Setup requires:
    
    - `NavigationContainer`
        
    - `createNativeStackNavigator`
        
    - `Stack.Screen` registration
        
- First screen registered = CategoriesScreen
    
- You now have a navigation-ready app structure
