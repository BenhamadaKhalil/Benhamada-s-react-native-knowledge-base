## 📌 Configuring Navigation Headers & Global Styles (React Navigation)

---

## 🧠 Key Concepts

- Screens have **default headers (title + styles)**
    
- You can **customize per screen**
    
- Or define **global styles for all screens**
    
- Navigation uses **screen name as default title**
    

---

## 🎯 1. Default Behavior

```js
<Stack.Screen name="MealsCategories" component={CategoriesScreen} />
```

👉 This automatically gives:

- Header title = `"MealsCategories"`
    
- Default styling (platform-based)
    

---

## ⚠️ Important Insight

```txt
Screen "name" ≠ UI title
```

👉 `name` is for **navigation logic**, not UI

---

## 🧩 2. Customizing Screen Options

Use the `options` prop:

```js
<Stack.Screen
  name="MealsCategories"
  component={CategoriesScreen}
  options={{
    title: "All Categories",
  }}
/>
```

---

## 🧠 What happens?

👉 Header title changes from:

```
MealsCategories → All Categories
```

---

## 🎨 3. Styling the Header

### 🔹 Background Color

```js
options={{
  headerStyle: {
    backgroundColor: "#351401",
  }
}}
```

---

### 🔹 Text & Icon Color

```js
headerTintColor: "white"
```

👉 Affects:

- Title
    
- Back button
    
- Icons
    

---

## 🖼️ 4. Styling Screen Content

```js
contentStyle: {
  backgroundColor: "#3f2f25"
}
```

👉 This controls:

- Screen background (NOT header)
    

---

## 🧠 Separation of Concerns

|Area|Property|
|---|---|
|Header|`headerStyle`|
|Header text|`headerTintColor`|
|Screen body|`contentStyle`|

---

## ⚠️ 5. Problem: Styles Reset on Navigation

👉 When navigating:

```txt
Screen A → Screen B
```

Styles may reset because:

- Each screen has its own config
    

---

## ❌ Bad Solution

```txt
Copy-paste options to every screen
```

👉 Leads to:

- Repetition
    
- Hard maintenance
    

---

## ✅ 6. Best Practice: Global Screen Options

Use `screenOptions` on navigator:

```js
<Stack.Navigator
  screenOptions={{
    headerStyle: { backgroundColor: "#351401" },
    headerTintColor: "white",
    contentStyle: { backgroundColor: "#3f2f25" },
  }}
>
```

---

## 🧠 What this does

👉 Applies styles to ALL screens automatically

---

## ⚠️ Priority Rule

```txt
Screen options > Navigator screenOptions
```

👉 If both exist:

- Screen-specific overrides global
    

---

## 🔁 Example

```js
<Stack.Screen
  name="MealsOverview"
  component={MealsOverviewScreen}
  options={{
    title: "Custom Title", // overrides global
  }}
/>
```

---

## 🧠 7. What You Achieved

Now your app has:

✅ Consistent header style  
✅ Consistent background  
✅ Centralized configuration  
✅ Cleaner code

---

## 🚨 Common Mistakes

- ❌ Confusing `name` with `title`
    
- ❌ Styling each screen manually
    
- ❌ Forgetting `headerTintColor` (text becomes unreadable)
    
- ❌ Using `options` instead of `screenOptions` globally
    

---

## 📚 Quick Summary

- `name` → used for navigation
    
- `title` → used for UI header
    
- `options` → per screen config
    
- `screenOptions` → global config
    
- Screen config overrides global config
    

---

## 🧠 Big Picture

```txt
Navigator
   ↓ (screenOptions)
All Screens get default style
   ↓
Individual Screen (options)
   ↓
Override if needed
```
