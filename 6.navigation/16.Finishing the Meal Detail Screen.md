## 🎯 Goal of this lesson

Improve the **Meal Detail Screen UI** by:

- Styling image, title, subtitles, lists
    
- Creating reusable components (`Subtitle`, `List`)
    
- Improving layout structure
    
- Adding scroll support with `ScrollView`
    

---

## 🖼️ 1. Styling the Meal image

We define styles inside `MealDetailScreen`:

```js
image: {
  width: '100%',
  height: 350,
}
```

### 📌 Key idea

- `width: '100%'` → fills parent container
    
- `height: 350` → fixed height needed for images

## 📦 7. Fixing border issue → wrapping subtitle in View

### ❌ Problem:

- Text cannot properly handle borders in RN
    

### ✅ Solution:

Wrap it:

```js
<View style={styles.subtitleContainer}>
  <Text style={styles.subtitle}>Ingredients</Text>
</View>
```

---

### 📌 Subtitle container style

```js
subtitleContainer: {
  borderBottomColor: '#e2b497',
  borderBottomWidth: 2,
  marginVertical: 4,
  marginHorizontal: 24,
  padding: 6,
}
```

---

## ♻️ 8. Creating reusable component: Subtitle

### 📦 Subtitle.js

```js
function Subtitle({ children }) {
  return (
    <View style={styles.subtitleContainer}>
      <Text style={styles.subtitle}>{children}</Text>
    </View>
  );
}
```

### 💡 Key idea

- Uses `children` prop → flexible reusable text component
    

---

## 🍽️ 9. Creating reusable List component

### 📦 List.js

```js
function List({ data }) {
  return data.map((item) => (
    <View key={item} style={styles.listItem}>
      <Text style={styles.itemText}>{item}</Text>
    </View>
  ));
}
```

---

### 📌 List styling

```js
listItem: {
  borderRadius: 6,
  paddingVertical: 4,
  paddingHorizontal: 8,
  marginVertical: 4,
  marginHorizontal: 12,
  backgroundColor: '#e2b497',
}
```

```js
itemText: {
  color: '#351401',
  textAlign: 'center',
}
```
