## 🧭 React Native Notes — Drawer Navigator (Side Menu Navigation)

---

## 🎯 Goal of this lesson

Learn how to:

- Use a **Drawer Navigator** (side menu)
    
- Set up navigation from scratch
    
- Understand how it differs from Stack navigation
    

---

## 📚 1. What is a Drawer Navigator?

A **Drawer Navigator** adds a **side menu (hamburger menu)** to your app.

### 📱 Behavior:

- Swipe or tap icon → drawer opens
    
- Shows list of screens
    
- Tap → navigate to screen
    

---

## 🔄 2. Navigation types recap

|Navigator|Behavior|
|---|---|
|Stack|Push screens (like pages)|
|Drawer|Side menu navigation|
|Tabs|Bottom/top tabs|

---

## 📦 3. Installing Drawer Navigator

### Step 1:

```bash
npm install @react-navigation/drawer
```

### Step 2 (Expo dependencies):

```bash
expo install react-native-gesture-handler react-native-reanimated
```

---

## ⚠️ Possible issue (Reanimated bug)

If you get errors:

```bash
npm install react-native-reanimated@1 --save --save-exact
```

Then restart:

```bash
npm start
```

---

## 🧩 4. Basic setup in `App.js`

### 📌 Import core navigation

```js
import { NavigationContainer } from '@react-navigation/native';
```

---

### 📌 Import drawer navigator

```js
import { createDrawerNavigator } from '@react-navigation/drawer';
```

---

### 📌 Create drawer

```js
const Drawer = createDrawerNavigator();
```

---

## 🏗️ 5. Setting up navigation structure

```js
<NavigationContainer>
  <Drawer.Navigator>
    <Drawer.Screen
      name="Welcome"
      component={WelcomeScreen}
    />
    <Drawer.Screen
      name="User"
      component={UserScreen}
    />
  </Drawer.Navigator>
</NavigationContainer>
```

---

## 📥 6. Importing screens

```js
import WelcomeScreen from './screens/WelcomeScreen';
import UserScreen from './screens/UserScreen';
```

---

## 🔑 7. Initial screen configuration

### Default:

- First screen = initial screen
    

---

### Custom initial screen:

```js
<Drawer.Navigator initialRouteName="User">
```

---

## 📱 8. What happens after setup?

You automatically get:

- ✅ Header
    
- ✅ Drawer icon (☰)
    
- ✅ Slide menu
    
- ✅ Navigation between screens
    

---

## 🎮 9. How users interact

- Tap menu icon → open drawer
    
- Swipe from left → open drawer
    
- Tap screen name → navigate
    

---

## 🎨 10. Customization options

You can configure:

### Per screen:

```js
options={{ title: 'My Screen' }}
```

---

### Global (navigator level):

```js
<Drawer.Navigator screenOptions={{}}>
```

---

## 🧠 11. Key concepts

### 🔁 Same pattern as Stack

- `Navigator` wraps screens
    
- `Screen` registers components
    

---

### 🎯 Main difference

- UI/UX behavior (drawer vs stack)
    

---

### ⚙️ NavigationContainer

- Required for ANY navigation setup
    

---

## ⚠️ Common issues

- ❌ Forgetting `NavigationContainer`
    
- ❌ Missing dependencies (gesture-handler, reanimated)
    
- ❌ Not restarting app after install
    
- ❌ Wrong import paths for screens
