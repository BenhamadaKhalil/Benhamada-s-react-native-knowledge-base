## 📌 Initial Screen in React Navigation (Stack Navigator)

---

## 🧠 Key Concept

When you set up a **Stack Navigator**, React Navigation needs to know:

👉 “Which screen should open first when the app starts?”

That screen is called the **Initial Route / Initial Screen**

---

## 🚀 Default Behavior

### 👉 By default:

React Navigation uses the **first `<Stack.Screen>` declared**

```js
<Stack.Navigator>
  <Stack.Screen name="AllProducts" component={AllProducts} />
  <Stack.Screen name="ProductDetails" component={ProductDetails} />
</Stack.Navigator>
```

### 💡 Result:

- App starts at 👉 `AllProducts`
    

---

## 🔁 Changing Initial Screen (Method 1: Order)

Just change the order:

```js
<Stack.Navigator>
  <Stack.Screen name="ProductDetails" component={ProductDetails} />
  <Stack.Screen name="AllProducts" component={AllProducts} />
</Stack.Navigator>
```

### 💡 Result:

- App starts at 👉 `ProductDetails`
    

---

## ⚙️ Better Approach (Recommended): `initialRouteName`

Instead of relying on order, you can explicitly define it:

```js
<Stack.Navigator initialRouteName="ProductDetails">
  <Stack.Screen name="AllProducts" component={AllProducts} />
  <Stack.Screen name="ProductDetails" component={ProductDetails} />
</Stack.Navigator>
```

---

## 🧠 Why `initialRouteName` is better

- ✅ Clear and explicit
    
- ✅ Not affected by screen order
    
- ✅ Easier to maintain in large apps
    
- ✅ Prevents accidental bugs when rearranging screens
    

---

## ⚠️ Important Rule

```txt
initialRouteName must match the "name" of a Stack.Screen
```

Example:

```js
// ❌ wrong
initialRouteName="ProductDetail"

// ✅ correct
initialRouteName="ProductDetails"
```

---

## 📱 Real App Usage Example

In your Meals App:

```js
<Stack.Navigator initialRouteName="Categories">
```

- App starts at:  
    👉 Categories Screen
    

Then:

- Tap category → MealsOverview
    
- Tap meal → MealDetails (later)
    

---

## 📚 Quick Summary

- First screen in Stack = default initial screen
    
- You can change it in 2 ways:
    
    1. Change screen order
        
    2. Use `initialRouteName` (recommended)
        
- `initialRouteName` is clearer and safer
    

---

## 🚀 Key Takeaway

👉 Always prefer:

```js
initialRouteName="YourScreenName"
```

over relying on order.
