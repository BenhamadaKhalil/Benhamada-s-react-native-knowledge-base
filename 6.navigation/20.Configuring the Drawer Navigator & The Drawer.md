## 🧭 React Native Notes — Configuring Drawer Navigator (Styling + Icons + Interaction)

---

## 🎯 Goal of this lesson

Learn how to:

- Customize the **Drawer UI**
    
- Style header & drawer items
    
- Add **icons to drawer items**
    
- Move from screen-specific → global config
    
- Interact with the drawer programmatically
    

---

## 🎨 1. Styling the header (per screen)

```js
options={{
  headerStyle: { backgroundColor: '#3c0a6b' },
  headerTintColor: 'white',
}}
```

### 📌 Effect:

- Changes header background
    
- Updates text + icon color automatically
    

---

## 🏷️ 2. Customizing drawer label

```js
options={{
  drawerLabel: 'Welcome Screen',
}}
```

### 💡 Why?

- More user-friendly names in drawer
    

---

## 🎨 3. Styling active drawer item

```js
options={{
  drawerActiveBackgroundColor: '#f0e1ff',
  drawerActiveTintColor: '#3c0a6b',
}}
```

---

## 🧱 4. Styling entire drawer

```js
options={{
  drawerStyle: { backgroundColor: '#ccc' },
}}
```

---

## ⚠️ Important concept

### ❌ Problem:

Styles applied in `Screen` → only affect that screen

### ✅ Solution:

Move shared styles to `Drawer.Navigator`

---

## ⚙️ 5. Global configuration (best practice)

```js
<Drawer.Navigator
  screenOptions={{
    headerStyle: { backgroundColor: '#3c0a6b' },
    headerTintColor: 'white',
    drawerActiveBackgroundColor: '#f0e1ff',
    drawerActiveTintColor: '#3c0a6b',
  }}
>
```

---

## 🧠 Key idea

- `screenOptions` = default config for ALL screens
    
- `options` = override per screen
    

---

## ⭐ 6. Adding icons to drawer items

### 📌 Basic setup

```js
import { Ionicons } from '@expo/vector-icons';
```

---

### 📌 Add icon to screen

```js
options={{
  drawerIcon: ({ color, size }) => (
    <Ionicons name="home" color={color} size={size} />
  ),
}}
```

---

## 🎯 Important details

### Props provided automatically:

- `color` → changes if active/inactive
    
- `size` → consistent sizing
    
- `focused` → boolean (selected or not)
    

---

## 👤 7. Example: second screen icon

```js
options={{
  drawerIcon: ({ color, size }) => (
    <Ionicons name="person" color={color} size={size} />
  ),
}}
```

---

## 🎨 Result

- Icons auto-aligned
    
- Color changes on selection
    
- No manual styling needed
    

---

## 🎮 8. Interacting with the drawer programmatically

### 📌 Add a button inside a screen

```js
<Button title="Open Drawer" onPress={openDrawerHandler} />
```

---

### 📌 Use navigation prop

```js
function openDrawerHandler() {
  navigation.toggleDrawer();
}
```

---

## 🔑 New method available

When using Drawer Navigator:

```js
navigation.toggleDrawer()
```

### 💡 Behavior:

- Opens drawer if closed
    
- Closes drawer if open
    

---

## 🧠 Key concepts

### 🔁 Navigation props evolve

- Stack → basic navigation methods
    
- Drawer → adds drawer-specific methods
    

---

### 🎨 Styling hierarchy

```text
Drawer.Navigator (global styles)
   ↓
Drawer.Screen (specific overrides)
```

---

### ⚙️ Drawer customization power

You can control:

- Labels
    
- Icons
    
- Colors
    
- Layout
    
- Even custom drawer UI
    

---

## ⚠️ Common mistakes

- ❌ Styling only one screen instead of global
    
- ❌ Hardcoding icon color instead of using provided `color`
    
- ❌ Forgetting to import Ionicons
    
- ❌ Not using `screenOptions` for shared styles
