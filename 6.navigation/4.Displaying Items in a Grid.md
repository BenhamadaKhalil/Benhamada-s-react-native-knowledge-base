## 📌 Styling the Categories Grid (React Native)

---

## 🧠 Key Concepts

- Use **FlatList columns** to create a grid layout
    
- Style reusable UI components (`CategoryGridTile`)
    
- Handle **Pressable feedback (Android + iOS)**
    
- Use **Platform-specific styling**
    
- Add **dynamic styles based on data**
    
- Improve UI with shadows, spacing, and typography
    

---

## 🧩 1. Create a Grid Layout with FlatList

### 🔹 Key Property: `numColumns`

```js
<FlatList
  data={CATEGORIES}
  numColumns={2}
  keyExtractor={(item) => item.id}
  renderItem={renderCategoryItem}
/>
```

### 💡 Effect:

- Converts list → **grid layout**
    
- 2 items per row
    
- Can also use 3+ columns
    

---

## 🎨 2. Styling the Grid Tile

### 📄 `CategoryGridTile.js`

We structure it with 3 layers:

```
Pressable
  └── outer View (container + shadow)
        └── inner View (content + color)
              └── Text (title)
```

---

## 🧱 3. Outer Container Styling

```js
gridItem: {
  flex: 1,
  margin: 16,
  height: 150,
  borderRadius: 8,
  backgroundColor: "white",

  // Android shadow
  elevation: 4,

  // iOS shadow
  shadowColor: "black",
  shadowOpacity: 0.25,
  shadowOffset: { width: 0, height: 2 },
  shadowRadius: 8,
}
```

### 💡 Important:

- `flex: 1` → fills available grid space
    
- `margin` → spacing between tiles
    
- `elevation` → Android shadow
    
- iOS shadow requires `backgroundColor`
    

---

## 📦 4. Inner Container Styling

```js
innerContainer: {
  flex: 1,
  padding: 16,
  justifyContent: "center",
  alignItems: "center",
}
```

### 💡 Purpose:

- Centers text
    
- Adds spacing inside tile
    
- Controls layout inside the card
    

---

## 👆 5. Pressable Styling (Important)

### 🔹 Fix layout issue:

```js
button: {
  flex: 1,
}
```

```js
<Pressable style={styles.button}>
```

### 💡 Why?

- Pressable must take full space
    
- Otherwise inner layout collapses
    

---

## 🌈 6. Dynamic Background Color

Instead of hardcoding:

```js
backgroundColor: color
```

Use:

```js
style={[styles.gridItem, { backgroundColor: color }]}
```

### 💡 Result:

- Each category has its own color 🎨
    

---

## 📱 7. Press Feedback (Android + iOS)

---

### 🔹 Android Ripple Effect

```js
android_ripple={{ color: "#ccc" }}
```

### 💡 Improves UX:

- Visual feedback on tap
    

---

### 🔹 Fix ripple overflow

```js
overflow: Platform.OS === "android" ? "hidden" : "visible"
```

---

### 🔹 iOS Press Feedback

```js
buttonPressed: {
  opacity: 0.5,
}
```

```js
style={({ pressed }) => [
  styles.button,
  pressed ? styles.buttonPressed : null
]}
```

### 💡 Result:

- iOS → fades when pressed
    
- Android → ripple effect
    

---

## 🧠 8. Platform API

```js
import { Platform } from "react-native";
```

Used for:

- Android vs iOS differences
    
- Styling behavior control
    

---

## 🎯 9. Fix Rounded Corners Issue

Problem:

- Ripple ignored border radius
    
- Shadow broken when using `overflow: hidden`
    

### ✅ Solution:

- Apply border radius to BOTH:
    
    - outer container
        
    - inner container
