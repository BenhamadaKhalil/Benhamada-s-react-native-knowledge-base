## ⭐ React Native Notes — Building a Custom Icon Button (Header Action)

---

## 🎯 Goal of this lesson

Replace the default `<Button />` with a **custom reusable Icon Button** that:

- Uses icons
    
- Supports press interaction
    
- Provides visual feedback
    
- Is reusable across the app
    

---

## 🧩 1. Creating the IconButton component

📁 `components/IconButton.js`

### 📦 Basic structure

```js
import { Pressable } from 'react-native';
import { Ionicons } from '@expo/vector-icons';

function IconButton() {
  return (
    <Pressable>
      <Ionicons name="star" size={24} color="white" />
    </Pressable>
  );
}

export default IconButton;
```

---

## 🎨 2. Making the component reusable (props)

We replace hardcoded values with props:

```js
function IconButton({ icon, color }) {
  return (
    <Pressable>
      <Ionicons name={icon} size={24} color={color} />
    </Pressable>
  );
}
```

---

## 🔘 3. Handling press events

We pass a function from parent → child:

```js
function IconButton({ icon, color, onPress }) {
  return (
    <Pressable onPress={onPress}>
      <Ionicons name={icon} size={24} color={color} />
    </Pressable>
  );
}
```

---

## 🎯 4. Adding visual feedback (pressed effect)

### 📌 Style setup

```js
import { StyleSheet } from 'react-native';

const styles = StyleSheet.create({
  pressed: {
    opacity: 0.7,
  },
});
```

---

### 📌 Apply dynamic style

```js
<Pressable
  onPress={onPress}
  style={({ pressed }) => pressed && styles.pressed}
>
```

---

### 💡 Key idea

- `pressed` → boolean (true when pressed)
    
- Adds **opacity effect** when tapping
    

---

## 📲 5. Using IconButton in MealDetailScreen

Replace default button:

```js
<IconButton
  icon="star"
  color="white"
  onPress={headerButtonPressHandler}
/>
```

---

## 🔁 6. Full integration with navigation header

Inside `useLayoutEffect`:

```js
useLayoutEffect(() => {
  navigation.setOptions({
    headerRight: () => (
      <IconButton
        icon="star"
        color="white"
        onPress={headerButtonPressHandler}
      />
    ),
  });
}, [navigation, headerButtonPressHandler]);
```

---

## 🧠 7. Key concepts

### ♻️ Reusable component design

- Props make component flexible:
    
    - `icon`
        
    - `color`
        
    - `onPress`
        

---

### 🎨 UI improvement

- Replaces ugly default `<Button />`
    
- Uses icons → modern mobile UI
    

---

### ⚛️ Separation of concerns

- UI logic → inside `IconButton`
    
- Business logic → inside screen
    

---

## ⚠️ Common mistakes

- ❌ Forgetting to pass `onPress`
    
- ❌ Hardcoding icon instead of using props
    
- ❌ Not importing `Ionicons`
    
- ❌ Not using `pressed` feedback
