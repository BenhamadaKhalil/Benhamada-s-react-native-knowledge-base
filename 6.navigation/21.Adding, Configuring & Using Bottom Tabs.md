Learn how to:

- Use **Bottom Tab Navigator**

---

## 🧭 1. What is Tab Navigation?

A **Tab Navigator** displays navigation options as tabs:

### 📱 Behavior:

- Tabs at **bottom (most common)** or top
    
- Tap tab → switch screen instantly
    
- No stacking → direct switching
    

---

## 🔄 2. Types of tab navigators

- Bottom Tabs ✅ (most used)
    
- Top Tabs (Material style)
    
- Platform-specific variants
    

👉 In this course: **Bottom Tabs**

---

## 📦 3. Installation

```bash
npm install @react-navigation/bottom-tabs
```

---

## 🧩 4. Basic setup

### 📌 Import navigator

```js
import { createBottomTabNavigator } from '@react-navigation/bottom-tabs';
```

---

### 📌 Create navigator

```js
const Tab = createBottomTabNavigator();
```

---

### 📌 Setup in App.js

```js
<NavigationContainer>
  <Tab.Navigator>
    <Tab.Screen name="Welcome" component={WelcomeScreen} />
    <Tab.Screen name="User" component={UserScreen} />
  </Tab.Navigator>
</NavigationContainer>
```

---

## 📱 5. Default behavior

Out of the box you get:

- ✅ Bottom tab bar
    
- ✅ Labels (screen names)
    
- ✅ Switching between screens
    
- ❌ No icons (must be added manually)
    

---

## ⭐ 6. Adding icons to tabs

### 📌 Import icons

```js
import { Ionicons } from '@expo/vector-icons';
```

---

### 📌 Add icon to screen

```js
options={{
  tabBarIcon: ({ color, size }) => (
    <Ionicons name="home" color={color} size={size} />
  ),
}}
```

---

### 📌 Second screen example

```js
options={{
  tabBarIcon: ({ color, size }) => (
    <Ionicons name="person" color={color} size={size} />
  ),
}}
```

---

## 🎯 Important props provided automatically

- `color` → active/inactive color
    
- `size` → consistent icon size
    

👉 Always use these → ensures consistency

---

## 🎨 7. Styling tabs (global)

Use `screenOptions`:

```js
<Tab.Navigator
  screenOptions={{
    tabBarActiveTintColor: '#3c0a6b',
  }}
>
```

---

### 📌 Result:

- Active tab → purple
    
- Inactive tab → default color
    

---

## ⚙️ 8. Other customization options

You can control:

- Label visibility
    
- Icon position
    
- Background color
    
- Entire tab bar style
    

---

## 🧠 9. Key concepts

### 🔁 Same structure as other navigators

```text
Navigator
  ├── Screen
  ├── Screen
```

---

### 🎨 UI handled automatically

- Layout
    
- Positioning
    
- Spacing
    

---

### ⚙️ Config flexibility

- Per screen → `options`
    
- Global → `screenOptions`
    

---

## ⚠️ Common mistakes

- ❌ Forgetting to add icons
    
- ❌ Hardcoding icon color instead of using `color`
    
- ❌ Keeping drawer options (not compatible)
    
- ❌ Not using `screenOptions` for shared styles
    

---

## 🆚 10. Drawer vs Tabs (quick comparison)

|Feature|Drawer|Tabs|
|---|---|---|
|UI|Side menu|Bottom bar|
|Use case|Many screens|Main sections|
|UX|Hidden navigation|Always visible|
