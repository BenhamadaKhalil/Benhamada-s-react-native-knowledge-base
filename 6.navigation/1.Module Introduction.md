## 📌 React Native Navigation — Introduction

---

## 🧠 Key Concepts

- **Navigation** in React Native = moving between different screens (views) in your app.
    
- In earlier examples (like the game app), navigation was:
    
    - **Manual**
        
    - **Basic**
        
    - Without animations or history control
        
- Real-world apps need:
    
    - Smooth transitions 🎬
        
    - Ability to **move forward and backward**
        
    - Better **user experience (UX)**
        

---

## 🚧 Problem with Basic Navigation

In the previous app:

- Screens were switched manually (e.g., using state)
    
- No navigation history (no "go back")
    
- No animations
    
- Not scalable for bigger apps
    

👉 This approach works only for **simple apps**, not production-level apps.

### 2. Navigation Approaches

You will learn different navigation systems:

#### 🔹 Stack Navigation

- Screens are stacked on top of each other (like pages)
    
- You can:
    
    - Push a new screen
        
    - Go back to the previous one
        
- Example:
    
    ```
    Home → Details → Settings
    ```
    

---

#### 🔹 Drawer Navigation

- Side menu (usually from the left)
    
- Used for main app sections
    
- Example:
    
    - Dashboard
        
    - Profile
        
    - Settings
        

---

#### 🔹 Tab Navigation

- Tabs at bottom or top
    
- Quick switching between main screens
    
- Example:
    
    - Home | Search | Profile
        

---

## 💡 Practical Insight

- Navigation is one of the **core parts of any mobile app**
    
- Choosing the right navigation type affects:
    
    - UX
        
    - App structure
        
    - Scalability
        

👉 In real apps, you often **combine multiple navigation types**:

- Stack + Tabs
    
- Drawer + Stack
