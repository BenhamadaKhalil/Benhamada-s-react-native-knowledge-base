## ⚙️ Prerequisite: Node.js

Before creating a project, you **must install Node.js**.

- Website: https://nodejs.org
- Install the **latest LTS version**

### Why Node.js Is Required
- Node.js is a **JavaScript runtime**
- It allows JavaScript to run **outside the browser**
- Expo uses Node.js **under the hood**
- Node.js enables the use of the `npx` command

Important:
- We will **not write Node.js code** in this course
- It is only required as a tool

---

## 🧰 Creating the Project with Expo

After installing Node.js:

1. Open your system **terminal / command prompt**
2. Navigate to the folder where you want to create the project
3. Run the project creation command

### Command Used

```bash
npx create-expo-app --template blank rnCourse
````

Explanation:

- `npx` → runs a package without installing it globally
    
- `create-expo-app` → creates a new Expo project
    
- `--template blank` → creates a **minimal project**
    
- `rnCourse` → project name (and folder name)
    

---

## 📌 Why Use the `blank` Template

- Produces a **very basic setup**
    
- Makes it easier to:
    
    - Learn step by step
        
    - Understand core concepts
        
- Avoids:
    
    - Extra complexity
        
    - TypeScript (used by default in other templates)
        

Reason:

- Not everyone knows TypeScript
    
- The course focuses on **core React Native concepts**
    

---

## 📁 Project Creation Result

- A new folder is created with the project name
    
- All required dependencies are installed automatically
    
- This process can take some time (normal behavior)
    

Once finished:

- The terminal shows commands to:
    
    - Enter the project folder
        
    - Run the app on:
        
        - Android
            
        - iOS
            
        - Web (ignored in this course)
