## 🎯 Purpose of This Video
Explain **how React Native works internally**, especially:
- What gets compiled
- What does NOT get compiled
- How JavaScript communicates with native platforms

---

## 🧩 Writing React Native Code

When building a React Native app:
- You write **React components**
- The syntax looks the same as React.js
- You can use:
  - Arrow functions
  - Regular functions
  - Class-based components

This code is later **bundled into a real native app**.

---

## 🧱 Special React Native Components

Some JSX elements used in React Native are **not available on the web**, for example:
- `View`
- `Text`

These are **React Native–specific components**.

Important:
- These components are **compiled to native UI elements**
- This compilation applies **only to JSX (UI)**

---

## 🔄 Component Mapping Concept

React Native translates its components to **platform-specific native elements**.

The instructor explains this using a comparison table:

| Web (React DOM) | Android (Native) | iOS (Native) | React Native |
|----------------|------------------|--------------|--------------|
| `input`        | EditText         | UITextField | `TextInput` |

Meaning:
- You write **one React Native component**
- React Native compiles it to:
  - Android native UI
  - iOS native UI

This mapping works for:
- `TextInput`
- `View`
- Many other components

➡️ One of React Native’s **main jobs** is handling this mapping.

---

## ⚠️ What Gets Compiled vs What Does Not

### ✅ Compiled
- JSX elements
- React Native UI components
- Visual structure of the app

### ❌ Not Compiled
- JavaScript logic
- Functions
- `if` statements
- State management
- Business logic

---

## 🧠 How the Logic Works

Instead of being compiled:
- JavaScript logic runs on a **JavaScript thread**
- This thread is **embedded inside the native app**
- React Native:
  - Starts this JS process
  - Manages it for you

The JavaScript code:
- Runs as **real JavaScript**
- Communicates with the native platform
- Uses a **translation bridge** provided by React Native

---

## 🔌 Communication Model (Mental Model)

- Native App (iOS / Android)
- ⬅️➡️ React Native bridge
- JavaScript thread (your logic)

UI = Native  
Logic = JavaScript  
React Native = the connector

---

## ✅ What You Need to Know (And No More)

- UI components are compiled
- JavaScript logic is not compiled
- Logic runs in a JS thread
- React Native handles communication
- This understanding is **enough to work with React Native**

No deep internals required.

---

## 🧠 Key Takeaways

- React Native compiles **UI**, not logic
- Logic runs as JavaScript inside the app
- A bridge connects JS and native code
- Same React mindset, native execution
- Understanding this helps debug and reason about apps
