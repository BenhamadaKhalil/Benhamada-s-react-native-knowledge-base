## 🧰 Choosing a Code Editor

You can use **any code editor**, but the recommendation is:

- **Visual Studio Code**
  - Free
  - Cross-platform
  - Highly extensible
  - Very popular for React & React Native

---

## 📂 Opening the Project in VS Code

Steps:
1. Open Visual Studio Code
2. Close the welcome screen (if shown)
3. Open a folder:
   - Menu → File → Open / Open Folder
4. Select the project folder created earlier  
   (e.g. `RNCOURSE`)
5. Open it

The Expo React Native project is now loaded in VS Code.

## 📁 Project Structure Overview

The created project is intentionally **minimal**.

### Folders You Can Ignore (For Now)

- `.vscode`
  - Workspace-specific editor settings
- `.expo-shared`
  - Internal Expo data

---

### `assets/`
- Will be important later
- Used to store:
  - App icon
  - Images used inside the app

---

### `node_modules/`
- Contains all third-party dependencies
- Managed automatically
- You generally **never edit this**

---

## 📦 `package.json`

- Lists all project dependencies
- Includes:
  - `expo`
  - `react`
  - `react-native`
  - `react-dom`
  - `react-native-web`

Important clarifications:
- Expo is **not only a CLI**
- Expo is also a **JavaScript package**
- It provides many utilities used throughout the app

Notes on web support:
- `react-dom` exists only because of `react-native-web`
- Web support is **not the focus of this course**
- For web apps, React + React DOM is preferred

---

### `package-lock.json`
- Related to dependency management
- Auto-generated
- Not manually edited

---

## ⚙️ `babel.config.js`

- Configures how code is **transpiled**
- Internal setup file
- Should **not be changed** unless you know exactly what you’re doing

---

## 🧩 `app.json`

- Expo-specific configuration file
- Used when:
  - Previewing the app
  - Building for app stores

Allows configuration of:
- App name
- App appearance
- Behavior & settings

This file will be revisited later when needed.

---

## 🧠 `App.js` — The Main File

- The **only real code file** in the starter project
- Contains:
  - A React component
  - React Native–specific JSX elements
  - Some initial styling

Important:
- This file is the **entry point** of the app
- The instructor provides a version of `App.js`
  - To ensure everyone has the same starting code
- Future lessons will build on this file

Styling may look unfamiliar:
- React Native styling works differently
- This will be explained later
