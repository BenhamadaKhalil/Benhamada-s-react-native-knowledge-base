## 📂 Section

## 🎯 Purpose of This Video
Explain **what React Native is**, how it relates to **React.js**, and why it can be used to build **real mobile apps** for iOS and Android.

---

## 🧠 Core Idea

React Native is a framework that allows you to build **real native mobile applications** for:

- iOS
- Android

These apps:
- Are **real apps**, not web apps
- Can be published on **App Store** and **Google Play**
- Run on actual devices

---

## 🔗 Relationship Between React.js & React Native

### React.js
- A **JavaScript library**
- Used to build **user interfaces**
- Originally created for **web development**
- Focuses on:
  - State management
  - Component trees
  - UI logic

Important point:
- **React itself is platform-agnostic**
- It does **not** depend on the browser

---

### React DOM
- A **separate library**
- Connects React to the **web browser**
- Translates React components into:
  - HTML
  - CSS
  - DOM elements

➡️ React + React DOM = **Web apps**

---

## 📱 Where React Native Fits In

React Native is essentially an **alternative to React DOM**.

Instead of targeting the browser:
- React Native targets **iOS & Android**

What React Native provides:
- Built-in **React components**
- These components:
  - Are written in JSX
  - Are compiled into **native UI elements**
- Handles the **compilation step automatically**

So:
- React Native replaces React DOM
- But still uses **React concepts**

---

## 🧩 Native Capabilities

React Native also exposes **native device APIs**, such as:
- Camera access
- Other platform-specific features

This allows:
- JavaScript code
- To interact with **native device functionality**

---

## 🧠 Mental Model

- React = UI logic + state management (platform-independent)
- React DOM = React → Browser
- React Native = React → iOS / Android

Same React mindset, **different target platform**.

---

## ⚠️ Important Requirement

To work with React Native:
- You **must know React.js**
- You still write:
  - React components
  - JSX
  - React state logic
- You simply use:
  - React Native components
  - React Native APIs

---

## ✅ Key Takeaways

- React Native builds **real native mobile apps**
- It is **not** a web-to-mobile wrapper
- React is platform-agnostic
- React Native replaces React DOM
- React knowledge is **mandatory**
- Same React concepts, new platform
