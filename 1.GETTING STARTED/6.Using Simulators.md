## 🔁 Why Use Simulators?

Using **Expo Go on a real device** is often enough.

However, simulators are useful if:
- You don’t own both Android and iOS devices
- You want to test multiple platforms
- You prefer testing directly on your computer

A simulator:
- Runs on your local machine
- Simulates a real phone
- Is suitable for development and testing

---

## 🤖 Android Emulator (All Platforms)

To run Android simulators:

### Install Android Studio
- Download from: https://developer.android.com/studio
- Available for:
  - Windows
  - macOS
  - Linux
- Required to run Android emulators

Installation may take time, but it’s necessary.

---

### Creating an Android Emulator

Inside Android Studio:
1. Open Android Studio
2. Go to **Virtual Device Manager**
3. Click **Create Device**
4. Choose a device preset (e.g. Pixel 5)
5. Select an Android version (e.g. API 32)
6. Keep default settings
7. Click **Finish**
8. Click ▶️ to start the emulator

The emulator is now:
- A virtual Android phone
- Running on your computer

---

### Important Emulator Requirement

Expo requires:
- An emulator **with Google Play Store support**

If you get errors:
- Create a new emulator
- Choose a template that includes the **Play Store icon**

Expo needs this to install **Expo Go** automatically.

## 🍎 iOS Simulator (macOS Only)

For iOS:
- You must use **Xcode**
- Only available on **macOS**

Steps:
1. Open the macOS App Store
2. Search for **Xcode**
3. Download and install it

⚠️ Limitation:
- iOS simulators are **not available on Windows or Linux**
- This is an Apple restriction

---

### iOS on Windows / Linux

If you:
- Don’t own a real iPhone
- Don’t have a Mac

Then:
- You can only **preview Android apps locally**
- iOS builds are still possible later via cloud services
- But local preview requires macOS or a real iPhone

---

## ⚙️ Xcode Setup (macOS)

After installing Xcode:
1. Open Xcode
2. Go to **Preferences**
3. Open **Locations**
4. Select a version under **Command Line Tools**
   - None is selected by default
   - You must select one

Then close Xcode.

---

## ▶️ Running the App on Simulators

Make sure:
- The Expo dev server is running
- You started it earlier with `npm start`
- Keep it running while coding

From the running terminal:

- Press **A** → run app on Android emulator
- Press **I** → run app on iOS simulator
- Press **R** → manually reload the app

Expo will:
- Detect running simulators
- Install Expo Go automatically
- Open your app inside Expo Go

You can:
- Run Android and iOS **at the same time**
- No need to restart the dev server

---

## 🔁 Live Reload Behavior

While the dev server is running:
- Code changes are detected automatically
- Saving a file triggers instant reload
- Changes appear on:
  - Real devices
  - Android emulators
  - iOS simulators

Manual reload is optional (`R`).

---

## 🧪 Debug Menu

On simulators:
- A debug/info screen may appear
- Provides tools like:
  - Reload
  - Debugging options

Debugging will be covered later.

---

## 🛑 Dev Server Rule

- Keep `npm start` running while coding
- If stopped:
  - Code is no longer watched
  - Updates are no longer pushed

To stop:
- Press **Ctrl + C**

To restart:
- Run `npm start` again

## 🧠 Key Takeaways

- Expo supports real devices and simulators
- Android emulators work on all platforms
- iOS simulators require macOS + Xcode
- Expo detects simulators automatically
- One dev server can serve multiple devices
- Live reload works everywhere
